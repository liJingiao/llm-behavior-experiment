# 用机器行为文献训练组件知识库的方法

**方法标准 v1.1，2026-11-22 确认。** 训练对象是供研究者设计机器行为实验时查用的组件知识库。训练材料为243篇开发论文。另有109篇评测候选，未用于这项训练。

## 论文方法表述

我们以69项实验组件及其构念与任务附录为基线，从243篇开发论文中提取研究者实际实施的实验操作与控制措施，并为每项操作保留原文证据。原组件手册以传统实验方法为基础，已经包含20项大模型专项。我们逐项对照论文的实际操作与原库的指导。只要一篇论文揭示了原库缺少或未讲完整的步骤，就可以登记为一个知识点。多篇论文需要同一步骤且适用条件一致时，归并到同一知识点。5,479条范围内的实际方法需求经分析，形成381个需要逐项处理的知识点。[原手册](../../../analysis/literature_component_coverage/baselines/实验组件_v1.4.md) · [构念与任务附录](../../../analysis/literature_component_coverage/baselines/实验设计原则清单v1.6_相关构念与任务.md) · [具体功能与缺口表](../../../analysis/literature_component_coverage/data/gaps.json)

我们按知识点核对关联论文，提炼研究者需要的输入、操作、输出及适用条件，并回到原条款判断需要补什么。多个实例所需的操作相同时，共用一段方法说明；分析单位、接口或解释条件有实质差异时，分别交代。开发论文支持对实际做法的描述，原始方法文献、作者实现和官方文档支持通用规则。定稿时，每个知识点都能追到对应的论文证据和正文位置，或查到直接引用原附录、列为范围外的理由。[方法来源](SOURCES.md) · [逐项证据与定稿正文](TRACEABILITY.md)

同时，我们逐号审视69个组件，结合其原职责、论文中的实际用途和机器实验的适用条件，共同决定保留、改写、合并或移出。使用频次帮助发现应当仔细审视的条目。即使很少出现，只要有明确的机器侧用途，仍可保留。修订记录保存每个原编号的决定、理由与内容去向。[原组件使用统计](../../../analysis/literature_component_coverage/tables/components.csv) · [组件修订记录](COMPONENT_REVISIONS.md)

## 逐项判断的尺度

| 要判断什么 | 怎样处理 |
|---|---|
| 论文提供了什么证据 | 从论文需求找到对应的方法事实和原文位置。区分作者实际执行的操作、只讨论过的可能性和未报告的设置。有歧义时定向查原文，通用知识不回填为某篇论文的实施事实。 |
| 具体缺在哪一步 | 对照原手册和附录的实际条款。两者均缺少该做法时，写出实施方法。已有部分指导时，指出还缺哪一步及其影响。附录已给出通用判据时直接引用，保留论文特有设置的出处。 |
| 什么内容可以共用 | 按操作和适用条件归并。同一编号关联的实例都纳入考虑。会改变输入、计算步骤、分母或结论的差异需分别核对。只有复现单篇研究才需要的参数留在论文记录里。 |
| 怎样知道写得够不够 | 按原知识点提出的问题检查正文。缺的是计算规则，就核对操作数、分母和计算关系。缺的是两步之间的衔接，就说明上一步的产出怎样进入下一步。缺的是解释边界，就写清结果允许作何判断。通用依据不足时保留待补项及下一处可查来源。 |
| 哪些属于机器行为实验 | 看操作作用于谁。人工给模型输出评分可以属于机器行为测量；仅用于维持真人答题者注意力的安排列为范围外。使用人类构念术语时说明实际测到的模型行为；主张人机测量等价需有相应依据。 |
| 怎样决定组件去留 | 按论文去重查看使用记录，再单独判断机器适用性。原使用统计可能同时包含人类侧和机器侧用例。合并或移出须注明每项仍适用的操作由哪一段承接，并保留原编号。具有独立功能且现有组件无法承接时，可提出有证据的增设建议。最终去留由项目负责人与整理者共同决定。 |

**例一，同题比较两种提示。** 第235篇报告了配对重抽样。对这类实验，手册需要把“保留配对”写成可以照做的步骤：每次抽取题目，同时取出这道题在两种提示下的答案，再重算两者的差异。第120篇没有报告具体重抽单位；这一缺失仍留在该篇记录中。[配对重抽样与论文证据](TRACEABILITY.md#gap-kg_boot_paired) · [统计分析第12节](K01_statistics.md#k01-12)

**例二，任务规则已有出处。** 第199篇用到n-back任务。原附录已经说明判断“当前刺激是否与往前数第n个刺激匹配”，可以直接引用。该论文实际怎样构造非目标序列、如何设置起始试次，仍按该篇证据记录。[原附录](../../../analysis/literature_component_coverage/baselines/实验设计原则清单v1.6_相关构念与任务.md) · [第199篇对应记录](TRACEABILITY.md#gap-worker_2_nback_generation_gap)

**例三，低频组件如何取舍。** J12“基准饱和”在开发文献中实际采用为0篇。当模型得分接近测试上限时，研究者仍需判断题目能否区分模型，故按此条件保留。D2“疲劳效应”关联的第059篇规定，每名众包答题者最多回答20题，以维持注意力并减少答题者偏差。该编号移出独立目录，其中可观察的机器侧现象分别进入长上下文位置、长输出重复等条目。[J12的依据](COMPONENT_REVISIONS.md#rev-j12) · [D2的决定和承接条目](COMPONENTS.md#d2)

## 结果如何计数与复查

知识修订以原知识点编号计数。381个知识点中，272个关联一篇开发论文，109个关联两篇或以上。按原库能提供的指导划分，260项在训练前手册及附录中缺少相应操作指导，118项已有部分指导，两类均在定稿方法正文中有具体落点。另有1项直接引用原附录，2项的论文实例仅属真人参照。同一段正文可以回答多个知识点。[381项处理结果](TRACEABILITY.md)

组件修订按独立组件计数。原69项中，59项保留原职责，6项保留编号并改写，3项并入相邻组件，1项移出独立目录，定稿为65项。使用者按组件查正文，需核实理由时按原编号查修订记录。逐项核对回答的是知识库收录了哪些指导，应用效果留待后续评测。[定稿组件库](README.md) · [执行与恢复规则](TRAINING_WORKFLOW.md#component-training)
