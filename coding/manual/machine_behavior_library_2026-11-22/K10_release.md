# K10 可解密的公开材料发布

连接J11和J19。本章回应article_055/D018的一项发布方法需求，不要求所有研究改用加密，也不处理当前项目的真实发布。

<a id="k10-01"></a>
## 01 公开密文、解密入口与可获取性

适用目标是让研究者能取得评测材料，同时减少普通网页抓取直接取得明文的机会。它并不依赖永久保密，因为解密办法也公开。

可操作流程：

1. 将待发布材料作为明确版本冻结，说明格式、许可和预期用途；保留原始明文的受控工作副本。
2. 用明确算法及参数生成发布密文，提供解密程序、所需依赖、合法取得密钥/口令的步骤及解密后格式说明。密钥若可从公开脚本或人类题目取得，应明确这一访问模型。
3. 在干净目录按公开说明完成一次取得→解密→读取检查，与原版本直接比较记录数、字段和实际内容；这一步是可获取性验收，不是污染检测。
4. 检查发布网页、预览、示例和历史版本是否另含完整明文；只记录实际检查范围。未来更新另发版本，保留版本对应，避免使用者误把解密后的不同数据当同一评测集。

article_055原文报告公开加密数据和解密脚本，希望减少训练抓取。2026年11月5日查阅作者仓库时可见加密JSONL、decrypt.py和通过完成自指陈述解密的说明。开发论文的提取记录保留了当时的核查范围。[作者仓库](https://github.com/TristanThrush/i-am-a-strange-dataset) 这里的发布程序说明不构成对任何模型训练暴露情况的实测。

公开可解密意味着有意执行脚本的抓取者仍能获得内容；算法、脚本或发布方式本身不能证明任一模型没有见过材料。评测污染判断仍需独立证据，并连接原J11的时间、隔离和留出设计。相关A事实与页码见[逐项对应](TRACEABILITY.md)。
