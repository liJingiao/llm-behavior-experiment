# K02 标注、裁决与信度

连接A2、F3、E5、C6。已有明确判据的评分、试标与讨论裁决继续使用原手册；下面补“评价哪一种一致性、怎样计算、能说明什么”。客观判据的常规核验不必一律追加机会校正系数。

<a id="k02-01"></a>
## 01 先保留独立判断，再产生最终标签

先定义标注单位、类别/量尺、允许多选与否、证据跨度、无法判断和缺失的处理。用指南与少量练习统一理解，正式标注保留各评分者原始标签、对象ID和标注版本；需要评价独立一致性时，评分者在该阶段不互看答案。对不明确或复合类别写决策规则，不能靠最终分数倒推类别。

之后可以讨论分歧或由指定角色裁决，形成用于后续分析的最终标签。共识是最终标签的产生方式，不是独立一致性估计；把裁决后的相同标签拿去算κ会改变问题。盲法解决特定来源线索，信度系数描述某种重复性，两者不能相互代替。

article_090/D313已经有双标与讨论裁决的事实，现有原则足以承接；两名评分者是否独立盲标，原文未说明。article_112/D004则确有Krippendorff α的计算需求，应沿以下具体方法处理。保存流程不要求所有研究使用同一个系数，也不将标注者一致误当内容真实。

<a id="k02-02"></a>
## 02 两名评分者：Cohen κ、加权κ与两两聚合

把共同标注对象组成类别×类别计数表n_ab。`P_o=Σn_aa/N`，两名评分者的类别边际比例为p_a、q_a，`P_e=Σp_aq_a`，`κ=(P_o−P_e)/(1−P_e)`。先核对类别顺序与缺失共同子集；P_e=1时系数未定义。κ为负表示低于该机会模型，不是“负百分比一致”。类别基率极偏时，应同时呈现原始一致率和列联表。

有序类别用明确的损失矩阵d_ab替代简单不等标签：线性损失可取`|a−b|/(k−1)`，平方损失为其平方；`κ_w=1−Σd_ab o_ab/Σd_ab e_ab`，o、e分别为观察和机会联合比例。权重必须与实际量尺相符，类别编号不等于天然等距分值。

多名评分者两两算κ再平均，是“评分者对”的汇总，不是Fleiss κ。说明每对使用哪些共同对象、简单还是加权平均、各对样本重叠。若做区间，应在保留这些共同结构的对象层重抽或用匹配的模型。来源：[Cohen实现与权重说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.inter_rater.cohens_kappa.html)。

<a id="k02-03"></a>
## 03 多名类别评分者：Fleiss κ及未明变体

标准平衡情形有N个对象、每对象m次评定，n_ic为对象i获类别c的次数。对象内成对一致率`P_i=[Σ_c n_ic(n_ic−1)]/[m(m−1)]`，总体`P̄=mean(P_i)`；类别边际`p_c=Σ_i n_ic/(Nm)`，机会一致`P_e=Σp_c²`，最后`κ=(P̄−P_e)/(1−P_e)`。

先将数据整理为对象×类别计数，并核对每行总数及共同标注结构。m变化、缺失或不同抽样方案时，不能未经说明套平衡公式。Fleiss使用观察边际定义机会模型；均匀机会模型的其他κ是另一系数，同样原始一致率会得到不同结果。[Fleiss与不同机会模型](https://www.statsmodels.org/stable/generated/statsmodels.stats.inter_rater.fleiss_kappa.html)。

论文仅写κ而未明变体时，可以说明机会校正目标、评分者结构和基率限制，不能从“有三个人”自动补成Fleiss。article_054/D009只称“Gwet’s gamma”，没有给实现和多选聚合；保留该命名与未知，不能替换成Cohen κ、AC1或AC2。若在新研究中采用Gwet家族方法，需要选定具体系数、类别尺度和其机会模型后再计算。这里的补充闭合的是已知的信度目标与使用边界，不声称恢复了原论文未报告的算法。

用模型生成解释作评分对象时，先按“同一条输出、同一评分维度”建表。例如第059篇有四个维度；按维度分别计算可以保留标准差异，若合并，须另写合并单位和理由。多人只给了聚合类别份额时，若缺少每题的评定次数或原始标签，不能把份额直接作为题内配对计数。

若新的机器输出评分研究明确选择无权重AC1，可先在每题多人标注的名义类别上求成对同意率Pₐ，再对各类别的题内评分占比跨题平均得πₖ。对q≥2个类别且每题有相同数量、至少两名评分者的完整设计，机会项为Pₑ=Σπₖ(1−πₖ)/(q−1)，系数为(Pₐ−Pₑ)/(1−Pₑ)。这说明原始同意率本身不能确定校正系数；换成有序类别加权时还应声明权重。第054篇没有给足信息把其“gamma”认作这里的AC1。[Gwet，AgreeStat计算说明 §4.4](https://www.agreestat.com/documents/agreestatguide.pdf)

<a id="k02-04"></a>
## 04 Krippendorff α：不一致、距离与缺失

整理对象×评分者矩阵；缺失用缺失值表示，不另编码成一个实质类别。选择名义、顺序、区间等测量层次。名义距离对不同类别取1、相同取0；区间距离取数值差平方；顺序尺度应使用相应秩/累积频数距离，不随意把类别编号当等距。

α=`1−D_o/D_e`。一个可复建的计数形式如下：对至少有两次有效评定的对象u，令m_u为有效次数、n_uc为类别c次数，构造重合矩阵

`o_ck=Σ_u n_uc[n_uk−I(c=k)]/(m_u−1)`。

令`n_c=Σ_k o_ck`、`n=Σ_c n_c`，给定距离δ²，有

`D_o=Σ_ck o_ck δ²(c,k)/n`；

`D_e=Σ_ck n_c[n_k−I(c=k)]δ²(c,k)/[n(n−1)]`。

只有一次有效评定的对象不能提供对象内一致性；D_e=0时α未定义。区间和缺失处理要与所选实现一致。α高说明相对该距离和机会模型的不一致较低，不等于类别本身有效或标注符合外部真值。使用接口时检查矩阵方向：有的实现要求评分者为行、对象为列。[实现与缺失矩阵约定](https://github.com/pln-fing-udelar/fast-krippendorff)。

article_112/D004按角色×face-act分层计算再平均有效格。平均多个α不等于把原标签合并后计算一个α；必须保存分层、有效格和权重。不能用本章推荐的明确规则倒填原论文未报告的细节。

## 05 连续评分的ICC：一致还是数值相同

先回答三件事：评分者视为固定名单还是可推广的抽样；关心绝对数值相同还是允许评分者有整体偏移的一致性；最终使用一次评分还是k次均值。把这些选择写出，比只写“ICC”有用。

平衡完整的n对象×k评分者设计中，记MS_B为对象间均方、MS_J为评分者间均方、MS_E为双向模型残差均方、MS_W为单向对象内均方：

|目标|常用点估计|
|---|---|
|单向单次ICC|`(MS_B−MS_W)/(MS_B+(k−1)MS_W)`|
|双向绝对一致、单次|`(MS_B−MS_E)/(MS_B+(k−1)MS_E+k(MS_J−MS_E)/n)`|
|双向一致性、单次|`(MS_B−MS_E)/(MS_B+(k−1)MS_E)`|
|绝对一致、k次均值|`(MS_B−MS_E)/(MS_B+(MS_J−MS_E)/n)`|
|一致性、k次均值|`(MS_B−MS_E)/MS_B`|

以对象×评分者的双向ANOVA或合适的方差成分模型估计所需项，连同选定形式报告区间。平衡ANOVA的F反演区间需使用对应ICC形式；若以对象重抽构造区间，保留同对象所有评分，并说明推断是给定这批评分者还是还涉及评分者总体。不平衡/缺失数据不能直接假装完整表，应使用支持该结构的估计方案。

评分者均值偏移可使一致性ICC高、绝对一致ICC低；取多次均值通常比单次更稳定，不能拿平均ICC代替单次可靠性。来源：[Pingouin信度实现及ANOVA公式](https://github.com/raphaelvallat/pingouin/blob/master/src/pingouin/reliability.py)。

## 06 内部一致性、分半和长度校正

Cronbach α面对对象×条目矩阵：`α=k/(k−1)·[1−ΣVar(item_j)/Var(总分)]`。先按理论方向反向计分，明确缺失是整行删除、成对删除还是另有模型。它反映条目共同变化，受条目数、协方差和样本异质性影响；高α不能单独证明单维性、内容有效或评分者一致。将α解释为信度还依赖误差结构等测量假设。[计算与缺失处理](https://github.com/raphaelvallat/pingouin/blob/master/src/pingouin/reliability.py)。

分半可靠性先在明确单位上分成两半，每半独立重建相同目标：例如按各半反应重算词频、表征或相关矩阵，再按共同对象顺序比较两半结果。不能只把最终矩阵的格子随意切半。Spearman–Brown全长度校正为`2r_half/(1+r_half)`，用于两半具有相应平行/等质关系的情形；不是所有分半r都天然满足假设。重复随机分半应报告汇总方式，不能只选最高值。

实例article_047/D015重构表征后相关，article_103/D005进行长度校正。基础原始一致率或已得标签比较已有A2/F3支持，不强制转换成α。

## 07 跨初始化匹配、衰减校正及其选择影响

不同初始化的表示维度可能排列或符号不同。先计算共同对象上的跨维度相关矩阵，按所声明目标进行维度匹配；若要求一一对应，应使用全局匹配，逐列各取最大值会重复使用同一维度。是否按绝对相关匹配、是否允许翻转符号须说明。匹配后可将r做Fisher变换、平均、再反变换，但在同一数据上选最大相关会产生选择偏高，验证时宜在独立对象上评价已定匹配。

经典衰减校正为`r_corrected=r_observed/√(rel_x rel_y)`，要求信度描述相同测量目标并满足相应独立误差假设。信度低或估计不稳定时比值会放大误差，可能超过±1；不能直接截断后当作已证明的潜在真实相关。报告未校正r、两项信度和校正结果。实例article_121/D010、D013。

## 08 重复试次噪声上限与预测R²归一

若`ncsnr=σ_signal/σ_noise`，平均n个独立同方差重复后的信号占比为`ceiling=ncsnr²/(ncsnr²+1/n)`。这里n是同一对象被平均的重复数；相关噪声会改变`1/n`衰减，不能按模型调用总量填n。先确认信号/噪声的估计来自对应重复设计，再计算上限。

若预测R²为0—1比例、上限C也是比例，归一为`R²/C`；若C用百分数表示，应先除100。归一为“可解释部分的比例”后，负R²仍可能为负，超出1也应检查估计误差和假设，不能任意裁切。该上限是模型化测量可靠性的估计，不是任何预测器已达到的成绩。article_121/D024采用n=3并把上限乘100；按原A所载公式保留尺度，不猜补其未报告的额外实现。

若以人类脑反应为外部预测目标，重复次数及噪声估计取自人类测量，归一后的分数描述模型表征对该目标的预测表现。第121篇的三次重复不代表测试了模型三次。
