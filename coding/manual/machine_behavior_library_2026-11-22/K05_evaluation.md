# K05 校准、区分能力与排序评价

连接A2、F3、F1和E6。先选评价目标：概率是否可信、能否把正负例排开、某阈值下是否判对、对象之间如何排名、两套分区是否一致。这些问题不能由一个“综合准确率”替代。以下参数为方法说明；论文未报告的实现保持未报告。

<a id="k05-01"></a>
## 01 条件校准、可靠性图与分箱损失

对声称概率p和二元结果Y，校准目标是`P(Y=1|p)=p`。预测信心0.8的**一组**样本应约80%正确，不是每个样本都有可直接观察的80%正确性。先固定目标事件、样本单位和信心来源；模型自报信心与token概率见[K04](K04_probability.md#k04-01)。

在概率轴划分箱B，记录边界包含规则及空箱，计算箱内平均概率c_b、正例频率a_b与样本数n_b（按题计分时为题数）。可靠性图画(c_b,a_b)，同时显示各箱样本数，避免把少量样本的起伏当稳定规律。常见绝对误差`Σ_b(n_b/N)|a_b−c_b|`；article_023的Calibration Index用平方差`Σ_b(n_b/N)(a_b−c_b)²`。后者不是置信区间，也不等于逐样本Brier均方误差。

分箱是粗化近似：同箱中的高估与低估可能抵消，等宽、等频和log概率分箱回答的分辨率不同。报告箱数、边界、零概率与空箱规则；比较时共用协议，并查看图形和样本数。单凭平均信心等于总体正确率、信心上升或Brier更小，不能断言条件校准改善。article_038和article_172未细报的ECE损失/分箱不能从本节倒填。[校准目标与可靠性图](https://scikit-learn.org/stable/modules/calibration.html)。

边界和空箱要能落到计数上。例如可事先约定左闭右开、最后一箱包括1；空箱对加权总数的贡献为零，图上标出无观测，不给它虚构一个正确率。若有两例都报0.8而一对一错，箱内经验正确率为0.5，该箱的绝对偏差为0.3，平方偏差为0.09；两种指标即使对同一组输出也不相等。

## 02 最高类别与按类校准

top-label取每个样本最大概率`max_k p_ik`与“预测类别是否命中”的指示分箱。classwise则对每个类别k，把所有样本的p_ik与`1(Y_i=k)`分箱，先得各类别误差，再按预定类别权重平均。二者事件不同：前者不检查非最高类别的概率；后者可能被大量低概率、稀有类别主导。

article_106使用等权类平均，并比较概率等宽与−log₂p等距方案。log分箱必须定义p=0及经验上限；不能从坐标刻度猜实际边界。保留类别集合、每类样本数、类权重和样本权重，避免把宏平均与微平均混写。

## 03 ROC、PR、AP与特定排名MAP

固定正类及分数方向。依次扫描阈值，把分数达到阈值者判正：`TPR=TP/(TP+FN)`、`FPR=FP/(FP+TN)`，ROC画(FPR,TPR)。ROC AUC等于随机正例分数高于随机负例的概率，加上并列的一半；两类必须都有样本。它衡量排序，严格递增变换通常不改AUC，因此不能证明概率已校准。

PR画Recall=TPR与`Precision=TP/(TP+FP)`。正类比例改变，Precision及PR基线也改变；同一模型对“错误”与“正确”分别作正类会得到不同曲线。无预测正例的端点采用明确软件约定。article_038的主文/附录正负类命名张力保留，不能只按PR-P缩写猜方向。

非插值AP常用`Σ_n (R_n−R_(n−1))P_n`，与PR曲线梯形积分不是同一个量；并列分数需同阈值处理。多标签mAP先求每标签AP再平均，说明宏/加权方案。检索排名中，给定相关集合、无并列排名和相关总数R，也可用`AP=(1/R)Σ_r Precision@r × relevant(r)`；截断、未检出相关项与R=0须另定。

article_020并非通常的“跨标签mAP”：它依次把人类排名前i项作为相关集合，i=1…5，各求模型排名AP后平均，以保留人类top5内部次序。应保存这五个相关集合与完整候选排名，不能换成一次top5集合AP。来源：[指标的定义与平均方式](https://scikit-learn.org/stable/modules/model_evaluation.html)。

若信心越高代表越可能正确，而研究改以“错误”为目标类，应同时改变标签和分数方向，例如用1−信心排序。只翻标签而保留排序会把最有信心的正确例排成最优“检错”结果。论文对正类或阈值的叙述互相冲突时，保留各自定义，不能从图例缩写代为决定。

<a id="k05-04"></a>
## 04 MCC：固定阈值下的二元关联

`MCC=(TP·TN−FP·FN)/√[(TP+FP)(TP+FN)(TN+FP)(TN+FN)]`。保留四格计数与正类定义，范围−1至1；0代表该二元关联量为0，不直接等于所有意义的随机表现。某边际只有一个类别时分母为0，应明确数学未定义及软件返回约定，不能伪造可解释的相关值。

MCC需要离散预测；阈值影响四格计数，与无阈值AUC不同。article_030后续MR把负MCC截为0，是另定义的变换，报告时保留原MCC。全为错误的子集没有两类，不能自行补算普通二元MCC。

## 05 Bradley–Terry拟合与谱排序

BT设每个对象强度θ_i，`P(i胜j)=exp(θ_i)/(exp(θ_i)+exp(θ_j))`。把成对胜数或声明的软胜权重W_ij代入`Σ_ij W_ij log P(i胜j)`并最大化；固定一个θ或中心化处理整体平移不识别。第225篇的W_ij是连续裁判偏好之和，第229篇从两局互换位置的比较结果出发，两者要分别记录权重来源。

考察无惩罚估计时，有正胜权重W_ij就从i向j画一条边。定好强度尺度后，唯一且有限的最优解要求该胜图强连通：从每项出发都能沿胜边到达其他每项。只看“比过”会漏掉整组始终压过另一组的情形，即使没有哪一个对象个人全胜也会分离。两组完全没比过时，组间强度差无法从数据确定；有跨组比较但胜负只朝一个方向时，推大两组强度差能持续提高目标。连续软权重仍按同一加权对数目标检查哪个方向权重大于零。先验、惩罚或人为加上的胜数若用于取得有限数值，应同时报告；它们改变了估计目标。[Hunter，第2节与假设1](https://doi.org/10.1214/aos/1079120141)

谱方法以比较图构造随机游走。例如Rank Centrality式构造令`P_ij=(j胜i的比例)/d_max`（有比较的i≠j），对角补到行和1，求平稳分布`πᵀP=πᵀ`，按π排强度。若胜率确为BTL且比较充分，详细平衡把平稳质量连到潜在强度；有限样本、断连或不可约性不足会改变可识别性与稳定性。它与直接最大似然不是同一求解器。

article_087只报告BTL spectral ranking；上述给出可操作的常见构造，不声称论文采用了未报告的转移矩阵、平滑或迭代容差。拟合单一强度不能表达所有循环偏好，也不证明跨任务能力单维。[成对比较的BTL、迭代谱排名与估计接口](https://choix.lum.li/en/latest/)。

## 06 Elo更新、量尺换算与Swiss配对

常用Elo预期胜率`E_A=1/[1+10^((R_B−R_A)/400)]`，实际得分S为胜1、平0.5、负0，逐场更新`R_A←R_A+K(S−E_A)`。同场双方应从同一赛前评分计算预期；初值、K、场次顺序和赛程影响结果。article_017用初值1500、K=20，是其配置而非必要通则。

该量尺下100分差对应约0.640的胜率。若从BT的自然对数强度转换，可用`R_i=(400/ln10)θ_i+C`；C只确定显示基点。批量BT或BayesElo评级不等于已经逐场执行上述更新。article_179的Oracle比赛及其胜率解释仍受评判者、对手和任务集合限定，不能写成人类竞赛胜率。

Swiss是赛程：每轮按累计分把分数相近者配对，取得判胜并更新分数，重复规定轮数后排名。若当轮参赛项数为奇数，事先说明如何安排轮空；同时约定重赛回避、平局和同分破同分办法；这些未报告时保留未知。article_154每胜加1、运行5轮，并用外部review分差选择轮数。有限轮次的Swiss累计分不是BT强度，也不保证所有候选两两比较或全序唯一。

## 07 ARI：两个分区是否把相同对象放在一起

在完全相同的对象集合上建立分区交叉表n_ij，行和a_i、列和b_j、总数n。令`I=Σ_ij C(n_ij,2)`，`A=Σ_i C(a_i,2)`，`B=Σ_j C(b_j,2)`，机会参照`E=AB/C(n,2)`，则`ARI=(I−E)/[½(A+B)−E]`。

该机会修正固定分区大小；1表示两分区一致而不要求类别名称相同，0约为此机会参照，负值可出现。单对象或退化分区须按明确实现处理零分母；噪声点是否计入同一簇也影响结果。article_032以Leiden分区作参照，ARI=1只表示匹配这个分区，不证明它是唯一真实社区。构造参照分区见[K09](K09_structure_geometry.md#k09-14)。
