# 机器行为研究组件手册

**融合定稿 · 2026年11月25日**

本手册用于设计、执行、分析和阅读机器行为实验。65项组件保留通用实验方法的骨架，把开发文献中提炼的方法写进相应组件：既说明为什么用，也说明怎样操作、怎样计算，以及结果能够支持什么判断。所需操作均在本手册内；来源和逐项改动见[集中改动记录](CHANGES.md)。

## 怎样使用

围绕当前实验选用相关组件。先用A组定义变量和任务，用B、C组安排比较与控制，再按D、E、J组处理实际状态、偏差和模型接口，最后用F、G组确定测量解释、分析单位和推断。具体方法是可选工具，不要求每项研究执行全部组件或全部检验。

同一道题比较两个提示时，B2规定配对和状态重置，G1确定推断单位，A2规定输出怎样计分，F1完成配对差与区间，J19保留可复算材料。各条负责不同环节，共用算法在一个位置完整说明，通过手册内部链接连接。

机器行为是本手册的应用目标；人工可以参与评分，已有外部数据可以作参照，但不要求建立真人对照组。

## 阅读论文时的判定

每条的“核对与判定”给出该职责的判断要点。若需要沿用编码，先判断是否适用，再判断核心做法和完整性：**1**表示适用要求已正确、充分落实；**0.5**表示核心做法存在但有影响解释的缺项或缺陷；**0**表示证据表明核心做法缺失或明显错误；**NR**表示材料不足以判断；**NA**表示不适用。信息未报告不能自动记0，未使用本条列举的某一种算法也不自动扣分。

判定与证据出处分开：正文讲方法，具体论文做过什么仍以其事实和原文记录为准。来源是否核对、教材是否覆盖是不同问题，不能用一个状态代替另一个，也不能把本手册已有某项知识当成某篇论文已经正确实施。

## A 变量与任务定义

<a id="a1"></a>
### A1 自变量

自变量是研究中主动改变、用来比较结果的因素。先写明改变的对象、各条件的具体取值及分配单位，再列出保持一致的设置。例如比较“有反馈”和“无反馈”，应规定反馈的内容、出现时点和下一轮能否看到；只写“反馈组”还不能执行。自然存在的模型规模、版本或训练来源也可以作为比较变量，但它们同时带来的差异要保留在解释中。

机器实验可改变提示、材料、解码、工具权限、环境状态，也可在开放模型中临时改变内部张量。内部操作须定位到层、位置与坐标，明确改动后哪些计算继续执行。改变多个因素时，先决定研究的是整个方案，还是通过交叉条件拆开各部分。

<a id="a1-01"></a>
#### 连续嵌入输入与扰动

若接口允许直接传入嵌入，可对原嵌入X施加连续变化`X′=X+Δ`。说明Δ的分布或构造、幅度、作用位置、是否每次重新采样，以及padding和注意力掩码怎样保持。比较条件使用同一原始材料和相应随机结构。

这种操作改变实际进入模型的连续输入，不要求每个向量都能还原为合法token，也不意味着更新了模型权重。需要自然语言提示的任务不能把不可解码的向量自动算成可部署提示；应以接口和实验目的界定结论。

<a id="a1-02"></a>
#### 替换、消融与激活干预

一次内部干预需明确供体、受体、参考运行、层、hook位置、token坐标、变换和持续步数。先获得原运行，再在目标位置替换、置零、加噪、引导或投影，按约定重新计算下游；结束后移除hook，防止干预带入后续条件。

改变注意力logit后再softmax、在softmax后置零或打乱权重、直接改变残差是不同操作。下游重新计算还是保持部分值不变也需说明。恢复实验可以比较原始、破坏和恢复三次运行；同时给出原始效果，恢复比例的分母接近零时不作稳定比例解释。随机位置或等范数等对照只在它能排除本次解释的替代原因时使用，不要求每个实验机械套齐。

<a id="a1-03"></a>
#### 定向梯度干预与伪逆映射

设R为召回目标、C为观察输出，在固定输入x求`g=∇R(x)`，施加`x+αg`。α=0附近的局部变化率为`∇C(x)ᵀg`；用小步有限差分核对时保持g固定。若每步重新求梯度并优化，已经是另一种过程。

设词表读出矩阵E为V×d，目标logit变化为Δy，则最小二乘输入变化可取`δx=E⁺Δy`，实际线性读出变化为`EE⁺Δy`。EE⁺是可达空间上的投影，不一定等于单位阵；E满列秩时才有E⁺E=I_d。改变logit后可重新softmax；直接从概率中减去一个向量可能产生负值或总和不为一，不能未经处理称为有效概率干预。

<a id="a1-04"></a>
#### 旋转位置编码干预

需要改变RoPE位置作用而保持内容不变时，将位置旋转R_n替换为R_n*；若张量已旋转，可按相应约定使用`R_n* R_n⁻¹`转换。明确作用于Q、K还是两者，覆盖哪些层和跨度，以及已有缓存是否同步改变。

真实数组位置、token内容和掩码保持何种状态必须说清。只改旋转编码与真正交换序列位置是不同干预；它们改变的可见关系和注意力限制可能不同。

**核对与判定：** 能从条件定义还原实际操纵，条件间确有目标差异，且输出不是反过来决定分组，才算操作明确。操纵未产生预期成绩差异不等于自变量失败；但若接口忽略了参数或目标张量根本没改，须按实际执行解释。

<a id="a2"></a>
### A2 因变量

因变量是用来回答研究问题的可观察结果。先确定观察对象：一次回答、一题的多次回答、整局轨迹，还是模型内部某一位置的读数；随后给出计分方向、取值范围、分母、缺失和无效输出处理。正确率、概率、裁判评分、语义距离和内部激活分别测不同的东西，不能因都能输出数字而互换。

按题比较时保留题号和重复编号；文本评分保留原输出与参照；概率测量保留事件及条件前缀；内部测量保留张量位置。指标聚合顺序必须明确：先在题内平均再跨题平均，与把全部调用直接合并，在重复次数不同时权重不同。跨题计算的AUC等指标应在完整对应样本上重算。

<a id="a2-01"></a>
#### 二元预测的Tjur区分系数

二元预测的Tjur系数为`mean(p̂|y=1)−mean(p̂|y=0)`，需要两类都存在。它衡量区分程度，与OLS解释率、校准及准确率分别报告。

<a id="a2-02"></a>
#### 分布形状与密度展示

正态拟合需说明使用均值、方差的何种估计，以及是否适合当前分布。变异系数`CV=SD/mean`适用于有意义零点的比率尺度；均值为零或负值时普通相对离散解释失效，不宜跨异质量尺直接比较。

核密度估计`f̂(x)=1/(nh)ΣK((x−x_i)/h)`，带宽h控制平滑，边界与缺失处理影响形状。violin把密度映成两侧宽度，应注明各组按面积、最大宽度还是样本数缩放；图上的宽度不是新样本量。

距离偏斜的一种读数为`1−Σ_ij||x_i−x_j||/Σ_ij||x_i+x_j−2γ||`，以γ作为对称参照，固定纳入的配对与计数方式；分母为零时未定义。它描述相对于γ的不对称程度，不是带正负方向的第三矩偏度。参照点、距离和平均偏差应分别说明。

<a id="a2-03"></a>
#### 从独立判断到最终评分

确定评分单位、标签集合、判据、示例和难例处理，再在共同材料上校准理解。正式评分保留每位评分者或每个裁判配置的独立原始判断，之后再按多数票、讨论裁决或指定规则形成最终标签。记录缺失、平局、不可判定和裁决理由；不能先讨论出一致答案再据此计算独立一致率。

人工或模型评分都要绑定实际输入、尺度及版本。对生成者或条件身份实施遮蔽时用[C6](#c6)。同一模型换提示形成多个判断可能仍高度相关，不自动等于多名独立专家。最终评分负责给出因变量；一致性算法集中在[F3](#f3)，二者用途不同。

<a id="a2-04"></a>
#### 现成表征与语义相似

明确编码器和分词器版本、输入单位、上下文、mask、层及池化。词表向量、上下文词元、句向量和图文向量的空间不同；OOV、空输入和截断分别处理。均值池化通常只对有效token，不能将padding纳入。

余弦`cos(x,y)=xᵀy/(||x||||y||)`要求同一坐标且两向量非零；余弦距离常取1−cos，零向量按事先规则处置。点积还包含模长，不能当作已归一余弦。句内先匹配、跨参照取最大或平均、跨题再平均，会产生不同指标。

给每个候选绑定参照和聚合方式，阈值由所用表征与校准材料确定。相似高支持特定表示下的接近，不保证事实正确、逻辑等价或新颖；更换编码器后不能无依据沿用旧阈值。

<a id="a2-05"></a>
#### 连续片段与公共子序列

先选择比较单位是字符、词还是token。最长共享连续片段可用动态规划：相等时`D[i,j]=D[i−1,j−1]+1`，不等时置0，取全表最大；它要求片段内部相邻。

最长公共子序列LCS允许跳过元素但保持顺序：相等时取对角+1，不等时取`max(D[i−1,j],D[i,j−1])`，最终为D[m,n]。长度归一要说明分母是候选、参照还是二者的组合。两种算法不能因都叫“最长匹配”而混用；空序列和重复词的对应规则也应固定。

<a id="a2-06"></a>
#### 带类型跨度评分

每条候选和金标写成起点、终点、类型，并统一端点包含规则及字符/token坐标。精确匹配要求边界和类型均相同，建立一对一匹配后计TP；多余候选计FP，未匹配金标计FN。

重叠、嵌套和重复候选按协议处理，同一个金标不能被多个预测重复计TP。若采用部分重叠匹配，另定义阈值和最大匹配规则，并作为不同指标报告。Precision、Recall和F1的零分母规则预先确定。

<a id="a2-07"></a>
#### 字词重合评分

BLEU按阶n统计候选n-gram，将计数裁到参照中允许的最大计数，得精确率p_n；`BLEU=BP·exp(Σw_n ln p_n)`，候选长c、有效参照长r时，c>r取BP=1，否则`exp(1−r/c)`。零匹配、空候选、平滑及多参照选长规则要明确。语料级先合并计数，不等于句级BLEU平均。

ROUGE-L以LCS长度L给`P=L/候选长`、`R=L/参照长`，`Fβ=(1+β²)PR/(β²P+R)`；摘要级跨句并集等变体另标。chrF++分别在字符和词n-gram上计算匹配精确/召回，按指定阶数平均后形成加权F；空格、大小写、词边界与β均影响结果。

METEOR按选定的精确、词形或同义匹配建立对齐，得P/R及加权调和分，再按对齐片段数ch和匹配数m施加如`penalty=γ(ch/m)^δ`的片段惩罚；参数、语言资源与对齐策略必须对应。上述指标衡量各自定义的重合，不能单独证明事实忠实。

<a id="a2-08"></a>
#### 上下文语义评分器

BERTScore以候选和参照上下文token的相似矩阵为输入。候选每个token取最大参照相似再加权平均得到P，反向得到R，最后组合F1；说明编码器层、IDF权重、特殊token及baseline rescaling。最大匹配并不强制一对一，词元重复可能影响含义。

SimCSE类评分固定现成编码器和实际相似度，把同题候选与参照配对；BLEURT给学习式连续质量分，不能直接当作人工评分的原量尺，额外线性标定须用独立材料。UniEval按具体维度提供所需源文、候选和参照，保留维度分数及聚合；流畅、可懂和事实忠实不是同一判据。评分器训练不在本组件的调用步骤中。

<a id="a2-09"></a>
#### 无人工摘要参照的评分

BLANC-help在同一源文及相同mask位置上，比较不提供摘要与提供摘要时的词预测正确率，按明确分母计算增益。BLANC-tune则先用摘要作指定适配再比较，不能称为仅改变上下文的同一操作。mask抽样、可评分位置和基线须匹配，增益衡量对该恢复任务的帮助。

SUPERT先按规定的句选择、位置或权重从长源文形成伪参照，再与摘要做token语义匹配和P/R/F归约。伪参照的内容和截断会影响覆盖；与直接使用人工参照的BERTScore不同。无参照不等于无外部模型或没有选择假设。

<a id="a2-10"></a>
#### 词频倾向与情绪词典

比较两语料的词倾向时，固定共同词表和计数单位。Dirichlet先验计数α_w、总量α0下，单语料log-odds为`ln[(c_w+α_w)/(N+α0−c_w−α_w)]`；两语料相减得到δ_w，常见近似方差为`1/(c_1w+α_w)+1/(c_2w+α_w)`，以δ除SE标准化。先验来源、稀有词和平行文本依赖会影响解释。

情绪词典需指定词项极性/强度、否定与程度组合、文本归约及阈值。VADER的compound、各类比例与TextBlob的polarity等不是同一尺度；按阈值分正负也不自动识别讽刺、意图或真实情绪。更换语言或词典版本后需核对适用性。

<a id="a2-11"></a>
#### 可读性与年级量尺

使用前先说明句、词、字符、音节和复杂词如何计数。英语常见量尺为：Flesch Reading Ease=`206.835−1.015(W/S)−84.6(Sy/W)`；Flesch–Kincaid Grade=`0.39(W/S)+11.8(Sy/W)−15.59`；ARI=`4.71(C/W)+0.5(W/S)−21.43`；Fog=`0.4[W/S+100·复杂词数/W]`。复杂词通常涉及多音节并有具体例外，采用实现的规则须明确。

Reading Ease高通常更易读，Grade高表示更高年级，方向不能混用。空文本、分句失败和非英语输入不宜直接套这些系数。年级共识须列出所组合的量尺、从非年级量尺到年级的转换及投票/平均规则，不能凭函数名猜默认成员。这些是文本特征指标，不等于模型真正理解难度。

<a id="a2-12"></a>
#### 概率读数与预测位置

先定义事件和概率来源：原始logit、归一概率、logprob、重复生成频率、候选内条件概率和模型自报信心不同。logit经`p_i=exp(z_i)/Σexp(z_j)`归一；logprob依对应底数指数还原。只在候选集S内归一时`q_i=p_i/Σ_(j∈S)p_j`，同时保留原候选总质量，不能将q当完整词表概率。

按模型架构定位：decoder在给定前缀的下一位置预测；encoder从被mask位置读出；encoder–decoder按源输入与实际decoder目标前缀定位sentinel和目标token。核对候选文字在真实上下文中的token身份、空格和特殊符号。多token候选依各步真实前缀取条件概率，不能只取首词元；目标读数与提示本身的概率分开。

<a id="a2-13"></a>
#### 截断概率与偏置接口

接口若确实返回最高K个原始概率，其和为S，未返词元的概率同时受剩余质量和最小已返值限制，即`p_missing≤min(1−S,p_Kmin)`。这是上界而非真实值；把所有缺项赋此上界会改变分布，也可能使总和超过1。若接口返回的是其他候选集合，该top-K界不一定成立。

运行时logit bias改变原分布。比较时记录偏置位置、大小、被改变候选及是否有完整归一信息；不能把偏置后读到的尾部概率说成未偏置概率。假定剩余质量均匀分给未见词元须声明支持集及假设。截断后再归一与除以最大可能熵是不同变换，两者均不能恢复未知完整分布。

<a id="a2-14"></a>
#### 参照引导的候选排名

取得指定预测位置的token排名后，可按参考词的前缀继续评分或续写，将完成的目标词映回起始候选的秩。保存参考文字、各步分词、续写条件、完整匹配规则及未匹配处置。

这种流程利用了参照来限定可检索候选，结果表示该限定过程中的排名；不等于模型无参照自由生成了完整词，也不等于整个词的联合概率排名。多token和同前缀候选尤需区分。

<a id="a2-15"></a>
#### 熵、有效类别与集中度

对固定支持集上的归一概率，`H=−Σp_i log p_i`，约定0log0=0并说明底数。以相同底数取指数得到有效类别数，例如自然log下exp(H)；除以log K得到的归一熵需K>1，不能与概率本身混淆。

若先把解释评分经softmax转成权重，熵依赖评分尺度与温度，未必代表真实事件概率。熵差H(P)−H(Q)只比较分散程度，相等熵不表示相同分布；它不是KL“相对熵”。

Gini–Simpson为`1−Σp_i²`，是两次独立有放回抽取不同类型的概率。有限计数无放回版本为`1−Σn_i(n_i−1)/[N(N−1)]`，N>1时才定义。类型数、Shannon熵和该二次集中度分别报告；低不确定性也可能对应稳定重复错误。

<a id="a2-16"></a>
#### 分布差异、交叉熵与关联

共同事件空间上，`KL(P||Q)=Σp ln(p/q)`；p>0而q=0时可无穷。平滑改变比较对象，应记录。以m=λp+(1−λ)q，`JS=λKL(p||m)+(1−λ)KL(q||m)`；等权、log2时JS在0—1，JS distance通常指其平方根。

逐类别JS贡献由两项对应加权log比之和组成，可定位哪些词改变分布；贡献高不等于词频高。交叉熵`H(P,Q)=−Σp ln q=H(P)+KL(P||Q)`，方向及符号要固定，对称化交叉熵不是JS。点式互信息`PMI(a,b)=ln[P(a,b)/(P(a)P(b))]`度量该事件对相对独立基准的关联，正负与零概率边界分别解释，平均PMI也不证明全部依赖结构。

<a id="a2-17"></a>
#### 运输距离

Wasserstein先定义支持位置、概率质量及ground cost。离散p阶距离为`W_p=[min_π Σ_ij π_ij d(x_i,y_j)^p]^(1/p)`，约束π的行和、列和为两边质量。位置、单位及p改变结果；把概率向量的元素值直接当空间坐标是另一问题。

一维有序共同支持可由CDF差计算W1，离散时按相邻位置间距加权。距离本身非负，图上额外标方向的正负号不是Wasserstein定义的一部分；缺乏有意义类别距离时不能随意给类别编号后解释运输大小。

<a id="a2-18"></a>
#### 从列表排序估计候选分布

对同题候选集合去重，保留每次列表中的比较方向及权重。用参数θ并令`p_i=softmax(θ)_i`，成对偏好概率为`p_i/(p_i+p_j)`；最大化观察方向的加权log似然得到题内相对分布。来自同一列表的成对项相关，目标函数写成求和不使它们成为独立观测。

候选集合外的概率未知，这不是更新LLM权重。强度整体平移不识别，固定一个值或中心化；有限无惩罚解的胜图条件及惩罚影响见下文的成对排名。拟合失败或比较不足不能用默认均匀分布冒充结果。

<a id="a2-19"></a>
#### 主张条件概率与语义熵

Claim-Conditioned Probability在主张的词位置构造替代词及其上下文版本，使用NLI分为蕴涵e、矛盾c和无关n；`CCP_word=Σ_e P(替代词|前缀)/Σ_(e或c)P(替代词|前缀)`。原方法把功能词置1，以`1−∏_词 CCP_word`形成主张不确定性。保存词到token对齐、候选截断、零分母和抽取失败；乘积评分不自动证明各词正确独立或整句概率已校准。后续跨主张平均和设阈值另行定义。

语义熵从同一问题的多个答案出发，以双向蕴涵等规则形成语义类，按声明的采样或概率质量估计类概率，再算类熵。近似蕴涵不一定传递，须确定聚类算法和顺序；采样频数与截断概率重归一也不同。主张经多个问句生成答案时保留主张—问句—答案—类的对应。低熵可能是共同犯错，事实准确另测。

<a id="a2-20"></a>
#### 联合正确与首次成功

步骤联合正确概率为`∏_t P(第t步正确|此前均正确)`。边际信心直接连乘额外需要独立性；模型自报overall和程序重算乘积须区分，百分数先转为0—1。

若c_t定义为此前未发生时第t次发生的条件概率，首次事件质量为`b_t=c_t∏_(i<t)(1−c_i)`，截止T仍未发生为`∏_(i≤T)(1−c_i)`。令正确指示g_t，则截至t已正确发生的概率`C_t=Σ_(e≤t)b_e g_e`。总质量通常需包括未发生项，不能无说明把最后c强制改为1。

与外部累计进度参照h_t合成奖励时，若采用`R=Σ_t h_t C_t+(1−Σ_t h_t)C_T`，须保留其代数定义。累计比例跨时点相加可超过1，剩余权重不能直接解释为尚未成功的比例；改用首次成功比例会成为另一指标。

N个候选中s个成功，均匀无放回试到首次成功时，s≥1有`P(T=t)=C(N−t,s−1)/C(N,s)`及`E T=(N+1)/(s+1)`。s=0无成功时刻，可另定义耗尽成本N；有放回或自适应选择不适用此式。

<a id="a2-21"></a>
#### 后验位置与绝对误差

Beta(α,β)后验中点估计q的累计位置为正则化不完全Beta函数`F(q)=I_q(α,β)`。它表示后验质量中有多少在q以下，区别于q和后验均值的绝对距离，也不是该点错误的概率或频率学p值。

需要汇总绝对正态误差时用[F1的误差传播](#f1-error-propagation)中折叠正态矩，保留各对象相关和估计精度。后验位置、绝对误差、可信区间分别回答不同问题。

<a id="a2-22"></a>
#### 概率校准与可靠性图

二元事件Y与预测p的条件校准目标为`P(Y=1|p)=p`。把p分箱B，固定边界包含规则，计算箱内平均概率c_b、实际正例频率a_b和数量n_b；画(c_b,a_b)并显示样本数。空箱不虚构正确率，加权贡献为零。

绝对型误差为`Σ(n_b/N)|a_b−c_b|`，平方型为`Σ(n_b/N)(a_b−c_b)²`，后者不等于逐样本Brier均方误差。分箱会使同箱高估、低估相互抵消，等宽、等频或log分箱分辨率不同。报告边界、数量、零概率处理和损失定义；仅平均信心等于总正确率或Brier下降，不足以证明条件校准更好。

<a id="a2-23"></a>
#### 多类别校准

top-label用每题最高概率与“最高类别是否正确”分箱，只检查获选类别；classwise对每个类别k，用全部p_ik与`1(Y_i=k)`分箱，再按明确类别权重平均。类别等权是宏平均，按样本加权是另一目标。

稀有类的大量低概率项可能主导结果；记录每类样本、箱数、权重和置信来源。按−log₂p等距分箱时另定p=0及有限上界，不从绘图坐标猜边界。概率校准与输出等级偏好属于不同层面。

<a id="a2-24"></a>
#### 区分能力与检索排名

固定正类和分数方向，扫描阈值形成`TPR=TP/(TP+FN)`、`FPR=FP/(FP+TN)`的ROC。AUC等于随机正例分数大于随机负例的概率加并列一半，需要两类都有样本。严格递增变换通常不改AUC，因此它不证明概率校准。

PR画Recall与`Precision=TP/(TP+FP)`，基率影响精确率及基线；无预测正例端点按所用规则处理。以错误为正类时，原“正确信心”也要改为相应反方向。非插值`AP=Σ(R_n−R_(n−1))P_n`不同于梯形PR面积，并列分数同阈值处理。

无并列检索排名可用`AP=(1/R)Σ_r Precision@r·relevant(r)`，说明相关总数、截断和R=0。多标签mAP先逐标签AP再按规则平均。若把参考排名前i项依次作为相关集、对多个i平均AP，则是在评价参考内部次序；不能换成一次top-k集合AP。

<a id="a2-25"></a>
#### 阈值分类与MCC

保留固定阈值下的四格计数，`MCC=(TP·TN−FP·FN)/√[(TP+FP)(TP+FN)(TN+FP)(TN+FN)]`。方向与正类定义一致，范围−1至1；0只表示该关联量为0，不等于所有意义的随机。

任一边际只有一类时分母为零，须说明数学未定义及实际软件约定。将负值截零或再作其他变换是新指标，原值应保留。MCC依赖离散阈值，不能代替无阈值排序AUC。

<a id="a2-26"></a>
#### 成对比较的潜在排名

Bradley–Terry令`P(i胜j)=expθ_i/(expθ_i+expθ_j)`，对胜数或明示软胜权重W_ij最大化`ΣW_ij ln P(i胜j)`。固定基准强度或中心化消除平移不识别。胜图以正W_ij形成i→j；有限且唯一的无惩罚解要求强连通。组间从未比较不可定相对尺度，组间胜负单向则可能分离；先验、惩罚或添胜数会改变估计目标。

谱方法可令有比较的`P_ij=(j胜i比例)/d_max`，对角补足行和1，再求`πᵀP=πᵀ`按π排名。保存比较图、转移定义、连通和求解状态；它与直接BT最大似然不同。单一强度无法完整表达循环偏好，排名范围受任务和对手集合限定。

<a id="a2-27"></a>
#### Elo量尺与Swiss赛程

常见Elo预期`E_A=1/[1+10^((R_B−R_A)/400)]`，结果S取胜1、平0.5、负0，更新`R_A←R_A+K(S−E_A)`。双方用同一赛前评分计算预期，保留初值、K、次序和赛程。该量尺下100分差约为0.640胜率；由BT自然log强度换算可用`R=(400/ln10)θ+C`，不代表已经逐场执行Elo更新。

Swiss按当前累计分将相近者配对，运行规定轮数后排名；事先定义轮空、避免重赛、平局和同分处理。有限轮次不覆盖所有对手，累计分不是BT强度。自适应选择近强度对手的逐轮程序另见[J20](#j20)。

<a id="a2-28"></a>
#### 分区一致性ARI

在完全相同的对象上建立两分区交叉表n_ij，行和a_i、列和b_j。令`I=ΣC(n_ij,2)`、`A=ΣC(a_i,2)`、`B=ΣC(b_j,2)`、`E=AB/C(n,2)`，则`ARI=(I−E)/[½(A+B)−E]`。

机会参照固定分区大小。ARI=1表示同样分组而不要求标签名相同，负值可出现；单对象、退化分区及噪声点的处理要固定。匹配某算法分区只说明与该参照一致，不证明其是真实类别。

<a id="a2-29"></a>
#### 辨别敏感性与置信阈值

等方差SDT以两类潜在量`N(−d′/2,1)`与`N(d′/2,1)`、决策准则c0形成响应，`d′=Φ⁻¹(H)−Φ⁻¹(F)`，`c0=−[Φ⁻¹(H)+Φ⁻¹(F)]/2`。该参数化中似然比准则`β=exp(d′c0)`，与c0不同。命中/误报率为0或1时需预定校正或明确不可估；裁剪及取|d′|会分别限制极端值、抹去反向辨别，另标指标。

MetaSDT在两个响应半轴增加有序置信阈值。真类s、响应r下区间[l,u]的条件概率为`[Φ(u−μ_s)−Φ(l−μ_s)]/P(r|s)`，外尾为±∞；每个真类×响应行和为1，经验4×k计数按行归一。

拟合明确哪些参数固定、哪些估计，保留阈值次序、损失方向和不可行处置。若约束各响应内正确率随置信递增，要用该响应下真类频数乘条件概率再归一。行为阈值拟合不是对LLM内部正态变量的直接测量。

<a id="a2-30"></a>
#### 联盟贡献

定义参与者集合N、每个联盟S的价值v(S)，包括空联盟与成员缺席时的替代规则。Shapley贡献为`φ_i=Σ_(S⊆N\{i})[|S|!(n−|S|−1)!/n!]·[v(S∪{i})−v(S)]`，也可对加入顺序的边际贡献平均。

精确枚举满足`Σφ_i=v(N)−v(∅)`；采样排列须保持同一价值定义，报告蒙特卡洛误差。价值由另一模型估计时结论也依赖该模型。近似算法不自动严格守恒；贡献分数转为真实支付还需协商与可行约束，见[J20](#j20)。

<a id="a2-31"></a>
#### 读取激活、注意力与内部张量

先固定模型、分词器和运行模式，再指定读取的张量位置：残差流在模块之前还是之后，注意力的Q/K/V或权重，FFN非线性前还是后的输出。记录各轴的含义，如批次、token、隐藏维度、头、query位置和key位置，并核对掩码、padding及实际非填充位置。

最后一个词、最后一个子词和最后一个有效token不一定相同。自由生成与给定答案的teacher forcing具有不同历史，读取结果不能混在一起。注意力对目标区域的总质量与在该区域内重新归一化的分布回答不同问题；正激活次数和激活频率也要使用实际纳入token数作为分母。先核对形状和位置，再解释数值。

<a id="a2-32"></a>
#### 梯度归因与积分梯度

先定义标量目标F，例如指定答案的对数概率、logit或损失，并固定输出和上下文。梯度对可微的嵌入或内部张量求导，不对整数token编号求导。输入乘梯度可写为x⊙∇F(x)；使用符号、绝对值、维度求和或范数会产生不同读数，需在比较前固定。

积分梯度以参考输入x′和路径为条件：`IG_i=(x_i−x′_i)∫₀¹ ∂F(x′+α(x−x′))/∂x_i dα`。记录参考、积分步数及数值求积方式；在未经绝对值或范数转换前，检查各维之和是否近似F(x)−F(x′)。对注意力等内部量归因同样要定义目标；若目标为KL散度，应明确两分布、方向及参考。梯度描述局部敏感性，不能直接替代实际干预效果。

<a id="a2-33"></a>
#### 基于检查点梯度的训练样本影响

TracIn式分数把训练样本z与目标样本t在多个检查点的损失梯度内积相加：`I(z,t)=Σ_c η_c ∇θL(z;θ_c)ᵀ∇θL(t;θ_c)`。使用相同的损失定义、参数子集、序列与批次归一化，记录检查点和学习率或其他权重。

在小步梯度下降的近似下，正内积表示沿z的下降方向有助于降低t的损失。分数依赖所取训练轨迹和目标，不能解释为删除该文档并重新训练后的真实因果差异。目标是某个token、整句还是整个任务时，必须分别定义损失范围。

<a id="a2-34"></a>
#### 将内部表征投到词表

先说明读出对象是残差状态、单个头的输出、某个更新量还是值向量，再使用对应模型的归一化、unembedding和偏置得到词表logit，按需要计算softmax或排名。使用输入嵌入做近邻检索属于另一种相似性读数，应单独命名。

中间层或单个更新量的词表投影只是该读出方式下的解释，不能当作模型当时实际生成的词。层归一化是非线性的，分别读出多个增量再相加通常不等于读出总和。若另行训练探针，应按探针的训练和验证规则处理，不能与固定读出混用。

<a id="a2-35"></a>
#### 对比方向、固定坐标轴与子空间投影

使用同一题目或匹配条件的表示差构造方向，例如`d=mean(h⁺−h⁻)`，固定层、位置和配对关系。需要单位方向时先检查非零范数，再令u=d/||d||。沿u读取hᵀu或去掉该方向`h−uuᵀh`，分别是测量和操作；实际干预见[A1](#a1)。

多方向组成矩阵U时，投影可写为`UU⁺h`，移除为`h−UU⁺h`；只有方向正交归一时才能直接用`UUᵀ`。逐个移除非正交方向可能依赖顺序。同一固定方向用于多层与各层单独拟合方向具有不同含义；跨模型或检查点还要确认坐标系是否可比。

<a id="a2-36"></a>
#### Key向量邻接图

从固定层、头和窗口取得key向量，按定义构图，例如`A_ij=k_iᵀk_j`。说明是否缩放、是否对称化、是否保留自环、负边怎样处理以及后续是否归一化；图节点必须能对应原token位置。

Key之间的内积图描述key空间关系，不是query与key经过softmax得到的注意力矩阵。下游图算法若要求非负权重，应明确转换并解释它改变了什么，不能直接把不满足条件的邻接矩阵送入算法。

<a id="a2-37"></a>
#### 矩阵组合与稀疏自编码器读数

分析模块间静态组合时，先统一行列约定及维度，把上游写入映射与下游Q/K/V等读取映射按实际顺序相乘。一种归一化组合分数为`||W₁W₂||_F/(||W₁||_F||W₂||_F)`，零范数需单独处理。若只取某个SVD秩一项，说明选择规则，并与所声称的完整映射区别开。静态组合强度不能替代运行时干预。

使用已有稀疏自编码器时，绑定其模型、层、归一化和尺度。按实际编码器计算特征，例如`f=activation(W_enc(h−b_dec)+b_enc)`，同时查看重建误差。特征激活、解码方向和后来训练的预测回归是不同产物；不能把回归拟合结果当成自编码器自身的解释。

<a id="a2-38"></a>
#### 权重与输入共同决定的重要性

对线性映射WH，单独删除连接w_ij造成第i个输出在样本上的变化为`w_ij H_j,:`，其二范数为`|w_ij| ||H_j,:||₂`。Wanda式分数据此同时使用权重幅度和输入激活规模；激活范数沿样本或token轴计算，再对应广播到权重列。

若只使用一个位置，该项退化为`|w_ij| |h_j|`，不能用整条隐藏向量的范数替代每个输入维度。说明跨样本和跨层怎样汇总。单连接近似没有包含同时删除多连接时的交叉作用，重要性排序也不表示已经实际执行剪枝或得到了全局最优删除方案。

<a id="a2-39"></a>
#### 多维尺度分析

先明确如何由相似度得到距离D，检查对称性、非负性、对角线和缺失值。度量MDS拟合所选距离的stress；非度量MDS主要保持次序并拟合单调差异；经典MDS计算`B=−(1/2)J(D∘D)J`，由选取的正特征值及特征向量构造坐标。

报告维数、初始化、重复拟合和拟合误差。低维位置允许旋转或镜像，坐标轴不能未经额外依据直接命名为心理维度。原距离无法被低维空间准确表达时，应保留这一失真，不能只展示清晰图形就认定结构成立。

<a id="a2-40"></a>
#### t-SNE与UMAP表示

t-SNE根据高维局部邻域概率和低维Student分布优化KL目标；记录perplexity、距离、学习参数和随机种子。UMAP根据邻域图构造模糊关系并优化低维表示，至少明确邻居数、距离和min_dist。两者的显示结果都依赖参数及拟合对象。

这些方法主要强调局部结构，图上远距离和空白区域不能直接解释为原空间的全局间隔。区分降维仅用于展示、用于聚类还是进入正式指标计算；若指标定义在原表示上，就不能改在二维图上测量。对新样本使用何种变换或重新拟合也要说明。

<a id="a2-41"></a>
#### PCA、SVD与低秩读数

PCA先在指定拟合数据上确定均值及必要的尺度，再对中心化矩阵`X=UΣVᵀ`分解，得分为XV，协方差特征值为`σ_i²/(n−1)`。解释方差比例使用所定义的全部方差作分母。新数据应使用同一均值、尺度和轴；若重新拟合，已改变比较坐标。

一般SVD不必中心化。取秩一项时同时保留左右向量各自所属空间，能量比例可用`σ_i²/Σ_jσ_j²`，不能与奇异值比例混用。对数展示处理零值，且只有量的定义确为方差时才称“解释方差”。

<a id="a2-42"></a>
#### 带共同项约束的低秩分解

对于d×L矩阵M，可拟合`M≈a1ᵀ+SΓᵀ`并要求`aᵀS=0`，以区分共同方向和低秩变化。明确目标为Frobenius误差、秩r及轴约定；共同项的初始列均值为`M1/L`。先对去除共同项的残差取秩r近似，再组成暂定重建M̃。

一种校正形式令`z=(M̃⁺)ᵀ1`，在z非零且相应行空间条件成立时取`a=z/||z||²`，然后对`M̃−a1ᵀ`再作秩r分解。奇异值吸收到S还是Γ都可以，但乘积必须重建相同矩阵；检查残差及正交约束。若条件不满足，应直接处理约束优化或说明失败，不能把伪逆公式当作任意矩阵都成立的恒等式。

<a id="a2-43"></a>
#### 距离、核相似性与序列几何

欧氏距离、余弦和内积分别保留不同信息：归一化后的方向比较去掉了幅度，原始内积同时受到范数影响。RBF核`exp(−||x−y||²/(2ℓ²))`依赖带宽及输入尺度，需说明如何确定；历史表示均值还要明确时间和样本权重。

Hamming距离计算对齐坐标的不同数。若用内积近似`−aD_H+b`，应检查表示编码、尺度和自内积b是否符合构造，不能默认所有向量为单位向量。成对距离共享样本会产生依赖；阈值只在选定表示和用途下解释，不存在可以通用于所有模型的相似性界线。

<a id="a2-44"></a>
#### 协方差、子空间与Procrustes对齐

区分样本协方差的1/(n−1)与经验总体协方差的1/n。整体缩放c会使迹变为c²倍、d维行列式变为c^(2d)倍；秩不足时行列式为零。沿单位方向u的方差为`uᵀSu`，跨条件比较应保持表示、缩放及PCA轴定义一致。

子空间主夹角由正交基`Q₁ᵀQ₂`的奇异值σ得到`arccos(σ)`，数值误差可裁到[0,1]。最小夹角为零只说明至少共享一个方向，不表示整个子空间相同。Procrustes对齐先匹配同一对象，按需要中心化X、Y，再对`XᵀY=UΣVᵀ`取`R=UVᵀ`；禁止镜像时修正行列式符号。是否允许尺度和平移单独决定，使用的库函数不一定自动中心化。

<a id="a2-45"></a>
#### 图编辑距离

先定义节点、边及属性，规定插入、删除、替换和匹配代价，再求将一张图变成另一张图的最小总成本。说明是否有向、标签如何匹配及空图处理。节点映射事先已知时直接计算差异，只是该映射下的距离，不能假定等于所有映射上的最小值。

带时间限制或启发式算法返回的可能是上界或近似值，需保留求解状态。节点F1、边F1和编辑距离衡量不同错误结构，不能仅因都用于图比较就互相替代。

<a id="a2-46"></a>
#### 音频强制对齐与动态时间规整

强制对齐以录音、已知转写和声学语言模型估计词的起止时刻，它不等于自动识别录音内容。检查采样率、停顿、填充词和缺漏转写；将词时间均分给子词只是近似，必须与模型token对应关系一致。

比较两个长度不同的序列可用DTW：以选定局部距离，按三个允许前驱累积最小代价，固定起止边界、窗口和路径长度归一化。FastDTW等近似实现与精确最优路径有区别。生成序列发生插入或删除时，直接按相同索引比较通常失去对应，需先说明对齐依据。

<a id="a2-47"></a>
#### 平滑、峰值与事件读数

高斯平滑需给出核宽度的单位、采样间隔、归一化和边界处理；一维时间序列与二维空间图分开设定。插值用于显示时不会增加真实观察数，缺失区域也不能未经说明当成零。

峰值检测明确阈值或百分位、最小间隔、相邻峰合并及保留最大峰规则，保留原信号、平滑结果和被剔除峰的关系。已有真人按钮等信号可以作为外部参照，但不属于机器自身生成事件。参数应服从实际信号和测量目的，不能因为同叫“峰值检测”就跨数据直接复用。

**核对与判定：** 原始输出能按公开规则得到分数，分数方向与问题一致，失败样本有去处。因变量不必随处理变化，零差异是有效结果。客观可计算也不等于构念有效；需要解释“推理”“记忆”等能力时，接用[F3](#f3)。

<a id="a3"></a>
### A3 控制变量

控制变量是本次不打算研究、但可能影响结果的条件。根据比较列出模型版本、系统提示、题目、上下文、工具、解码、预算、裁判与运行时段，区分已固定、已匹配、已随机分散和只能记录的条件。不要把本次自变量也要求固定。

固定的是模型实际收到和执行的配置，而不只是请求参数。不同模型不支持相同选项时，记录各自有效配置及可比范围；服务端版本未知时保留接口日期和可见标识。同一随机种子不保证跨模型得到相同随机过程。

**核对与判定：** 能说明关键非目标条件如何处理，并检查它们是否与实验条件共同变化。这里负责识别要控制什么；具体恒定操作见[C3](#c3)，不能控制且可能改变归因的部分见[A4](#a4)。

<a id="a4"></a>
### A4 混淆变量

当目标条件与另一个足以影响结果的因素一起变化，就可能产生混淆。例如长推理提示比短提示多了答案线索，成绩差不能直接归为“推理更长”。先列出实际存在的替代解释，再用只改变目标成分的对照、匹配或因子设计分离；无法分离时，把结论限定为整个条件组合的差异。

观察性模型比较也要做这项判断。版本、规模和数据来源经常同时变化，仅在回归中加入几个变量不能保证消除所有混淆。选控制变量前先明确处理与结果的关系；估计总效应时，不应无意中控制由处理产生的中介或筛选条件。

**核对与判定：** 关键替代解释得到有针对性的处理，或在结论中保留了实质限制。因果调整的识别条件和具体计算统一见[F2](#f2)，不要求每个描述性实验都建立完整因果模型。

<a id="a5"></a>
### A5 调节变量

调节变量回答“一个因素的作用在什么条件下更强或更弱”。先确定调节因素及尺度，计算各水平内的处理效应，再直接比较这些效应。例如分别在简单题和复杂题中计算提示改动的准确率差，再估计两种差的差。

可用包含处理、调节因素及其交互项的模型；连续变量的中心化有助解释截距，但不是调节成立的条件。调节因素若是既有模型属性，应检查伴随的版本、数据和接口差异。分组阈值和比较方向尽量在看结果前确定。

**核对与判定：** 证据来自效应差异本身及其不确定性。一个组显著、另一个不显著不足以证明调节。交互的计算与概率尺度解释见[B6](#b6)。

<a id="a6"></a>
### A6 中介变量

中介分析研究处理如何经一个中间量影响最终结果。先定义处理X、中间量M、结果Y，说明M在何时、怎样被测量或干预。模型生成的解释文本是可观察输出，不能直接当作全部内部推理过程；内部激活能被读取也不自动证明它承担因果中介作用。

在线性且相应假设成立的模型中，可拟合M对X的路径a及Y对X、M的路径b，以ab表示间接路径；不同链接或有交互时不能照搬“总效应减直接效应等于ab”。观测中介还需处理处理—中介、中介—结果的混淆。通过内部干预研究路径时，采用[A1](#a1)的供受体与对照操作，并明确干预是否同时改变其他量。

<a id="a6-01"></a>
#### 可观测代理与必要、充分性

替代不可观测跨世界量时，先说明目标、代理及可比性假设，再报告偏差来源。例如以输出相对原答是否变化定义总效应TE和代理间接效应AICE，令`ADCE=TE−AICE`，得到的是该变化判据下的分解，不是新答案正确率，也不是无条件的机制识别。

二元处理结果在单调性等识别条件、数据来源一致且分母为正时，可估`PN=[P(Y=1)−P(Y=1|do(X=0))]/P(X=1,Y=1)`、`PS=[P(Y=1|do(X=1))−P(Y=1)]/P(X=0,Y=0)`。PN面向已处理且结果发生者，PS面向未处理且结果未发生者。负值或超过1需查有限样本、来源与假设，不无说明截断；重抽时共同重算相关频率和分母。

<a id="a6-02"></a>
#### 人工追踪机制链路

从明确的输出对比出发，逐步选择可能的父节点，例如Q、K、V、MLP或残差位置，使用归因或实际替换检查贡献。记录展开了哪些分支、为何继续或停止、使用的阈值，以及未展开部分。只沿高分分支追踪会影响所得链路的范围。

静态矩阵组合、梯度敏感性与实际干预是三种证据，各自保留。链路中的关键因果主张需要相应干预及能区分替代解释的对照；人工选出的局部链路不自动代表完整电路，也不要求为每篇论文强造一条全覆盖链。

**核对与判定：** 清楚区分相关路径、假设下的效应估计和实测干预结果。本条的可观测代理方法给出计算及限制；不能仅因解释文本与答案相关就作机制结论。

<a id="a7"></a>
### A7 操作性定义

操作性定义把研究概念变成可运行的任务。写清输入材料、允许信息、处理条件、动作或回答、评分规则及终止条件。例如“缺信息推理”不能只写题目不完整，而要验证现有信息无法确定答案、补充指定信息后能够确定。

对于以对比定义的现象，列出基线与目标条件的差；对于容量、预测或搜索任务，列出可行空间、成功条件和计分边界。任务名称不能代替这些规则。使用形式求解器生成答案时，先核对语言到符号的转换，再检查求解所得结果；多解、无解和解析失败分别保留。

<a id="a7-01"></a>
#### 蕴涵、标签假设与预设诊断

NLI将一段文本作为前提、另一段作为假设，输出entailment、neutral、contradiction。方向不可交换；前提支持某句不等于该句在现实中为真。零样本分类先把类别语义写成假设，与同一待分类文本逐项比较，再按协议从关系分数形成类别判断；多语言标签要保持含义，而不是只换显示名字。

诊断事实性预设时，将主句否定、嵌入命题否定和回答“否”区分。模型否认“某人知道P”不一定否认P；评价它是否接受错误预设，应明确问题实际要求的事件及回答编码。不同触发词的投射特征不能只由模板名称推定。

<a id="a7-02"></a>
#### 类型语法与词汇任务

采用ERG/HPSG等类型语法时，确定语言版本、词汇条目、类型继承、补语选择及解析结果。同一表面词可有不同词性或mass/count用法，应据上下文和词汇类型区分，不能只按字符串相同合并。

构造任务时从指定类型和语法约束生成或筛选材料，保存原句到解析/类型的对应；多解析、无解析及类型冲突各自处理。语法许可与模型实际表现分开，解析器的分类也不直接等于目标构念解释。

<a id="a7-03"></a>
#### 条件概率分解任务

按变量顺序，联合概率恒可写为`P(X1,…,Xm)=∏_j P(Xj|X_<j)`。若将前序变量简化为较小parent集合，就额外假设对应条件独立；因为某个条件更容易询问，不足以证明可删除依赖。

任务执行时固定变量、顺序、每项条件事件及分母，记录概率来源，再用声明的求和、基数乘法和取整重组目标。对关键未知依赖可比较不同分解或范围。提示模型生成的因子图是任务产物，不自动是从数据识别的因果图。

<a id="a7-04"></a>
#### 效用选择与逆向偏好任务

给定候选效用U，Luce/softmax选择为`P(c=j)=exp(βU_j)/Σexp(βU_k)`；效用平移不改变概率，β与效用尺度可能混淆，β不同于token生成温度。

由选择反推效用，还需先验`p(u)`，`p(u|c,A)∝P(c|u,A)p(u)`。明确通过有限网格求和、积分或采样归一；后验效用均值与“某物品效用最高”的事件概率是不同目标。

语用speaker可将双方奖励组合为`R_joint=λR_L+(1−λ)R_S`，对话语的预期行动收益做softmax；listener以该话语似然乘奖励和动机先验，对非目标潜变量边缘化。哪些变量已知、动作怎样选取及归一分母要完整，不能把比例式当作已算好的后验。

<a id="a7-05"></a>
#### 有界拟合与认知层级参照

L-BFGS-B需可计算目标、逐参数边界、初值及梯度或差分规则。记录终止消息、目标、投影梯度和多初值结果；达到迭代上限不等于最优，非凸问题不保证全局解。

认知层级以`f_k=e^(−τ)τ^k/k!`给层权重，先定义level-0。level-k对h<k按`f_h/Σ_(l<k)f_l`混合对手策略，再计算各行动效用并按该层精度作logit响应；总体策略为`Σf_kP_k(a)`。若设`λ_k=γk`应明说，截断到K时检查Poisson尾质量，层内信念归一和总体权重不同。

条件i下行动j计数c_ij给似然`Σc_ij ln p_ij(τ,γ)`，核查零概率和参数可识别性。τ是该参照模型的战略深度参数，不能从CoT字数或LLM温度直接赋值。

<a id="a7-06"></a>
#### 随机图与图模型任务

G(n,p)固定节点数、方向和自环规则，对每条合法潜在边独立Bernoulli(p)抽取；每图再抽p会产生密度混合。它不同于固定边数G(n,m)、随机树或真实图邻域。给定独立边概率时完整图似然为`∏_(边)p_e·∏_(非边)(1−p_e)`，候选边空间固定且非边不能漏计。

ERGM定义`P_θ(G)=exp[θᵀs(G)]/Z(θ)`，`Z=Σ_(合法图)exp[θᵀs(G)]`，s可含边与motif。小空间枚举，大空间用明示近似；MAP目标还加log prior。有界均匀先验仅限制参数范围，不能省掉Z。核查统计共线和退化；从软边概率到图统计的桥接要定义，不能把软权重直接当二元边数。

<a id="a7-07"></a>
#### 逻辑事件的概率任务

保证各问题指向同一概率空间和背景。否定要求`P(A)+P(¬A)=1`，等价事件同概率，蕴含A⇒B要求P(A)≤P(B)。包含排除为`P(A∪B)=P(A)+P(B)−P(A∩B)`；交的Fréchet界是`max(0,p+q−1)`到min(p,q)，并为max(p,q)到min(1,p+q)。直接加和只适用于互斥划分。

链式分解保持方向：`P(A∩B∩C)=P(A)P(B|A)P(C|A∩B)`；全概率为`P(A)=P(A|B)P(B)+P(A|¬B)(1−P(B))`。零概率条件事件不能强行用比值定义。记录每题事件及条件映射，再测约束残差；相容不等于现实准确。

<a id="a7-08"></a>
#### 一致性修正与递推分析

列出逻辑允许的世界Ω，对旧概率F和候选p定义各世界对数评分增益`g(p,ω)=Σ[ω_i ln(p_i/F_i)+(1−ω_i)ln((1−p_i)/(1−F_i))]`，求`max_p min_ω g`。可引入t并对每个世界约束t≤g；0/1端点采用极限或明示截断，未定义事件按任务支付规则处理，不能任意当0.5。记录顺序修正的权重及更新，因为重叠约束会互相影响。

两个同义事件、等权且概率在(0,1)内时，可取两侧log-odds平均后logistic反变换；否定关系先将一侧换成补概率。若源题后续带权重复参与，保存其累计权重，不把每轮当独立修正。

另一数值形式由每个世界的评分导数组成A(p)：真项s′(p_i)、假项−s′(1−p_i)、N/A项0，解`A(p)p′=1`并从F积分。仅方阵非奇异时该式直接确定导数；用线性求解，检查误差、概率边界、近奇异和终止事件，非方阵不能擅以伪逆声称同算法。

确定递推`x_(k+1)=s x_k+I`有`l=I/(1−s)`、`x_k=l+s^k(x0−l)`，一般初值收敛需|s|<1；s<0会交替。若x是log-odds，再映回概率。有限log-odds极限在概率上位于(0,1)；固定长度相邻平均也保留同一极限。随机改写或移动目标未满足这些条件时，只报告观察到的有限轮结果。

<a id="a7-09"></a>
#### 空间关系、闭包与MaxSAT金标

空间任务先约定坐标和关系方向，若任务确实采用固定网格位移，可把事实写成`pos(b)−pos(a)=offset`，在连通分量选原点后沿路径累加，检查多路径一致，再解码目标关系。不连通时相对位置未知；纯定性“在左侧”不自动包含单位距离。

关系闭包按每种关系允许的对称、逆、传递、非对称规则分别推导，维护真/假三元组直到无新增。未出现不等于假；同一三元组两边都可推出时返回冲突。严格非对称约束`¬r(x,y)∨¬r(y,x)`不能直接用在所有非严格关系。

加权MaxSAT将三元组变为布尔变量，逻辑规则为硬子句，支持/反对断言按明示置信映射赋软权重，求满足硬规则且软满足总权重最大的赋值。硬约束不相容时报告无解。求解器返回未满足权重cost时，方向与满足收益相反，不要误当越大越好。

<a id="a7-10"></a>
#### 概念格与同步语法

形式语境(G,M,I)中，对象集A共同属性为A′，属性集B共同拥有者为B′；概念满足A′=B、B′=A。有限语境可枚举属性集做双闭包、去重，再按extent包含关系构偏序，去掉传递边得到Hasse图。较大空间用专门枚举法；阈值化和常数/零值处理会改变格，任意属性交集不自动构成闭包概念。

准同步CFG同时给输入和输出规则，同索引非终结符绑定子解析。匹配终结符、递归确定输入span，再按输出端顺序组合；冲突规则按给定优先级选择。保存歧义、失败与递归终止，不能用任意字符串替换替代执行器。

<a id="a7-11"></a>
#### 符号材料、枚举与容量计数

将实体、数量、单位和关系转为有类型的谓词或方程。逐步算术链须在允许域内、每步仅一未知且除法有定义；沿依赖求解后检查目标唯一，再将合法结构填回语言模板并核对。线性证明链每步至多一个非公理前提，与一般多依赖图不同。

穷举先定义完整候选空间、约束及同构/旋转/标签置换的等价规则，再筛选和规范去重。概率分母来自抽样空间；等价类大小不同，均匀抽类与均匀抽配置不同。

容量DP用`F(i,c)`表示从元素种类i起、剩余容量向量c的可行计数；枚举总数符合该类数量且`0≤a_j≤c_j`的分配a，递归`F(i+1,c−a)`，末端按容量要求返回0/1。对不可区分箱子排序c可复用计算，却不自动消除重复路径；还需规范分配或正确重数。用小规模显式枚举检查计数语义。

<a id="a7-12"></a>
#### 数值根与逻辑有效性

求f(x)=g(x)，令h=f−g，在声明区间扫描异号段并用括区间求根；偶重根可能不变号，还需检查|h|小的邻域与导数极值候选，再局部求根或最小化|h|。验残差、范围，按明确精度合并重复根。有限网格不能保证找出任意高频或极窄根，舍入位数与显示精度分开。

验证命题推理可把前提与结论写成布尔公式，用真值枚举或SAT检查“前提∧¬结论”能否满足；能满足即提供反例。局部步骤有效和最终答案正确分别计分。A→B不推出B→A，双条件则允许两个方向；异或要求恰一为真，不能只用互斥代替。

<a id="a7-13"></a>
#### 缺信息与充分变量任务

CSP包含变量域、约束、已知赋值和目标。枚举合法完整解；若所有解目标相同，现有信息已充分。补充变量集S充分，是指给定其允许回答后剩余合法解都确定目标；按包含不可再删与变量数最少是两种“最小”。可以存在多个正确的单变量提问。

造缺信息题可找目标真/假两侧仅一变量不同的相容配对，隐去该变量，再验证删后不确定、补后确定。需要控制推理深度时，找出更浅解的充分变量并形成禁止询问集合，再验目标深度解仍存在。数学题的解析必须保留自然数等变量域、单位和方程语义；无解、多目标值、解析失败分别处理。同一基础题的派生材料在统计中保持依赖。

<a id="a7-14"></a>
#### 树、有效链和未知关系题

树材料检查连通、无环且n−1边；若要均匀带标签树，可均匀生成长n−2的Prüfer序列并解码，其他随机算法可能给不同分布。为可传递严格关系定向时保持无环，再按有向路径生成闭包。

造不一致题可加入确实闭环的边并验环存在；造Unknown题检查查询两方向均不可达，未给直接边不等于未知。长三段论可从有效前提逐步DFS扩展，始终验证目标结论；需要共享项连接的前提顺序时，寻找满足端点条件且每前提恰用一次的Hamiltonian路径，无合法路径则重构材料。

<a id="a7-15"></a>
#### 图同构、条件独立与等价类金标

枚举DAG可按拓扑顺序限制候选边，再用保留全部有向邻接的双射判断同构，存代表及映射；改节点名或度数相同都不足以完成判定。

d-separation检查无向路径：已条件化非collider阻断；collider仅在自身或后代被条件化时打开；全部路径阻断才给图上的条件独立。从数据独立反推图还需要faithfulness等条件。无潜变量的标准DAG可按相同骨架和非屏蔽collider归MEC。

给定MEC和关系查询，逐图计算直接边、严格排除直接边的祖先/后代、共因或共果，再对所有成员作全称判断。gold=0表示不是必然蕴含，不能误解为每个成员都为假；单一代表图不能替代跨类量化。

<a id="a7-16"></a>
#### n-back及记忆任务规则

n-back在第t步判断当前刺激x_t是否等于x_(t−n)。先固定n、刺激集合、序列长度、目标比例、lure规则和生成/筛选方式；前n步没有对应历史，作为起始输入，不并入通常目标判分。可先在可评分位置安排目标，再逐步生成：目标位复制n步前刺激，非目标位从排除该刺激的集合抽取；若另设lure，按其对应滞后约束安排。生成后重算所有位置的真实target、nonmatch和lure；约束不可同时满足时调整生成方案，不能把偶然匹配直接标为nonmatch。

机器输入要说明先前刺激是否仍完整可见、是否只能读摘要或外部记忆、是否发生截断。模型能直接查完整历史与受限状态保持是不同操作。按可评分试次统计命中、误报、正确率；需要敏感性时用本手册SDT规则并预定极端率处理。API耗时不直接作为人类反应时的等价指标。

其他记忆任务同样明确编码、保持/干扰、提取及允许信息；跨度题给出停止与部分正确规则。只有任务设计本身要求对比时才设置对应基线，不要求所有容量任务都套同一对比式。任务名称和构念目录只作命名参照。

<a id="a7-17"></a>
#### 聚类组织材料与选择代表

k-means先固定表示和缩放，以簇内平方欧氏距离之和为目标，执行初始化、分配、更新中心与停止；说明多次启动及空簇处理。全局最优簇内误差随k增加不会上升，因此不能把“误差开始反弹”当作通用选k标准；肘部只是结合用途判断的线索。

k-medoids以实际样本为中心并按选定距离优化，不能把均值中心直接称为medoid。若需要从每簇挑材料，另行定义最近真实样本、覆盖边缘或其他代表规则；仅生成簇标签不等于已经选出了代表。聚类用于材料组织时，保留实际被选样本及对应簇，便于判断选择造成的范围变化。

<a id="a7-18"></a>
#### 主题模型组织文本

LDA以词频和词表为输入，文档主题比例θ和主题词分布β分别受Dirichlet先验控制，每个词先抽主题再抽词。记录主题数、先验、分词和停用词，以及变分或采样推断方式。短文本、低频词和预处理会影响主题解释。

BERTopic式流程通常包括文本嵌入、可选降维、聚类和基于类的TF-IDF主题词；噪声文本、主题合并及命名也要说明。主题名是对结果的解释，不是数据天然的学科标签。选材或配额使用主题时，先检查它是否对应研究所需的内容区分。

<a id="a7-19"></a>
#### 规则语言、模板与可执行函数材料

使用DSL或程序模板生成任务时，先定义语法、类型、变量范围和合法组合，再校验语法树。类名、属性、方法签名和返回映射要相互一致；解析通过与实际执行通过分别检查。关系模板中的槽位是有序的，交换主客体或使用逆关系应显式定义。

生成数学表达式时，保持字符串与可调用函数一致，明确除零、定义域、溢出和异常的处理。组合深度不等于多项式次数，不同字符串也不保证是不同函数。有限次随机生成或筛选只能描述已生成集合，不能宣称在全部合法函数上均匀采样。

<a id="a7-20"></a>
#### 图社区与连续事件分段

非负无向图的一种模块度为`Q=(1/2m)Σ_ij[A_ij−γk_ik_j/(2m)]1(c_i=c_j)`，导通率常写为跨边权重除以两侧体积的较小者。说明权重、分辨率γ、体积定义和自环；使用其他导通率分母时应明确区别。

Leiden式方法通过移动、细化与聚合优化指定质量，记录种子及停止条件。序列事件分段另外要求片段连续：只在允许的相邻边界比较切分或合并，更新后重新计算目标。只检查右邻、单次遍历和反复优化得到的算法不同；若最大化负导通率，应将符号写清。用某指标优化后该指标更好，不等于已经证明语义事件有效。

<a id="a7-21"></a>
#### 网络结构材料与局部子图

无向简单图密度为`2m/[n(n−1)]`，有向图和加权图需另定；局部聚类系数可写为`2T_i/[d_i(d_i−1)]`，低度节点处理应固定。改变节点集合也会改变分母，不能将不同规模的原始计数直接比较。

k-star计数可用`Σ_i choose(d_i,k)`；两步路径按共享邻居计数。几何加权共享伙伴项的一种形式为`λΣ_pairs[1−(1−1/λ)^s]`，λ>1；对所有节点对求和与只对现有边求和对应不同结构。若用独立软边概率的乘积估计结构期望，应明确独立近似。ego子图固定中心抽样方式、半径及是否取诱导子图，删除节点后重新检查规模和连通性。

<a id="a7-22"></a>
#### 图上的标签传播

对非负权重W构造度矩阵D及`S=D^(−1/2)WD^(−1/2)`，先处理孤立节点。给定初始标签F₀和0≤α<1，迭代`F_(t+1)=αSF_t+(1−α)F₀`；相应固定点为`(1−α)(I−αS)⁻¹F₀`，实际可解线性方程并检查残差。

省略共同系数虽然可能不改变每行最大项，却会改变绝对值、阈值和后续比较。传播分数不自动是校准概率；说明初始标签来源、保留强度、停止准则和最终硬标签规则，再用于材料组织。

<a id="a7-23"></a>
#### 词汇关系与句法约束生成

用WordNet等词汇资源改写材料时，先区分上下文义与基本义，定位synset，再按目标选择同义词或上位词，并检查语法和意义是否保持。歧义、词义缺失及领域用法应保留记录，不能只凭字符串替换认定得到合法操纵。

从句法树构造问题时，明确名词短语、命名实体、子节点及最深短语等选择规则，再生成问题并按所需答案筛选；只保留“No”是某种材料条件，不是通用质量标准。比较级标记、共指和X/Y主语关系要按解析及实际句义检查，不能把共现当作共指。合并句子、时态变换及that从句模板需要重新检查主语和谓词对应；模板频率加权也应明确抽样概率。

<a id="a7-24"></a>
#### 图像中的闭合区域与边数材料

从图像提取多边形属性时，固定灰度化、二值化阈值、4或8邻域连通规则、面积限制及轮廓层级。对轮廓按弧长比例设定近似精度，再用多边形逼近顶点数估计边数。分辨率、线宽、抗锯齿和交叉线会改变连通及轮廓结果。

只在确认标签为背景后才跳过对应项。连通块数量、外轮廓边数和所有嵌套闭合区域数量是不同目标，需按题目要求选择。人工查看有代表性的原图与提取结果，修正实际不符的规则；自己的实现应按实际运行描述，不能未经核对称为复现了来源中的完整程序。

**核对与判定：** 给定材料与协议能确定实际试次及其评分，且不把“未在当前参照集中出现”写成“从未出现”。本条的任务规则、金标构造和行为参照模型按需要选用；参数拟合的解释仍受[F3](#f3)约束。

<a id="a8"></a>
### A8 水平数与类型

列出每个因素是类别、有序等级还是连续数值，注明实际范围与间距。两个水平可以回答两点差异；要区分阈值、非线性或反转，则需在相关区间增加中间水平。没有统一必须使用三个、五个水平的要求。

检查每个水平覆盖哪些题目与模型。若较高示例数只适用于部分题，可用共同题集比较；若各水平使用不同题集，应同时说明构成变化。数字刻度也不自动等距，例如“弱、中、强”提示需要具体文本定义。

**核对与判定：** 水平足以回答所声称的问题，实际覆盖和缺格清楚；不能用少数离散点推断未测区间的曲线形状。跨规模跃升的解释见[J17](#j17)。

<a id="a9"></a>
### A9 单一操作化的风险

一个任务只能覆盖构念的某些方面。需要把结论推广到较宽的能力时，选择另一种能测同一目标、但不共享全部表面特征的任务或材料，比较效应方向、大小及分歧。只改同义词或角色名字，未必构成独立操作化。

例如机器工作记忆可以用n-back历史匹配，也可以用跨度或保持后提取任务；两者的信息可见性、干扰和评分条件应分别定义。无需把所有传统任务都运行一遍，也不能因为术语目录将任务连到某构念，就免去实际论证。

**核对与判定：** 多任务证据要说明共同支持什么、各自还受什么影响。只有单一任务时可报告该任务内的结论；若仍宣称覆盖整个构念，则证据不足。任务规则见[A7](#a7)，解释证据见[F3](#f3)。

<a id="a10"></a>
### A10 单一方法的风险

同一目标只由一种测量途径判定时，结果可能依赖该途径特有的误差。根据实际风险选用原理不同的判据，例如规则验证与匿名评分、行为结果与内部测量；在相同输出上对齐比较，查明分歧来自输入、尺度还是评分规则。

增加同一模型的几个提示，不一定增加独立测量信息。人工评分是评价机器输出的一种途径，不要求另建真人实验对照组。客观任务有充分可靠的执行金标时，也不必为了“多方法”再加一个裁判。

**核对与判定：** 方法选择与研究主张相称，对共用来源的局限有具体认识。各渠道一致不等于全部有效；共同方法偏差见[E7](#e7)，评分一致性的计算见[F3](#f3)。

## B 比较设计

<a id="b1"></a>
### B1 不同实验单位间的条件比较

把不同实验单位分配到不同条件，每个单位只经历规定的一种处理。先明确单位是题目、独立轨迹还是实际独立训练的模型实例，再分配条件、运行并保留分配结果。需要随机分配时使用[C1](#c1)。

同一模型开启多个空白会话可以隔离历史，却不会产生多个独立训练的模型。不同条件使用不同题目时要考虑题目构成；使用同一道题的两侧输出则仍可能按题配对。共享题目、模型或环境造成的关联，按[G1](#g1)进入分析。

**核对与判定：** 单位与处理分配相符，历史隔离得到实际执行，分析没有把会话数冒充独立模型数。该设计可以避免条件之间的状态迁移，但不自动保证其他条件可比。

<a id="b2"></a>
### B2 同一实验单位的配对与重复测量

相同题目、轨迹或模型实例在多个条件下被观察时，保留能对应双方的配对键。比较同题两种提示时，对每题计算差值，再按目标权重汇总；同一轨迹各轮则需保留时序依赖。不能仅因两组样本数相同就认定配对。

实施前检查条件能否重置。若目标是独立比较提示，应在匹配的初始状态下分别运行；重置范围包括聊天历史、外部记忆、工具环境，以及确实发生更新时的权重。隔离会话中的同一道题仍可按题配对。有意研究反馈或历史时保留状态，将其写进处理定义。

**核对与判定：** 配对有共同对象依据，缺失配对按预定规则处理，顺序和不可逆状态得到处置。均值差、配对检验和整对重抽的具体计算见[F1](#f1)。方向性残留见[D3](#d3)。

<a id="b3"></a>
### B3 混合设计

一个研究同时有单位间因素和单位内因素时，逐层说明因素在哪些单位上变化。例如把不同轨迹分到两种反馈策略，每条轨迹又经历多个试次；策略是轨迹间因素，轮次是轨迹内因素。

列出各层单位数、每格观察数、共享材料及缺失情况，再选择能保留相关结构的分析。连续评分可用合适的线性混合模型，二元成功可用相应链接的广义模型；并不限定必须使用重复测量ANOVA。相同提示在不同层级也可能承担不同设计角色。

**核对与判定：** 每个效应使用正确层级的信息，轨迹内轮次没有被当成独立轨迹。随机结构及拟合见[G2](#g2)。

<a id="b4"></a>
### B4 因子设计

两个或更多因素共同变化时，先列出因素、水平及其组合。完整交叉让每种组合都有观测，便于区分单因素作用与组合效应；部分交叉则须说明哪些比较仍可识别，哪些效应混在一起。

例如提示策略×反馈有无构成四格，四格共用可比题目和评分。每格实际执行量、无效输出及顺序安排要一起检查。若某接口无法实现某组合，不能把缺格填成零分后当作完整因子设计。

<a id="b4-01"></a>
#### 方差分解与因子效应

单因素独立设计中，`SS_between=Σn_j(ȳ_j−ȳ)²`，`SS_within=Σ(y_ij−ȳ_j)²`；以自由度k−1、N−k分别得到均方，`F=MS_between/MS_within`。该参照要求相应独立误差及模型条件。

多因素模型把主效应与交互写入设计矩阵，根据实际平衡、编码和目标对比确定所检验的效应；非平衡数据不能把不同平方和定义混用。重复测量须使用相应单位内误差或合适的混合模型，不能直接套独立组F。

同一模型内需比较多组均值时，Tukey使用学生化极差及共同残差估计。等样本量时标准化差为`|ȳ_i−ȳ_j|/√(MSE/n)`；不等样本量的Tukey–Kramer用`√[MSE(1/n_i+1/n_j)/2]`。它控制所声明均值比较族的错误率，不自动适用于任意异方差或相关观测。

**核对与判定：** 实际条件表支持所报告的主效应或交互；不要求每次因子实验都检验所有可能交互。边际比较见[B5](#b5)，交互见[B6](#b6)。

<a id="b5"></a>
### B5 主效应

主效应是在其他因素的指定分布下，某因素各水平的平均差异。先决定平均权重：各条件等权、按实际样本构成加权，或按目标任务分布加权；再计算边际预测及其对比。

回归中的某个系数未必就是总体平均作用，尤其有交互和非线性链接时，它可能只代表参考组或链接尺度上的差异。若各子条件作用方向不同，应把这些差异与平均结果并列，避免平均数掩盖交互。

<a id="b5-01"></a>
#### 系数对比与边际预测

线性对比Lβ的方差为`L Cov(β̂)Lᵀ`；Wald用估计差除SE，按所用z或有限自由度t参照求尾概率。估计边际均值先设定参考格、协变量值和条件权重，再计算预测及加权平均；非线性链接中“先平均链接值再反变换”与“先转概率再平均”不相等，应选择与问题对应的量。

**核对与判定：** 平均对象、权重和尺度明确，比较使用同一参考格；不把“其他条件固定为基准”的预测冒充跨条件平均。

<a id="b6"></a>
### B6 交互作用

交互是一个因素的效应随另一个因素变化。在2×2设计中，以准确率为尺度，可计算`(p11−p01)−(p10−p00)`，并给出这个差中之差的不确定性。线条无需交叉，不平行也可能代表交互。

连续调节因素可用回归交互项并展示代表性取值下的预测差。logistic模型的乘积项处于log-odds尺度，其显著与否不直接等于概率尺度上恒定或不恒定的效应；根据研究问题计算相应尺度的对比。直接比较两个简单效应，不能只比较各自p值。

**核对与判定：** 方向、尺度、条件及误差估计一致，样本设计支持所需对比。拟合方法见[F1](#f1)，有层级相关时见[G2](#g2)。

<a id="b7"></a>
### B7 区组设计

当题型、难度、平台或时段存在可预先识别的差异，可先划为区组，在每个区组内安排各处理。随机区组设计在组内随机分配条件或运行次序，使处理不会完全与某类题或某个时段重合。

区组定义使用处理前信息；保留组内分配和缺格，分析时先比较同一区组中的处理差异，再按研究目标汇总。区组数和条件数由材料与预算决定，没有固定只能少于几个条件的限制。

**核对与判定：** 区组内有真实可比的处理信息，区组与处理可区分。事后按结果高低分组不是原来执行了区组随机化；部分区组缺条件时须调整可估计范围。

<a id="b8"></a>
### B8 拉丁方

有k个条件时，可用k行×k列的排列，让每个条件在每行和每列恰好出现一次。行对应一套运行顺序，列对应序位；分配并尽量等量使用各行，最后检查实际完成的序位频数。

普通拉丁方平衡位置，不保证每个条件前后接过所有其他条件。若需要平衡一阶前序影响，可选经有序相邻对核查的方案。例如四条件的`A B D C / B C A D / C D B A / D A C B`同时覆盖每个有序不同条件对一次；这仍不保证更长历史的影响已消失。

**核对与判定：** 核查的是实际运行表，不只是计划表；失败和缺失可能破坏平衡。具体要平衡什么先由[C2](#c2)确定，存在方向性迁移时接[D3](#d3)。

<a id="b9"></a>
### B9 准实验设计

当处理不能由研究者随机分配，例如自然发生的服务版本更新，可使用非随机比较研究其影响。先说明分配机制、时间窗口和可比参照，检查题目、用户、系统及评分是否同时改变。

前后比较只有在替代时间变化得到合理处理时才支持因果解释。若使用差分中的差分、断点或其他识别策略，须写出对应假设和所用证据；方法名称本身不提供可比性。无法识别时，按所观测条件的关联或前后差异报告。

**核对与判定：** 区分研究者操纵、自然分配及纯描述；不把所有单一条件或缺少随机分配的研究一律叫准实验。识别逻辑见[F2](#f2)。

## C 分配与控制

<a id="c1"></a>
### C1 随机化

明确随机的对象和用途：抽取材料用于覆盖总体，分配处理用于改善条件可比性，随机排列用于分散顺序影响，随机解码用于产生模型输出。这四件事不能互相替代。

给出候选集合、抽取或分配单位、有无放回、分层或配额限制、各条件概率及种子，并保存实际结果。概率可以不相等，但应与设计及后续权重一致；生成随机材料时还要给出分布与约束，不能仅写“随机题”。

<a id="c1-01"></a>
#### 合成分布、任务分布与风险分母

合成样本应明确生成层次。正态样本可由`x=μ+σz, z~N(0,1)`生成；混合分布先按π抽组分再抽组内样本，总方差包括组内方差和组间均值差。多元正态可用`x=μ+Lz, LLᵀ=Λ`，并核对协方差可行性。

任务级生成与题目级生成分开。例如每个任务先取`w~N(0,I)`，再生成上下文与查询x及`y=wᵀx`；同一任务内不能为每道题重新抽w。只给上下文标签加噪而保持查询真值干净，与训练和评测同时加噪是不同条件。经验风险`(1/2B)Σ_b L_b`中的B若为任务数，不能替换为token数；总体风险则对指定任务、样本及噪声分布取期望。

一种加权parity构造先从重要任务集合S₁与其余S₂分别以1−p_T和p_T取任务，再在各集合内均匀选择坐标对。对选中两坐标，四种±1模式概率依次为`1/4+γ,1/4,1/4,1/4−γ`，其余坐标独立均匀，0<γ<1/4；随后`x=Gφ,y=φ_iφ_j`。必须保存四种模式对应顺序、G及任务分布。该设定用于明确理论和模拟条件，不能自动当作真实模型的训练数据分布。

**核对与判定：** 随机程序作用于声称的对象，限制条件得到满足。固定种子可以重现一次安排，不代表安排没有偶然不平衡；也不增加独立样本数。

<a id="c2"></a>
### C2 平衡

平衡使角色、标签、位置或次序在比较条件之间按预定权重分布。先决定要控制位置主效应、线性时间趋势还是前序作用，再选排列方法。条件少且预算允许时可全排列；拉丁方控制各序位出现；ABBA在各位置等权时可抵消线性时序趋势，但不能普遍消除非线性趋势或不对称迁移。

材料和角色互换后，应把答案映回同一内容或行动，再汇总；运行失败后重新核对有效样本中的频数。若关心相邻条件，单独计数每种有序相邻对，不能用“每个条件出现一样多”代替。

**核对与判定：** 平衡层级与实际风险相对应，实际完成表支持所声称的控制。排列构造见[B8](#b8)，答案槽位偏差见[J1](#j1)。

<a id="c3"></a>
### C3 恒定

恒定是把本次不研究的条件实际保持相同。运行前固定可控制的模型快照、提示模板、材料版本、工具、解码、长度预算和评分程序；运行时保存实际生效设置。若某项本身是自变量，则按条件变化，不要求恒定。

模型间必须使用不同聊天模板或不支持相同接口时，说明差异及为什么这样比较；远端版本、底层随机性不可控制时记录可见信息。重跑前确认外部文件、缓存和环境状态，不能只检查提示字符串。

**核对与判定：** 固定安排与实际执行相符，未知设置没有被假定为相同。恒定能减少差异来源，也可能限制推广范围，结论据此限定。

<a id="c4"></a>
### C4 匹配

匹配让处理与对照在重要的处理前属性上可比。例如构造只替换目标词的句对，或按题型、长度与难度给材料配对。写出匹配变量、距离或容差、允许复用次数、无法匹配时的处理，并保存配对键。

比较匹配前后构成和剩余差异；分析保留配对或匹配组关系。按处理后成绩挑“相似”样本可能引入选择偏差；按带噪声的极端初测值挑样本还可能出现向均值回归。匹配不能消除没有观测到的混淆。

<a id="c4-01"></a>
#### 配额约束与容量分配

有多个同时成立的选材条件时，可用二元变量x_i表示是否纳入，优化`max Σ_i c_i x_i`，同时约束总量、各层配额、互斥关系及资格阈值。两个模型各自的分位层配额如果需要同时满足，应放在同一个可行解中，不能分别抽样后假定交集仍满足原条件。

容量分配可建成最小费用流：候选到类别的边承载距离或代价，候选容量通常为1，类别到汇点容量为配额；检查是否送满所需流量。若分配后更新中心再重做，单次流优化最优不代表整体聚类全局最优。保存求解器返回的可行状态、目标值、时间限制和最优性差距；有可行解不等于已证明最优。

<a id="c4-02"></a>
#### 局部搜索与贪心覆盖选材

局部搜索先定义合法邻域，例如在满足词性、位置或长度约束的材料中替换一个词；计算真实目标，只接受规定的改进，并明确平分和停止条件。需要平衡各位置时，将它写进约束或更新规则。多次停止前无改进只说明当前搜索未找到更好邻居，不证明全局最优。

覆盖选材可把候选d覆盖的项目记为S_d，每步选取新增覆盖最多的候选，而不是累计覆盖最多者；已覆盖项目不重复计数。权重、平分及精确词项还是语义等价覆盖要预先说明。经过目标优化的材料具有明确选择偏向，不能再声称它们是自然总体的随机代表。

<a id="c4-03"></a>
#### 团结构选材与去冗余

将材料作为节点、超过相似阈值的关系作为边时，先固定表示和阈值。极大团指不能再加节点的团，最大团指规模最大的团；极大团之间可能重叠，不能直接当作不相交分组。

若从团中挑代表，明确是与其他成员最不相似、最居中还是其他准则，以及相似度怎样汇总。需要唯一分组时，规定重叠节点的分配依据、处理顺序、平分和单节点规则。得到的代表与k-medoids中心或真实重复文本并不等价，去冗余范围需按实际图定义解释。

**核对与判定：** 共同属性与研究问题相关，目标操纵仍被保留，排除与权重清楚。选材涉及多项联合配额时使用本条的约束分配，不能以各自抽样代替联合可行性。

<a id="c5"></a>
### C5 纳入为变量

对不能完全恒定、但已测得且与解释有关的属性，可在分析中显式纳入。先说明为何调整、在哪一层变化、怎样编码，再决定估计总效应、直接效应还是某个条件下的关联。试次位置、题长或时段不是自动正确的协变量。

若变量受到处理影响，固定它可能改变问题，甚至引入偏差；先用[F2](#f2)判断因果角色。变量与处理完全重合时，回归也无法把两者分开。对于重复题目或轨迹，应同时处理相应依赖。

**核对与判定：** 调整目标明确、模型可识别、变量来源可核对。线性与二元回归、编码及权重的具体算法见[F1](#f1)，随机结构见[G2](#g2)。

<a id="c6"></a>
### C6 盲法

盲法是向可能受身份或条件线索影响的角色隐藏非必要信息。机器实验可对人工标注者、模型裁判或分析者遮蔽生成者名称、实验条件及预期方向，并随机化显示顺序、统一评分标准。

先说明谁被隐藏了什么、何时揭示，以及风格等线索仍可能暴露什么。任务本身需要的信息不能为了盲法删掉；若研究的就是身份标签影响，则把标签设为明确条件。模型不知道研究者姓名，不等于整个评分过程已盲。

**核对与判定：** 实际裁判输入符合遮蔽安排，标签不从文件名或提示泄漏。独立评分先于讨论或裁决，具体标签流程见[A2](#a2)；无需为每个自动评分任务强加双盲。

## D 重复、历史与背景

<a id="d1"></a>
### D1 重复试次与反馈下的表现变化

在同一运行中，记录试次号、已见例子、反馈和可访问状态，比较难度可比的早晚表现。要把变化归于反馈，应在对应轮次设置有、无反馈或不同反馈的可比条件，同时控制材料与历史量。

模型可以因上下文适应而变好或变差；除非权重确实更新，不把这些变化称为参数学习。是否剔除起始试次要由任务和预先规则决定，不能看到早期差就一律删除“热身期”。

<a id="d1-01"></a>
#### 二元信念更新参照

在给定成功概率θ下观测独立，先验`θ~Beta(a,b)`且a,b>0；n次中k次成功后为`Beta(a+k,b+n−k)`，下次成功预测`(a+k)/(a+b+n)`。推导来自先验与二项似然的幂次相加。θ是连续概率，二项分布描述成功次数，不能混称。

动态折扣可另定义`a_t=γa_(t−1)+y_t`、`b_t=γb_(t−1)+(1−y_t)`。0<γ<1让旧观测失重，γ=1恢复等权累积；预测使用更新前还是更新后计数应固定。折扣是另一动态参照，不能说成静态模型的原样共轭更新，也不能仅凭拟合γ证明模型内部有相同遗忘机制。

<a id="d1-02"></a>
#### 线性预测与Kalman更新参照

在线性模型`y=Xw+ε`、`ε~N(0,σ²I)`、`w~N(m0,S0)`下，`S_n=(S0⁻¹+XᵀX/σ²)⁻¹`，`m_n=S_n(S0⁻¹m0+Xᵀy/σ²)`。新x的潜在均值为xᵀm_n，观测预测方差为`xᵀS_nx+σ²`。噪声未知时需另行估计；oracle知道真实生成先验时拥有更多信息，比较应注明。

标量随机游走Kalman先预测`m⁻=m,P⁻=P+Q`，收到噪声方差R的r后令`K=P⁻/(P⁻+R)`，再更新`m=m⁻+K(r−m⁻)`、`P=(1−K)P⁻`。静态状态可设Q=0，未选臂是否传播Q取决于状态模型。将均值差和不确定性差用于选择拟合时，区分SD与方差；行为拟合不证明模型实际计算了该滤波器。

<a id="d1-03"></a>
#### 价值学习与决策模型拟合

RW参照先用当前Q生成选择概率，再由所选动作的`δ_t=r_t−Q_t(a_t)`更新`Q_(t+1)(a_t)=Q_t(a_t)+αδ_t`；其他动作保持或遗忘的规则明确。正负δ可用α⁺、α⁻，给出初值和边界，以`−Σln P(a_t|Q_t)`拟合。不能用已经吸收本次奖励的Q解释同一次选择。

从选择切换推参数时，用切换前后的效用不等式形成可行区间，多个系列取交；多次切换、并列和空交集分别处理。联合识别可先约束一组参数，再在每个可行值下求余下参数并取并集；区间中点只是摘要，不是置信区间。

比较理论时分别写前向映射：期望效用用客观概率，概率权重模型变换概率，后悔模型依赖未选收益，启发式只取规定特征，混合模型还需混合权重。一种收益/损失模型可用`u(x≥0)=x^(1−σ)`、`u(x<0)=−λ(−x)^(1−σ)`和`w(p)=exp[−(−ln p)^α]`，但彩票同号/混号和排序权重规则还须定义。相同数据、预算和留出单位下比较预测损失，不能从拟合优胜直接判定内部机制。

**核对与判定：** 变化曲线与实际暴露历史对应，因果解释与对照相称。本条的更新模型可作为行为参照；拟合出的学习率描述模型假设下的选择轨迹，不直接等于LLM内部更新率。

<a id="d3"></a>
### D3 延滞与迁移效应

前序条件可能经聊天历史、外部记忆、缓存、工具状态或实际参数更新影响后续表现。先确定研究的是当前处理的独立作用，还是历史本身的作用。前者在相同初始状态分别运行；后者保留并记录历史，使状态成为明确的实验因素。

方向性迁移要分开比较A后测B、B后测A及各自无前序基线。若要区分A内容和单纯多了前文，可设置轮次、长度相近的其他历史。等待一段时间不等于清空模型可读状态；新会话也未必清除外部记忆。

**核对与判定：** 实际重置范围与问题一致，双向作用没有被强行平均。真实状态读写见[J20](#j20)，位置和长度见[J7](#j7)。

<a id="d5"></a>
### D5 背景取值范围对判断的影响

将同一目标刺激放入不同范围或分布的可见示例中，检查模型的评分或选择是否变化。定义窄/宽范围、极端值、中心和频数，并保持目标、位置与计分可比；模型实际看不到背景时，不能假定它受到该范围操纵。

可用固定锚点帮助比较量尺，但仍需检查锚点本身的作用。改变范围也可能改变难度、语义或类别比例，应根据问题分离或保留解释。不同会话分配背景不会自动消除范围效应，因为背景正是输入的一部分。

**核对与判定：** 同一目标的变化能追到具体背景输入，区别于一般位置效应；数值变化不足以单独证明人类式适应机制。

## E 反应与测量偏差

<a id="e1"></a>
### E1 位置与顺序偏差

同一内容出现在不同序位或运行阶段，结果可能改变。保留内容ID、序位、前序条件和时间，改变顺序后比较同一内容；不要把一次随机打乱当作已经测量了偏差。

诊断题目序位时可比较早晚位置并控制题目构成；诊断处理顺序时保留前序；答案槽位、示例排列和长上下文证据位置分别使用[J1](#j1)、[J5](#j5)、[J7](#j7)。这些具体对象不需要再合成同一个“顺序分数”。

**核对与判定：** 结果按内容对齐，顺序与其他条件有可区分的变化。控制方案见[C2](#c2)，持续状态影响见[D3](#d3)。

<a id="e2"></a>
### E2 默认赞同

默认赞同是模型在不顾内容方向时偏向肯定或同意。围绕相同目标构造方向相反且含义可比的陈述，分别统计原始同意率；若存在可核验真值，平衡应答肯定与应答否定的题，报告两类正确率及同一对两侧均正确的比例。

反向措辞可能增加否定理解难度，不能把所有差异都归为赞同偏差。量表反向计分用于统一指标方向，但原始应答极性仍需保留。条件概率可取得时，按[J5](#j5)的先验校准作有依据的比较，不用校准结果覆盖原分数。

**核对与判定：** 赞同、事实正确和计分方向分开。对用户明确立场的跟随属于[J3](#j3)，与无立场条件下的肯定倾向不同。

<a id="e3"></a>
### E3 极端与中间反应倾向

使用等级评分时，公布刻度锚点、数值映射、拒答和越界值的处理。统计端点、中间类别及各等级比例，并在内容与计分方向可比的材料上检查这种选择是否持续出现。

分布集中可能反映真实材料质量，也可能反映锚点、候选顺序或默认风格；需要通过改变相关条件来区分。未经验证的等级按序数解释，0—1映射不使它自动成为校准概率，也不保证相邻等级距离相等。

**核对与判定：** 能还原原始等级分布及转换，倾向判断有可比材料依据。不同裁判使用刻度的差异可用[F3](#f3)的绝对一致与一致性方法区分。

<a id="e4"></a>
### E4 任务目的线索对回答的影响

题面、示例或评分提示可能提前透露目标标签或预期答案。检查具体词语、模板和元信息；若要估计线索作用，构造任务含义可比的去线索版本，配对比较输出。

仅使用词表筛掉线索，只能说明实施了筛查；需要比较证据才能判断线索对结果的影响。机器实验不必安排真人访谈或询问模型“是否猜到研究目的”来证明控制成功。确实作为实验操纵的线索应明确保留。

**核对与判定：** 线索与任务必要信息区分清楚，删改没有暗中改变正确答案或任务难度。评分者身份线索见[C6](#c6)，研究者编制影响见[E5](#e5)。

<a id="e5"></a>
### E5 提示编制与评分线索的影响

研究者的预期可能通过材料选择、提示措辞、预处理和裁判标准进入结果。给各条件采用同一套编制与处理规则，保留候选提示和选择依据；评分时隔离不属于评判内容的自我宣传、来源标签等线索。

去除文字时检查是否删掉实质答案，不能只清理某一条件。自动化执行仍会继承人工编制的偏差。若研究对象正是某类线索，应设置有、无线索条件，而不是直接删除后宣称不存在影响。

**核对与判定：** 处理前后能对应，规则对各条件一致，评分依据与研究目标相符。探索与择优的记录见[G5](#g5)，不要求把每个编辑动作写成日志。

<a id="e6"></a>
### E6 天花板与地板效应

分数接近上限或下限时，量尺可能难以区分条件。查看逐题难度、各模型分布和边界比例，再估计当前设计还能分辨多大差异；不存在适用于所有指标的统一90%或“离上限一个标准差”门槛。

可在开发阶段增加较难/较易材料，或选用具有相应分辨率的连续指标。保留原题集与调整后结果的区别，不能在看到正式比较后删题直到差异变大。若研究目标就是固定题集上的表现，可以保留该题集并如实报告精度。

**核对与判定：** 量尺限制与实测分布相连，调整没有被混作同一次固定评测。整个基准对一组模型的区分能力见[J12](#j12)。

<a id="e7"></a>
### E7 共同方法偏差

当多个变量共享裁判、提示线索、表达格式或数据处理，相关关系可能含共同方法造成的部分。例如同一裁判同时给“推理深度”和“质量”评分，两个分数的相关可能部分来自同一种偏好。

先指出具体共同来源，再选择有意义的替代判据或交叉安排，在相同输出上比较。另一模型家族不必然独立，多个近似提示也未必带来新证据。共同方法可能放大或压低关系，不能只凭相关高就下结论。

**核对与判定：** 控制针对实际共享因素；不把Harman单因子检验或marker变量设为每项研究必做程序。测量信度与效度见[F3](#f3)。

## F 效度与分析

<a id="f1"></a>
### F1 统计结论效度

统计分析先确定要估计的量和推断范围，再按数据结构选方法。区分模型间差异、同题条件差异、同题生成波动、跨材料变化及整局成功；分析单位和权重由[G1](#g1)确定，层级结构见[G2](#g2)。

报告点估计、效应方向与相应不确定性，交代失败、排除和多重比较。分布假设针对具体统计方法，不要求所有原始变量都正态。置信区间、后验可信区间和新观测预测区间回答不同问题；非显著不等于等效，显著也不等于效果大。

<a id="f1-01"></a>
#### 线性相关及其解释

Pearson相关为`r=Σ(x−x̄)(y−ȳ)/√[Σ(x−x̄)²Σ(y−ȳ)²]`。先按相同对象对齐，两列共同处理缺失；任一列无变异时未定义。离群点、聚合尺度及取值范围会改变结果，必要时同时检查散点与逐项误差。二值变量按0/1编码后的Pearson就是点二列相关；也可写为`r=(ȳ1−ȳ0)√(pq)/s_y`，其中p、q是两组比例，s_y使用以n为分母的总体式SD。翻转编码改变符号。

r描述线性关联，`y=2x+10`也可以给r=1，因此不能证明数值一致、无偏差或因果。逐答相关、每若干答聚合后的相关及题内相关回答不同问题。时滞相关先按lag对齐并裁掉未匹配端点；搜索最大lag与预定零lag不同，自相关也影响通常的独立样本推断。

相似矩阵比较通常只取同一非对角三角一次；共享对象使这些元素相关，应按原对象进行重排或重抽。原始相关与信度衰减校正后的相关分别报告，后者按[F3](#f3)的测量假设解释。

<a id="f1-02"></a>
#### 秩相关

Spearman先对两列共同保留的对象分别赋秩，并列通常用平均秩，再计算两列秩的Pearson。无并列时可用`1−6Σd_i²/[n(n²−1)]`，有并列时不能直接用该简式。

Kendall按对象对计一致C、逆序D及只在一列并列的T_x、T_y；`τ_a=(C−D)/C(n,2)`，`τ_b=(C−D)/√[(C+D+T_x)(C+D+T_y)]`。说明采用的变体、缺失和零分母处理；不能仅凭软件名字推定并列规则。秩相关反映单调顺序关系，不等于原数值一致。需要区间或检验时仍须保留独立性、配对和矩阵依赖。

<a id="f1-03"></a>
#### 相关变换与相关差异

Fisher变换`z=atanh(r)=½ln[(1+r)/(1−r)]`，反变换`tanh(z)`。在独立、近似二元正态等条件下，z的SE约为`1/√(n−3)`。比较两个独立样本的相关可用`(z1−z2)/√[1/(n1−3)+1/(n2−3)]`；Cohen q为z1−z2，是效应量而非p值。

共享对象或共享变量的两个相关不能使用独立方差和。可按共同对象联合重抽，重算两个相关及其差；比较差值的分布，不能分别抽两列破坏对应。r接近±1、样本很小或使用秩相关时，上述近似需要另核适用性；不要将普通Pearson的方差公式不加判断套到所有相关。

<a id="f1-04"></a>
#### 均值比较

配对设计先算`d_i=y_i−x_i`，`t=(d̄−δ0)/(s_d/√n)`，自由度n−1；区间为`d̄±t临界值·SE`。独立等方差Student使用`sp²=[(n1−1)s1²+(n2−1)s2²]/(n1+n2−2)`，`SE=sp√(1/n1+1/n2)`。方差不等时Welch使用`SE=√(s1²/n1+s2²/n2)`及Satterthwaite自由度`(s1²/n1+s2²/n2)²/[(s1²/n1)²/(n1−1)+(s2²/n2)²/(n2−1)]`。

单样本t把样本均值与指定值比较。z比较用`z=(估计差−零假设差)/SE`和正态尾，须有相应已知方差或渐近依据；不能把所有大样本比较自动当z。单双侧方向在分析前确定。t方法的分布条件作用于误差或配对差；小样本重尾、离群和聚集依赖会改变适用性。先做方差检验再按p值选择Student/Welch的整套选择程序，不等于两个检验各自标称误差都得到保留。

<a id="f1-05"></a>
#### 秩检验与重复区组

独立两组Mann–Whitney先合并赋平均秩，`U1=R1−n1(n1+1)/2`，`U2=n1n2−U1`。给出使用哪侧U、尾方向及并列修正；其一般目标是分布或随机优势，在相同形状的移位条件下才可较窄地解释为位置差。

配对Wilcoxon先对`d_i−δ0`的非零绝对值排序，分别加正、负秩得到W⁺、W⁻。零差、并列和精确/近似方案要明确；以对称差分布为位置模型时才具有相应位置解释。

Kruskal–Wallis合并k组赋秩，`H=12/[N(N+1)]ΣR_j²/n_j−3(N+1)`，用`1−Σ(t³−t)/(N³−N)`作并列修正后通常参照χ²(k−1)，有差异再作明确的后续比较。Friedman在每个完整区组内对k条件赋秩，n个区组的列秩和R_j给出`Q=12/[nk(k+1)]ΣR_j²−3n(k+1)`；并列时将Q除以`1−Σ_blocks Σ_ties(t³−t)/[nk(k²−1)]`，其中t为每个区组内各并列组大小。小样本宜使用对应的精确或保留区组的置换，不能把重复区组当独立组。

<a id="f1-06"></a>
#### 列联表与配对类别比较

独立列联表用`E_ij=行和_i·列和_j/N`，`χ²=Σ(O−E)²/E`，自由度(r−1)(c−1)。期望数过小、结构零和重复观测会影响普通χ²近似。2×2 Fisher在固定边际下计算超几何概率；双侧可按“不大于观察表概率”的可行表求和，须说明实际尾规则，较大表另用相应精确或模拟算法。

McNemar针对同一对象的两个二元结果，只使用不一致格b、c。零假设下b在b+c次中服从Binomial(b+c,½)；可作精确检验，或以`(b−c)²/(b+c)`作χ²(1)近似。连续性修正形式使用`(|b−c|−1)²/(b+c)`并说明约定；b+c=0时没有不一致信息。配对类别差不能改用独立四格检验。

Cramér V=`√[χ²/(N·min(r−1,c−1))]`是无方向关联强度；类别划分与表大小影响解释，多表加权还须说明目标及权重。

<a id="f1-07"></a>
#### 二项与精确多项检验

二项模型要求n个对应单位在零假设下具有共同成功概率p0及适当独立性，`P(X=x)=C(n,x)p0^x(1−p0)^(n−x)`。单侧累加相应尾，双侧选择明确规则；概率排序双侧累加零假设概率不大于观察计数概率的x，不等于所有情况下都机械加倍单侧p。

多项计数在固定N和类别概率p_j下，`P(c)=N!·∏p_j^c_j/∏c_j!`。枚举总数为N的合法计数向量，按声明的概率排序尾部求和，或用可说明误差的模拟。类别空间和结构约束先固定；同题相关回答、动态选择或随状态改变的成功概率不能直接塞入普通独立二项模型。

<a id="f1-08"></a>
#### 离散度、标准误与系数区间

样本SD描述观测离散；独立同分布样本的均值SE为`s/√n`。相关或不等权汇总应用`Var(Σw_i X_i)=Σ_iΣ_j w_iw_j Cov(X_i,X_j)`，不能将记录行数直接当有效n。均值t区间为`x̄±t_(1−α/2,n−1)·SE`，大样本正态近似用对应z临界值。区间估计均值，不是新回答的预测区间。

OLS同方差条件下系数协方差为`σ̂²(XᵀX)⁻¹`。异方差稳健估计把各行残差平方纳入夹心矩阵；聚类方案以独立簇的得分和`s_g=X_gᵀe_g`构成中间项`Σs_gs_gᵀ`，两侧乘`(XᵀX)⁻¹`。保留实际小样本修正与自由度；簇少时普通渐近区间可能不稳，增加簇内记录不能代替增加簇。

比例的plug-in SE为`√[p̂(1−p̂)/n]`，边界0/1会错误表现为零不确定性，应按下一节选取适当比例区间。

<a id="f1-09"></a>
#### 比例及标准化差的区间

Wilson区间令z为正态临界值，中心为`(p̂+z²/(2n))/(1+z²/n)`，半宽为`z√[p̂(1−p̂)/n+z²/(4n²)]/(1+z²/n)`。Clopper–Pearson通过二项尾反演：x>0时下界为Beta(x,n−x+1)的α/2分位，x<n时上界为Beta(x+1,n−x)的1−α/2分位；x=0取下界0，x=n取上界1。CP在独立二项模型下通常保守，不能替相关采样自动提供覆盖保证。

独立两组标准化均差d在相应近似下可用`Var(d)≈(n1+n2)/(n1n2)+d²/[2(n1+n2−2)]`构造正态近似区间。注明标准化分母与样本条件；配对设计有协方差且可使用不同标准化定义，不能沿用独立组方差。必要时按实际单位重抽或采用适配模型的区间。

<a id="f1-bootstrap"></a>
#### 从重抽样到区间与检验

给定估计量θ̂，按研究设计从原始单位有放回抽样，每次重算θ̂*，重复B次。两个模型答同一道题时，每抽中题i同时取两侧记录；同情境下多次输出一起抽，跨对象距离先重抽对象再构建距离。是否另在题内抽生成重复，取决于要覆盖的随机层级。数据重抽与再次调用模型是两种实验操作。

复样时重算最终统计量所依赖的步骤，包括相关分母、基线、回归或排名。若PCA轴等已固定，区间只覆盖给定该轴的变异；若推断包含重新拟合，则每次重估相应步骤。对AUC等统计量要确保复样符合研究设计且所需类别存在，不能把缺类结果默默记零。

百分位区间直接取复样分布的α/2与1−α/2分位。有限B下，若用经验逆分布则取排序后第`ceil(Bp)`项（按1起算），端点与p=0另定；线性插值的索引约定不同，应保留所用定义。basic区间是`[2θ̂−q_(1−α/2), 2θ̂−q_(α/2)]`。复样θ̂*的SD估计统计量SE，不等于原始观测SD，也不自动是一条95%区间。

检验必须构造零假设参照。例如配对均值零差检验可先将差值中心化到零，再按适当单位重抽，比较`|d̄*_0|`与观察`|d̄|`；独立组可在零假设下平移到共同均值后复样。单双侧、标准化与尾计数应明确，复样次数本身不能确定p值。

比较两条件直接构造差值分布，两个单独区间重叠与否不是通用差异检验。两个83%区间分离近似对应5%双侧检验，只在独立、等SE和正态等条件下成立。变换区间时单调变换可变换端点；取绝对值遇区间跨零，应包含零，上界为两端绝对值较大者，不能只把负端变正后排序。

<a id="f1-11"></a>
#### 置换、机会模拟与距离分析

置换在零假设下可交换的单位上重排。独立随机分配可重排条件标签；配对问题可在满足相应零假设与对称条件下交换对内标签；聚集设计保留整簇。每次重算同一个统计量，用与观察值一样极端的模拟次数b构造例如`(b+1)/(B+1)`的蒙特卡洛尾概率，明确单双侧和是否枚举全部排列。

动态机会基线应真实模拟合法随机策略：从同样初态出发，逐轮更新状态、库存和奖励，再算整局分数。逐题固定机会率可能无法描述有路径依赖的游戏。零分布的分位数来自这些完整轨迹，模拟次数决定分辨率而非独立实验量。

PERMANOVA从对象间距离构造平方和，常见`SS_T=Σ_(i<j)d_ij²/N`，`SS_W=Σ_g Σ_(i<j∈g)d_ij²/n_g`，`pseudo-F=[(SS_T−SS_W)/(k−1)]/[SS_W/(N−k)]`，用适合设计的标签置换求右尾。距离度量、组内离散度和交换性影响解释；显著不自动表示仅有组中心差异。

<a id="f1-12"></a>
#### 多重比较和p值合并

先定义比较族及控制目标。Bonferroni使用阈值α/m或调整p为min(1,mp)。Holm将p从小到大排序，依次与α/(m−i+1)比较，首次不拒绝后停止；调整值为`min[1,max_(j≤i)((m−j+1)p_(j))]`。这两者针对族错误率FWER。

BH在排序p中找最大k满足`p_(k)≤kα/m`，拒绝前k项；调整值从后向前取`min[1,min_(j≥i)(mp_(j)/j)]`。它在独立或相应正相关条件下控制FDR，即拒绝集合中假发现比例的期望，不是“每个发现有α概率为假”。依赖结构不满足时需适配方案。只在子族内校正不能声称控制了全部分析的FWER。

Fisher合并法`T=−2Σln p_i`在各零假设下独立连续均匀p的条件下参照χ²(2m)。同题、同模型或共享数据的p相关时不能直接套此参照；合并显著也不证明每一项都存在同方向效应。

<a id="f1-13"></a>
#### 均值、优势比与秩效应的尺度

独立两组可用均值差除合并SD得到d；配对标准化可用差值SD，须注明与独立d不是同一量。2×2优势比`OR=ad/(bc)`，表示odds之比而非成功概率比；零格处理和参照方向先固定。`d≈ln(OR)√3/π`依赖特定潜在分布近似，不能当无条件换算。

独立U的秩双列相关可写`1−2U/(n1n2)`，方向取决于U的定义；配对用`(W⁺−W⁻)/(W⁺+W⁻)`并说明零差和并列。Kruskal–Wallis的一个秩效应量为`ε²=(H−k+1)/(N−k)`，有限样本可出现负估计，是否截零需报告。

<a id="f1-14"></a>
#### 线性回归、权重和对比

建立设计矩阵X，标明截距、连续量尺度及类别编码；OLS最小化`||y−Xβ||²`。满列秩时可按线性方程求解，秩亏时必须处理不可识别参数，不能把某个伪逆解当所有系数都有唯一科学含义。WLS最小化`Σw_i(y_i−x_iᵀβ)²`，权重必须非负并说明来源；人口权重改变目标总体，不自动是逆误差方差权重。

参照编码的系数与基准组比较，sum-to-zero编码例如k−1个水平列取单位向量、最后水平取全−1；非平衡样本中其截距含义还取决于模型与平均规则。嵌套对比只在对应上层组内变化，组外置零，明确组内权重。拟合后核查预测、残差、秩和所需误差条件。

`R²=1−Σ(y−ŷ)²/Σ(y−ȳ)²`依赖评价数据及基准，外部预测可为负；无截距或使用不同基准时说明定义。它不是逐题正确率。所需SE和对比按本条其他小节计算。

<a id="f1-15"></a>
#### 二元链接与正则化拟合

二元结果可令`p_i=logistic(x_iᵀβ)`或`p_i=Φ(x_iᵀβ)`，最大化`Σ[y_i ln p_i+(1−y_i)ln(1−p_i)]`；分组二项加入成功数和试次数。logit系数指数化给其他变量固定时的OR，不直接给概率差；probit系数处于潜在正态量尺。检查完全分离、极端预测及拟合状态。

L2或elastic-net在损失中加`λ[(1−η)||β||²/2+η||β||₁]`，说明截距是否惩罚、标准化、类别权重与参数化。筛出非零变量后再无惩罚重拟合，普通p值未计入选择过程；调参及预处理按[G5](#g5)置于训练部分。不同损失归一约定改变λ的数值，不可只按参数名称比较。

<a id="f1-16"></a>
#### 嵌套模型的整体比较

嵌套线性模型的F比较为`[(RSS_R−RSS_U)/q]/[RSS_U/(N−p_U)]`，须满足相应误差假设。LRT为`2(ℓ_U−ℓ_R)`，在常规可识别、内点等条件下近似χ²(q)；边界参数、数据驱动选模或不相容的拟合目标不能直接使用此参照。顺序加项与删一项检验的条件集合不同。

<a id="f1-17"></a>
#### 网格后验与受限假设

有限网格上计算`w(θ)=L(data|θ)π(θ)·网格体积`，以log-sum-exp稳定归一；不等间距网格不能漏掉体积。对干扰参数求和得到边缘后验，再求均值或分位，检查网格范围与精细度是否改变结论。

Bayes factor比较两假设的边缘似然比。参数相等假设处于低维空间，不能简单在连续高维网格筛“相等点”；有序假设如θ1<θ2须对该约束空间上的先验重新归一，分别积分。边缘似然和后验最大值不同，先验范围会实质影响比值。

<a id="f1-error-propagation"></a>
#### 误差传播和约束残差

线性组合精度使用完整协方差。非线性函数g在估计点附近可用delta近似`Var(g)≈∇gᵀΣ∇g`；乘积的梯度如g=ab为(b,a)，全概率表达式`g=ab+c(1−b)`的梯度为(b,a−c,1−b)。二项概率方差可代入`p̂(1−p̂)/n`，但相关估计还需协方差。

检验概率约束时先定义残差，如`r=p(A)+p(¬A)−1`，用相应传播方差标准化；小计数、端点和高阶误差可能使近似失效。使用Beta平滑必须记录参数并在残差各项中一致处理，不能只为避免零SE而无说明改动原值。此处检验相容性，不等于事实准确。

若D~N(μ,σ²)，绝对值后的矩为`E|D|=σ√(2/π)e^(−μ²/(2σ²))+μ[1−2Φ(−μ/σ)]`，`Var|D|=μ²+σ²−(E|D|)²`；σ=0时为确定的|μ|。跨组平均按平方权重和协方差传播，不把绝对值后的分布继续当原正态。

<a id="f1-19"></a>
#### 分布与序列诊断

正态模型的常见最大似然拟合为`μ̂=mean(x), σ̂²=Σ(x_i−μ̂)²/n`；以n−1作分母的是无偏样本方差，二者应按实际用途注明。拟合参数并不证明数据服从正态。

Shapiro–Wilk统计`W=(Σa_i x_(i))²/Σ(x_i−x̄)²`，a_i来自正态次序统计量的矩；p值用于检验相应正态假设，未拒绝不证明正态。KS以经验CDF的最大差为统计量：一例对给定F0，两样本比较两个经验CDF；若F0参数用同一数据估计，通常零分布不能原样沿用。

Levene先计算各观测对组中心的绝对离差，再对离差作组间F；中心可为均值或中位数，须说明。方差比`F=s1²/s2²`在两组独立正态条件下参照F(n1−1,n2−1)，双侧结合两尾；先检验再选最终分析会产生额外选择影响。

二值序列游程R在固定n1、n0的随机排序下，`E R=1+2n1n0/n`，`Var R=2n1n0(2n1n0−n)/[n²(n−1)]`；小样本用相应精确分布，缺一类时不能套正常方差。按词出现与否比较标签时，可在共同词频基线p0下用`z=(p̂−p0)/√[p0(1−p0)/n]`，前提与单位须成立；很多词分别筛选要考虑多重比较。

**核对与判定：** 从原始观测到最终统计量的操作可还原，配对与聚集依赖保留，所用假设与实际数据相符。本条的计算按问题选用，无需把全部检验执行一遍；不确定性计算也不代替研究设计。

<a id="f2"></a>
### F2 内部效度

内部效度关注所见差异能否归于目标处理。沿输入、分配、运行、输出与评分检查实际变化，重点处理条件间材料差异、服务更新、选择性失败及评分规则变化。能操纵时安排合适对照，不能操纵时明确识别假设。

例如接口在收集途中更新，先看各条件经历的版本与时间是否可分离；按时段重新比较或限定适用范围，不能把所有调用合成一个固定模型结果。内部张量干预还要确认写入点、供受体和下游计算一致。

<a id="f2-01"></a>
#### 因果查询与调整

先定义处理X、结果Y、图、潜在共同原因及可取得的观测/干预分布。条件概率可计算，不表示`P(Y|do(X=x))`已识别。

若Z不含X后代且阻断所有进入X的非因果路径，在一致性、正值性及图假设下，可用`P(y|do(x))=Σ_z P(y|x,z)P(z)`。没有后门集不自动证明不可识别，还可能有前门或正式ID/do演算。每次演算依据相应删入边/删出边图的d-separation条件，不能把所有do直接删掉。

形式任务的金标按“图—查询—可用分布”生成，区分不可识别、零条件事件与平凡查询；研究现实模型行为时还需判断这些假设是否可信。

<a id="f2-02"></a>
#### 结构模型与反事实

SCM定义外生联合分布P(U)及`X_i=f_i(pa_i,U_i)`，按DAG拓扑序生成事实样本，明确外生量是否独立。`do(X=x)`把对应方程替换为常数，保留其余方程和外生分布后向下游计算；筛选自然X=x不是同一操作。

对已见证据e的反事实，先溯因`P(U|e)`，再在同一后验外生状态上替换方程，最后预测Y_x。有限U可枚举并按证据相容性加权，连续情形需相应反演或后验方法。反事实保留个体信息，普通do边际则从P(U)积分。语言题替换是否对应同一SCM，需要逐题确认。

**核对与判定：** 因果表述有相应设计和证据；只做描述性研究时说明比较范围即可。本条的规则支持正式因果查询，不能用图或求解器替代对现实假设的判断。

<a id="f3"></a>
### F3 构念效度

构念效度回答“这个操作和分数是否足以支持我们赋予它的含义”。先写出目标能力或倾向及竞争解释，再考察任务内容、信息可见性、响应过程、评分和相关证据。准确率可以客观计算，但称其为通用推理能力仍需要论证。

原构念目录和任务目录用于统一名称与寻找候选操作。存在目录关联不证明有效，缺少关联也不证明任务无效。机器工作记忆任务需说明历史是否仍完整可见；推理任务需排除答案线索或格式失败等替代解释。可按实际需要比较同构变体、应相关和不应相关的指标，不强制真人对照。

本条方法：[因子适切性、提取与旋转](#f3-01) · [两名评分者的机会校正一致](#f3-02) · [多名类别评分者](#f3-03) · [缺失评分与Krippendorff α](#f3-04) · [连续评分的ICC](#f3-05) · [内部一致性与分半](#f3-06) · [跨初始化匹配与衰减校正](#f3-07) · [重复测量的噪声上限](#f3-08) · [表征相似性与既有外部参照](#f3-09) · [轮廓系数检查聚类分离](#f3-10) · [既有脑参照的空间展示](#f3-11)。

<a id="f3-01"></a>
#### 因子适切性、提取与旋转

对p个变量的相关矩阵R，Bartlett球形检验常用`χ²≈−[n−1−(2p+5)/6]ln|R|`，自由度p(p−1)/2；适用于相应连续多元条件，奇异矩阵和强依赖要另处理。拒绝球形只表示相关并非全零，不证明某个构念成立。

MINRES用共同因子部分近似相关矩阵，重点最小化非对角残差平方；明确保留维度、共同度、停止和异常解。Varimax在正交旋转下寻求较简单的载荷结构，旋转不改变共同空间的总解释结构，因子名称仍需内容依据。不能把PCA的总方差分解当共同因子分析，也不能只凭旋转后的漂亮载荷确认心理机制。

<a id="f3-02"></a>
#### 两名评分者的机会校正一致

同一批对象上，观察一致率P_o为同标签比例；按两评分者各自边际概率得到`P_e=Σ_c p_1c p_2c`，`κ=(P_o−P_e)/(1−P_e)`。Pe=1时未定义，类别基率会影响κ，应同时看原始一致率和列联表。

有序标签可设一致权重w_ij，如线性或二次距离转换的权重，观察和机会两项都按同一权重求和后计算加权κ。公布等级间距离、权重和缺失处理。多人两两算κ再平均时，保留每对共同样本及平均权重；它不是Fleiss κ，也不是若干独立κ的简单推断问题。

<a id="f3-03"></a>
#### 多名类别评分者

m名评分者完整评价每题时，题i各类计数n_ic给出`P_i=[Σ_c n_ic²−m]/[m(m−1)]`，平均得到P̄，整体类别比例p_c给`P_e=Σp_c²`，Fleiss κ为`(P̄−P_e)/(1−P_e)`。m不等或缺失时应选择相应定义，不能直接沿用固定m分母。

Gwet AC1使用不同机会模型：q类情况下常见`P_e=Σ_c p_c(1−p_c)/(q−1)`，再代入同样的机会校正结构。连续或有序版本另有权重；只写“Gwet”或“gamma”不足以确定算法。类别空间、共同标注结构、原始一致和所用变体共同决定解释。

<a id="f3-04"></a>
#### 缺失评分与Krippendorff α

每题至少有两条有效评分才贡献题内配对。令m_i为有效评分数，以每个有序评分对贡献`1/(m_i−1)`构造coincidence矩阵o_cc′；同类对使用`n_ic(n_ic−1)`，异类对使用`n_ic n_ic′`。其总量N_c是可用评分数，总边际记n_c。

给定名义、序数或区间尺度的距离δ²(c,c′)，`D_o=Σo_cc′δ²/N_c`；机会配对为异类`e_cc′=n_c n_c′/(N_c−1)`、同类`n_c(n_c−1)/(N_c−1)`，`D_e=Σe_cc′δ²/N_c`，最后`α=1−D_o/D_e`。距离和类别次序必须一致；De=0时不可作普通解释。缺失可以纳入此结构，但不能因此忽略系统性缺失造成的选择。

<a id="f3-05"></a>
#### 连续评分的ICC

先确定评分者是希望推广的随机样本还是固定集合，目标是绝对数值一致还是允许评分者系统偏移的相对一致，以及使用单次评分还是m次平均。双向平衡设计可从对象均方MS_R、评分者均方MS_C及误差MS_E计算。

单次绝对一致`ICC(A,1)=(MS_R−MS_E)/[MS_R+(m−1)MS_E+m(MS_C−MS_E)/n]`；单次一致性`ICC(C,1)=(MS_R−MS_E)/[MS_R+(m−1)MS_E]`。平均评分相应为`ICC(A,m)=(MS_R−MS_E)/[MS_R+(MS_C−MS_E)/n]`、`ICC(C,m)=(MS_R−MS_E)/MS_R`。单向模型及不平衡/缺失设计采用对应模型，不能照抄双向公式。报告具体形式和区间；相关高可以与数值不一致同时出现。

<a id="f3-06"></a>
#### 内部一致性与分半

在同一构念的k个条目上，以对象为行、条目为列，统一必要的计分方向，`α=k/(k−1)[1−Σs_j²/s_total²]`。总分方差为零时未定义；高α可能来自冗余，不能证明单维或效度。不同任务是否应合成量表先作实质判断，不把α强加到所有准确率。

分半先说明分割的是条目、试次还是重复观测，分别重算每半的目标分数、频数或关系矩阵，再比较同一对象的两半结果。在平行半测量等条件下，Spearman–Brown用`r_full=2r_half/(1+r_half)`估计全长信度；不等长或不平行时不能直接沿用。重复随机分半应记录分布或聚合规则，不能只挑相关最高的一次。

<a id="f3-07"></a>
#### 跨初始化匹配与衰减校正

对不同初始化得到的维度，先在同一对象上计算跨维相关，再按声明的一对一匹配目标寻找对应。匹配后若在Fisher尺度平均，用`mean(atanh r)`再tanh反变换，并记录符号处理与权重。选择最大相关本身会抬高估计，必要时在独立对象上确认匹配；不能把选优结果当未经选择的信度。

在经典测量误差等条件下，衰减校正为`r_corrected=r_observed/√(rel_x rel_y)`。低信度、非独立误差或选择影响会使结果不稳，超过1提示估计与假设问题，不能据此宣称超出数学上限的真实相关。原始相关与校正值并列。

<a id="f3-08"></a>
#### 重复测量的噪声上限

同一对象有n次重复观测时，区分对象间信号和重复内噪声。若信号噪声标准差比为ncsnr，则重复均值可达的方差比例常写`C=ncsnr²/(ncsnr²+1/n)`。它依赖信号/噪声模型、重复独立性及n的定义；百分比表示时先统一量尺。

用`R²/C`作噪声归一是对该参照的相对预测表现，不是原始R²，更不自动保证落在0—1。使用已有脑响应等外部参照时，n指参照数据的重复，不能替换为模型调用次数；不要求本项目新建真人实验。

<a id="f3-09"></a>
#### 表征相似性与既有外部参照

比较两种表示时，先对齐同一组刺激及其顺序，再各自计算表示相似性或距离矩阵，取一致的非对角元素比较。已有脑数据作为外部参照时，明确被试、空间、ROI或searchlight邻域及响应估计；球形邻域内的体素模式与另行学习的表示不能混称。

共享刺激造成矩阵元素相互依赖，推断方法按[F1](#f1)保留这一结构。此用法是比较已有外部测量，不要求新建真人对照实验。相似性一致只支持所选表示和度量下的关系，不能直接等同于内部机制相同。

<a id="f3-10"></a>
#### 轮廓系数检查聚类分离

对样本i，a_i为与同簇其他样本的平均距离，b_i为与各其他簇平均距离的最小值，`s_i=(b_i−a_i)/max(a_i,b_i)`。说明使用的表示、距离、标签来源，并处理单成员簇及分母为零；通常要求簇数在2与n−1之间。

同时查看样本或簇的分布，不能只看一个均值。高分说明所用距离下簇内更紧、簇间更分离，不直接证明类别有行为科学意义；低分也不能直接当作材料多样性更好的证据。

<a id="f3-11"></a>
#### 既有脑参照的空间展示

使用已有脑图与模型表示比较时，绑定刺激、功能数据、结构像、脑区或搜索邻域的对应。表面展示通常需把功能数据配准到结构空间，再采样到皮层网格和展平图；左右半球、变换、排除区域及显示阈值要保持一致。

这是一种既有外部参照的处理与展示方式，不把脑区称为模型神经元，也不要求本项目建立真人对照组。按R²等阈值遮罩后的空白表示未被显示，不直接证明该区域没有关系。

**核对与判定：** 结论不超出任务与证据支持的范围；信度只是测量稳定或一致的条件之一，不能用高α、高相关或好看的聚类图代替效度。本条给出评分一致性、结构检验与外部参照的实际算法。

<a id="f4"></a>
### F4 外部效度

先指出希望推广到哪些题型、模型、语言、时期、交互对象和部署设置，再对照材料与模型的实际来源。固定少数模型可以支持它们之间的比较；若声称适用于所有模型，则需要更广泛或有抽样依据的证据。

按目标有选择地更换任务、材料、对手或配置，保持比较指标可解释，并报告变化和未覆盖范围。多个公开基准可能共享题目或知识来源，不能仅以名称数当作独立领域数。选出的簇代表也不等于概率抽样的总体代表。

<a id="f4-01"></a>
#### 跨研究效应的合并

合并可比效应时，固定效应逆方差权重为`w_i=1/v_i`，`θ̄=Σw_iθ_i/Σw_i`；独立时SE为`1/√Σw_i`。随机效应在研究间方差τ²下用`1/(v_i+τ²)`，τ²可用明确的REML估计。共享对象或参照的效应需纳入协方差；异质性和效应定义不同不能靠加权平均消除。合并OR通常先在log尺度进行，最后指数变换。

**核对与判定：** 推广对象清楚，论断与已覆盖条件相称。跨研究合并效应时，还需核对效应定义、依赖与异质性，不能以平均数掩盖条件差异。

## G 单位、规划与分析选择

<a id="g1"></a>
### G1 分析单位

分别写出处理分配单位、原始观测单位和推断单位，并给出它们的对应关系。一题可有多次回答，一条轨迹可有多轮动作，一个模型可回答全部题；这些数量不是相同的样本量。

选择汇总方式时先确定目标：题目等权可先在题内平均；想估计按使用量加权的表现则采用对应权重。先合并全部试次再拟合的参数，一般不等于逐模型拟合参数的平均。共享题目、上下文、生成来源或参照对象的观测要保留聚集关系。

**核对与判定：** 分母与结论对应，分析正确处理分配与观测层级，无需强求它们字面相同。同题随机调用可估计给定条件下的输出分布，但不会把一个模型变成多个独立模型。

<a id="g2"></a>
### G2 随机效应

当数据含题目、提示、轨迹或模型家族等重复层级，且研究目标涉及这些层级的变异时，可建立随机效应。先列出嵌套或交叉关系，决定需要随机截距，还是有足够组内条件变化的随机斜率。

选定的几个模型并不因名称不同就必须作为随机样本；固定效应与随机效应取决于问题、抽样和可估计性。检查方差估计、相关、奇异拟合和收敛；简化时说明保留了什么依赖。也可用恰当的聚集重抽或汇总，不把某一种模型设为唯一合格办法。

<a id="g2-01"></a>
#### 线性和广义混合模型

线性混合模型写为`y=Xβ+Zb+ε`，`b~N(0,G)`、`ε~N(0,R)`，以ML或REML估计固定项与方差结构。题目和轨迹可交叉或嵌套，随机斜率必须在对应组内有条件变化。比较不同固定效应的似然通常使用ML；REML值不能直接跨不同固定设计作同样LRT。

二元等响应使用对应分布与链接，如`logit p=Xβ+Zb`，需积分随机效应，声明Laplace、求积等实际估计方式。记录不收敛、边界方差和相关接近±1等问题；更复杂并不自动更有效。

混合模型边际R²衡量固定部分，条件R²还含随机部分。在线性方差分解下，分母为`V_fixed+V_random+V_residual`，两者分子分别为V_fixed和V_fixed+V_random；随机斜率的V_random应按实际设计取平均贡献。非高斯模型的残差/分布方差与尺度有不同定义，注明具体版本，不能与OLS R²直接混同。

<a id="g2-02"></a>
#### 贝叶斯层级拟合与后验比较

指定观测似然、链接、参数先验和层级超先验，明确哪些组共享分布。例如多类别模型固定一个pivot类别logit为0，其余类别用线性预测，经softmax得到总和为1的概率；不固定尺度或基准会不可识别。

用NUTS等采样时报告链、热身、有效样本、收敛指标和发散，并检查后验预测能否描述数据。后验抽样不是保证收敛的次数清单。参数差应在每个联合后验draw内相减，再汇总区间和概率，不能分别打乱两参数抽样。

加性Gaussian模型按实际方差和参数边界形成联合后验。若以模型自报后验logit回归先验logit及log似然比来估计权重，先核对概率事件和0/1端点处理；这是行为权重拟合。参数可信区间与含观测噪声的新结果预测区间分开。

**核对与判定：** 分组是真实数据来源，随机结构可由设计支持，推断范围与组数相称。本条的模型提供具体拟合与解释。

<a id="g3"></a>
### G3 材料作为随机效应

同一材料反复用于多个模型或条件时，材料难度构成共同来源；要推广到新材料，还应计入材料间变异。保留题号、材料家族及改写来源，说明材料抽取或筛选方式。

可设题目随机截距；若同题跨条件且数据支持，可设条件随机斜率。多个表面改写来自同一基础题时，按基础题聚集。采用按题配对重抽或合适的题级汇总同样可以处理相应变异，具体取决于估计目标。

**核对与判定：** 同题依赖和材料来源没有被忽略。只研究一个固定题集时可以限定结论于该题集，不因没有随机题目模型就直接判错；但不能据此无条件推广到未测材料。

<a id="g4"></a>
### G4 统计功效与精度规划

在收集前确定主要比较、希望识别的最小差异或希望达到的区间精度，以及可用预算。用试点或明确假设估计题目间与题内波动，区分增加新题和增加同题重复各能改善哪部分精度。

功效规划给出显著性水平、目标效应、检验、目标检出概率和依赖结构；也可按置信区间宽度或预算下的可分辨差异规划。复杂设计可按拟定生成与分析流程模拟。不得在每次看p值后无约束加调用直到显著。

<a id="g4-01"></a>
#### 等效界与相关功效

独立二项比例的规划近似可用`p̂≈N(p,p(1−p)/n)`；以观察p̂代入是plug-in误差估计。边界比例或稀有事件时正态近似可能失效，应采用适当二项计算或模拟，不能让p̂=0给出的零方差成为停止收样的依据。

等效检验先确定有实际意义的界限[−Δ,Δ]。TOST分别检验差≤−Δ与差≥Δ，两个单侧检验都拒绝才支持相应等效；相同条件下等价于100(1−2α)%区间完全落在等效界内。普通差异检验不显著不能代替此结论。正态单侧阈值用z_(1−α)，双侧用z_(1−α/2)。

检验独立Pearson相关相对0的近似规划，可用Fisher尺度`n≈3+[(z_(1−α/2)+z_(1−β))/atanh(ρ)]²`，注明目标ρ、功效1−β和单双侧。依赖观测、非零零假设、秩相关或复杂层级需适配计算；样本量是对应独立对象数，不是同题重复总数。

**核对与判定：** 样本量对应真实推断单位，关键假设清楚。未显著结果的解释依赖效应区间；用观察效应计算“事后功效”不能补上缺乏信息的问题。

<a id="g5"></a>
### G5 研究者自由度

提示搜索、材料筛选、重试、排除、阈值选择和模型选择都会改变结论。把影响结果的选择规则与预算写清，保留候选和实际处理；技术失败重试、模型拒答和看分后择优应分别统计。

训练或调参用开发材料，最终评价使用未参与选择的数据。预处理、特征筛选和阈值也属于拟合过程，必须在对应训练折内完成。探索可以改变方案，但报告中要说明改变后的目标和使用过的数据。

<a id="g5-01"></a>
#### 交叉验证、袋外评价和特征归因

先按真正独立的组划分训练与评价：同题改写、同轨迹或共享来源材料应在同一折。需要类别平衡时在可行的组结构内分层。标准化、降维、特征筛选与参数网格搜索均在训练折内拟合；选择方案后用外层折或独立保留集评价。单变量F筛选连续目标可用`F=r²(n−2)/(1−r²)`，它不控制其他变量，也属于需要嵌入训练折的选择。

随机森林的OOB对每个对象只汇总未抽中该对象的树的预测，再按对象计算指标。它不同于训练内分数，也不自动替代反复调参后的独立评价。森林特征重要性可累计各节点按样本权重计的不纯度降低并跨树归一；高基数、相关特征和训练分布会影响结果。

独立背景假设下，线性SHAP可写`φ_j=β_j(x_j−E_bg X_j)`，基值为背景预测均值；相关特征下采用条件或干预背景会改变分配。全局平均绝对贡献与某个样本的有符号贡献不同，均不自动是因果作用。

<a id="g5-02"></a>
#### 候选模型与受约束选择

在相同数据与可比似然下，`AIC=2k−2ℓ̂`，`BIC=k ln n−2ℓ̂`，k为估计参数数目，n应对应似然的数据单位。候选路径、先后加项和停止规则影响最终模型；指标低表示该准则下的选择，不证明机制真实。

带等概率高/低组等约束的候选须在约束下重新拟合合法概率，再计算似然与比较统计量。逐步删除候选时保存每步集合及停止原因；若使用普通LRT，另外核查嵌套、参数边界和选择过程。为了让概率和为1而额外修正某项，会改变原优化问题，不能将任意数值修补当作原约束的最大似然解。

**核对与判定：** 主要结论没有隐含未报告的择优；不要求记录每次键盘操作。本条的交叉验证和选择方法说明怎样实际隔离选择与评价，相关多重检验见[F1](#f1)。

<a id="g6"></a>
### G6 预先设定与预注册

在查看目标结果前，写下主要问题、比较、分析单位、计分、排除、停止及分析方式，并保留日期。内部有日期的计划叫预先设定；预注册还须有内容固定且时间可核验的登记记录。

使用既有数据时说明登记前已接触哪些数据、代码和结果。实施中出现问题可修改，保留原因及原安排，把后续探索与原定检验区分。不能把事后整理的说明回写成早已登记的方案。

**核对与判定：** 时间顺序与实际知识状态相符。预注册帮助约束选择，但不保证设计正确；探索性研究也可有价值，不因没有预注册就自动无效。

## J 机器实验的具体条件

<a id="j1"></a>
### J1 模型作答与裁判评分的位置偏差

保持答案内容不变，交换显示位置或标签，再将输出还原到同一内容ID。分别检查各槽位选择率、换位后内容一致率、平局和无法解析；“都答A”不代表选择了同一答案。

两个候选可做双向交换，多候选按平衡方案覆盖位置。若标签文字也变了，区分位置与标签先验。裁判对换位结果不一致时，按预定规则保留分歧或重评，不把不一致自动当作真实质量平局。

<a id="j1-position-calibration"></a>
#### 排列先验校准

在内容不变的多种排列中读取每个显示槽位或标签的概率，估计内容平均后的先验。PriDe类方法可对各槽位的log概率跨排列取均值后softmax归一为q，对多个校准样本则先平均各自估计的先验，再以实际槽位概率除该先验并归一，最后映回内容ID。

保存每次排列、标签映射、候选总质量、零概率处理和先验估计用的数据。它依赖排列能平衡内容且先验可分离；有限排列或内容与位置交互会限制校准。若换位同时改变token标签，应明确校准的是哪一层。

**核对与判定：** 映射和分母正确，控制依据来自实际换位结果。可取得概率时采用本条的位置先验校准，同时保留原始分布。

<a id="j2"></a>
### J2 冗长偏差

先记录回答长度单位和实质内容，再判断评分是否额外偏爱篇幅。诊断时可以把同一答案写成信息尽量一致的简短版和展开版，平衡位置后比较裁判；长度与信息量同时改变时，不能单独归为偏差。

比较生成来源时可另做长度匹配或调整，报告原始与调整后胜率及共同长度范围。长度也可能是研究目标或处理效果的一部分，调整后回答的是不同问题。不可把长答案一律截断后当作无代价的公平比较。

**核对与判定：** 长度的定义、内容可比性和调整目标明确；长度与评分相关本身不足以证明裁判偏差。

<a id="j3"></a>
### J3 对用户立场的迎合

对同一问题设置中性、支持和反对立场等提示，保持事实与评分规则可比。观点题看立场互换后回答如何变化；有真值的题分别记录与用户一致及事实正确，不能合成一个无法区分的“迎合率”。

如果只在模型初次答对的题上施加错误反馈，说明这一筛选，并限定结论于该子集。合理接受新证据与迎合错误观点不同；赞同正确前提也不自动算迎合。各类题按研究目标选用，不必把所有反馈类型凑齐。

**核对与判定：** 用户意见与客观信息被分开操纵，计分和筛选清楚。无立场的默认肯定另见[E2](#e2)。

<a id="j4"></a>
### J4 自我偏好

交叉安排回答生成者与评分者，在遮蔽来源后比较同源和异源回答；另设正确、互换或无来源标签，可区分实际文本来源与显示标签的作用。保持内容质量、长度、位置及题目可比。

同模型生成并评分是需要审视的共同来源，不能直接等同于结果无效；可用执行金标、其他测量或适当交叉条件核查。不同模型家族也可能共享训练与评分偏好，不自动构成独立真值。

**核对与判定：** 来源、标签与质量没有混在一个比较中，结论限定于实际裁判和题域。独立判断及聚合过程采用[A2](#a2)的评分协议。

<a id="j5"></a>
### J5 少样本示例选择与排列

保存示例池、选择依据、标签比例、与目标题的关系及实际顺序。研究排列时保持示例内容不变；研究选材时控制或共同改变顺序并说明。比较结果同时保留题目与示例配置的变异。

示例筛选或校准使用开发数据，不能按测试成绩挑最优示例后仍称未见测试。标签先验、语义近邻和格式模仿可能各有作用，必要时设置对应控制。增加同题调用不能替代更换示例配置。

<a id="j5-01"></a>
#### 无内容与背景先验校准

无内容校准用保留相同任务框架、去掉实际内容的输入取得各标签参考概率q；对实际p可作`p′_i∝p_i/q_i`再归一。参考字符串、重复归约、零q和校准/测试隔离要说明，这一变换依赖参考能代表非内容偏好的假设。

背景中位数法在校准材料上为每个属性位置估计log概率中位数m_l，从目标题相应log概率减去m_l，再比较或归一。明确位置及跨样本、实体的汇总方式；减去log概率中位数不能改成除以平均概率。位置与标签的排列先验属于[J1的位置校准](#j1-position-calibration)。所有校准均保留原始分数，不把算法使用本身当偏差已被验证消除。

**核对与判定：** 选择与排列可还原，数据用途分开。需要概率偏好校准时使用本条的计算；校准只修正所定义的偏好，不保证所有任务偏差消失。

<a id="j6"></a>
### J6 提示敏感性

在同一批题上比较目标与评分可比的提示变体，保存完整系统、用户和工具说明。措辞、格式或角色可作为变体；否定指令或加入新证据若改变了任务含义，应作为不同条件，而非同义改写。

若目标是测稳健性，报告各变体结果及分布；若目标是选提示，在开发材料上固定指标和搜索预算，再锁定完整提示用于后续评价。两提示答题比较可逐题记0/1并求差，重抽时带上同题两列。

<a id="j6-01"></a>
#### 信息增益与提示间分歧

问题或观测的预期信息增益为`H(prior)−Σ_a P(a)H(posterior|a)`。答案分支必须互斥完备，权重来自明确概率或先验质量；零质量分支贡献为零，不用任意填出的后验参与平均。

比较多个提示形式，令权重w_f、各形式预测p_f、混合分布m=Σw_fp_f，则`H(m)=Σw_fH(p_f)+Σw_f KL(p_f||m)`。前项反映形式内部的不确定，后项反映形式之间的分歧；只报告H(m)会混合两者。固定支持、概率来源及形式权重，不能把不同题目构成造成的变化当作纯提示敏感。

<a id="j6-02"></a>
#### 离散提示搜索与删除敏感性

用嵌入梯度为替换token提出候选时，可以根据候选嵌入与原嵌入之差的内积近似排序，再对前若干候选做真实前向计算，按实际目标选择。固定可改位置、合法字符或token集合、预算及停止条件；近似梯度分数不是最终目标值。

跨模型搜索时，应将候选还原为同一可传递字符串，再分别分词和计算各模型目标，不能直接共享不兼容的token编号。删除敏感性比较原输入与删去片段后的同一测量目标；删除会改变后续位置及末token身份，必须明确怎样对齐。得到的是对该删除操作的敏感性，不能仅据此宣称找到了唯一机制。

**核对与判定：** 变体的语义关系和选择过程明确，不能只展示最好的版本。概率形式敏感测量和有内部访问的候选搜索见本条相应方法；其优化目标与实际行为改善分开解释。

<a id="j7"></a>
### J7 长上下文信息位置效应

在总长度、内容及其他线索可比时，把关键信息放到不同位置，按题比较结果。记录模型实际可见的token范围、窗口、截断与保留规则，先确认信息确实送达，再判断是否被利用。

分块、检索和缓存压缩改变输入或计算，应作为明确条件。若主张整个窗口都能有效利用，需要相应位置覆盖；并非所有长文本实验都必须检验固定的“U形曲线”。文本缺失与模型收到却未利用是不同问题。

<a id="j7-01"></a>
#### 计算成本与截断误差

先按状态数、分支b、深度d和节点成本c计算，朴素展开约`O(cΣ_(k=0)^d b^k)`；缓存收益取决于可合并状态，分块还计块间边界。声明把哪些参数视常数，渐近复杂度不能代替硬件实测时延。

全attention输出`o=Σa_i v_i`，子集S保留质量1−ε，重归一输出`o_S=Σ_(i∈S)a_i v_i/(1−ε)`。若ε<1且同一范数下`||v_i||≤M`，有`||o−o_S||≤2Mε`。近邻top-k不自动保证ε小，须检查保留权重质量；没有这些条件时不能宣称无条件误差保证。

<a id="j7-02"></a>
#### KV缓存分区与历史检索

将缓存分为固定保留的起始token、最近窗口和可检索历史，并为各层条目保留原token位置及K/V对应关系。历史检索后，将所选条目与本轮固定窗口按位置和注意力掩码合并，避免重复条目获得额外权重。

需要连续上下文时，以检索命中点的原序列邻域扩展，而不是按相似度排序后把相邻项当成原邻居。新检索后按协议去重并移出旧队列项，逐层说明检索、邻域宽度和总预算，例如固定部分k_s加检索部分k_c。位置编码和缓存重用方式必须与实际实现一致；稀疏历史缓存提供的信息与完整前向计算不同，应分别报告。

<a id="j7-03"></a>
#### 缓存卸载与层间执行

缓存或权重卸载要记录对象所属层、token范围、所在设备、替换策略及取回时点。使用LRU等策略时，先确认下一步所需对象可用，再释放不用对象；不能覆盖仍被本次计算引用的缓存。

测量峰值内存、传输量和精度转换，并保持层执行顺序及激活所在设备明确。报告端到端时延时应包含必要的数据传输和等待；只测计算核耗时不能说明卸载方案的实际速度。缓存遗漏、取回错误与模型行为错误分开定位。

**核对与判定：** 位置、长度和内容变化可区分。本条的缓存方法仅适用于有相应内部访问的模型，普通聊天接口不能被假定执行了同样机制。

<a id="j8"></a>
### J8 解码采样与随机波动

记录实际采样开关、温度、top-p/top-k、重复惩罚、停止条件、长度预算及可见种子。不支持的参数标明，温度0也不保证远端每次完全一致。

估计给定题目的生成波动时取得新的随机抽取；固定种子重跑主要检查复现。报告每题次数，并将题内生成波动与题目差异分开。best-of-N还要保留选择器、失败和总预算；它是生成加选择的整体方法。

<a id="j8-01"></a>
#### Beam与内部奖励解码

beam保存至多b条未完成序列，每步扩展token、累加log概率，按明确长度惩罚、结束规则和确定/随机选择保留下一束。它与独立生成b个完整答案不同；接口不支持beam时不能仅靠多次调用声称实现了它。

attention奖励解码可先取top-n logit候选，对每个候选读取指定层对问题q与上下文x的attention，计算`score(t)=logit(t)+ω·Attn(q,t)/Attn(x,t)`，选最高者追加直至结束。明确候选前向、query/key方向、聚合、零分母及范围；这需要内部访问，不能用温度参数替代，也不保证普遍改善推理。

**核对与判定：** 不把一个确定输出说成输出分布，也不把重复次数说成独立模型数。序列搜索和特殊奖励解码见本条相应方法；它们与独立采样N份完整答案不同。

<a id="j9"></a>
### J9 生成重复与文本退化

先定义要数的事件：连续词组重复、循环段落、语义冗余或跨代信息流失。保留原始输出，说明分词、窗口和过滤规则；比较长短文本时按重复机会归一或使用等长窗口，若关心总负担则另报总次数。

沿生成位置或传递轮次分析变化，并与具体解码、上下文和反馈条件相连。词汇重复有时是任务要求，不能一律判退化；过滤后变好也不能抹去原始失败。机器的重复不应直接命名为真人疲劳。

**核对与判定：** 重复定义和分母一致，干预前后使用同一规则。连续片段与子序列的计算见[A2](#a2)，历史传递见[J20](#j20)。

<a id="j10"></a>
### J10 分词效应

在实际提示前缀下核对候选的token序列与预测位置，记录分词器版本、特殊词元、空格和输入预算。单独分词所得候选，可能与接在提示后时不同；多token答案不能只取首token概率当全文概率。

比较语言或拼写时，区分字符长度、token长度、语义变化与截断。困惑度依赖token单位，使用不同分词器的数值不能直接当同一量尺。控制token数也不自动消除语言与材料差异。

<a id="j10-01"></a>
#### 词形、词元与依存表示

先区分模型token、语言词及词元lemma。词形还原用实际语言模型和上下文把屈折形式归并，保存多词边界、词性和歧义处理；stemming、lowercase与lemmatization不是同一操作。

依存解析保留token节点、head、依存关系及必要词元信息。若比较带类型依存边，应说明节点如何对齐、词项是否保留，再形成匹配计数；只统计关系标签频次是另一指标。解析器错误会进入分数，句法重合也不直接证明语义一致。

<a id="j10-02"></a>
#### 序列概率、惊异度与困惑度

自回归序列`P(y|x)=∏_t P(y_t|x,y_<t)`，log概率逐步求和，surprisal取负log。采用真实目标前缀的teacher forcing评分，明确只计目标还是连提示一起计，保留loss mask、终止符和长度n。

平均负自然log似然的指数为`PPL=exp[−Σln p_t/n]`；若用log2则配2的指数。不同分词器、目标范围或长度归一使量尺改变。SLOR为`[ln P(sentence)−Σ_t ln P_unigram(token_t)]/n`，unigram参照须同分词及明确语料；它扣除词频基线，不是归一概率。

<a id="j10-03"></a>
#### 双向评分与可见目标

masked模型的PLL逐一遮蔽目标位置，以其余上下文预测真实token，再累加log概率。单token遮蔽和整词遮蔽是不同条件；伪困惑度虽可取PLL的长度平均指数，但不是自回归联合概率。

从全mask开始按某个顺序逐真实词填回，可得到该顺序下的条件概率链。不同顺序有不同条件空间；除非这些条件来自同一个相容联合模型，平均log链不能自动解释为唯一真实联合分布。

AUL类指标在目标词仍可见时读其概率，再按指定位置平均；AUL-A还使用相应attention权重。目标可见评分与遮蔽预测衡量不同东西，须说明权重是否归一，不能叫“未见词预测准确率”。

**核对与判定：** 文字、词元和读出位置一一对应。具体分词、句法表示与序列评分见本条相应方法，原始与预处理文本都应可对应。

<a id="j11"></a>
### J11 测试集污染与数据泄漏

分别检查模型预训练可能接触材料、研究者开发过程接触测试答案，以及检索/工具在运行时取到答案的路径。记录材料最早可核验的公开时间、可验证的模型训练信息和实际检查语料范围。

论文较晚发表不等于其题目更晚公开；新题也可能复用旧题结构。模型训练语料不可见时，重叠检查只能覆盖取得的语料，不能证明完全未见。提示、示例和阈值选择也需与最终评价材料隔离。

<a id="j11-01"></a>
#### 语料查询与后缀索引

固定语料版本、字符或token单位以及查询是否精确。存在性、文档频数、总出现次数和共现次数分别记录；近似服务返回空不证明整个语料不存在匹配。

n-gram条件频率可用`count(前缀+目标)/count(前缀)`，零计数时按明确规则逐级缩短前缀，记录最后采用的阶数及平滑。它是特定语料中的频率参照，不是模型输出概率。

后缀数组将全部后缀按字典序排列；查询完整序列可用边界查找定位以其为前缀的连续范围，范围大小对应出现次数。相邻后缀的最长公共前缀帮助形成重复桶，但要保留文档边界，不能把跨文档拼接当自然片段。重复检测的单位与全文成员查询分别报告。

<a id="j11-02"></a>
#### 连续匹配与语义跨度搜索

精确成员查询具有子串闭包：长片段存在时其子片段也存在。双指针可从起点i和终点j开始，匹配则延长j；不匹配则推进i，并令`j=max(i+L,j)`保持最短长度L，用缓存避免重复查询，保留每次匹配范围。

语义相似并不保证子串闭包。对查询和文档token的相似矩阵，缓存查询到各位置的匹配、前缀和及反向最大值；枚举长度至少L的连续候选跨度，在该跨度内分别计算两个方向的平均最大匹配，只有两向均满足定义阈值才返回。前缀和可快速求固定逐位置量的区间和，但更换跨度会改变的最大值仍须正确更新。查询复杂度由编码、匹配矩阵与候选区间数共同决定，不能按精确双指针的单调性偷省语义候选。

<a id="j11-03"></a>
#### 加密发布材料及可复用性

发布时固定材料格式、许可和实际工作副本；使用加密方式时记录算法、参数、解密脚本、依赖及密钥取得方式。说明公众和评测模型各自能取得哪些内容。用干净目录完成解密与读取，并直接比较关键字段、记录及正文，确认发布包能还原预期材料。

检查实际发布页面、预览及版本历史是否存在明文，并保持发布版本与本地工作材料的对应。加密和发布约定可以控制访问路径，但若公开流程允许取得明文，就不能据此证明模型从未接触材料；污染判断仍依赖[J11](#j11)所列时间和暴露证据。

**核对与判定：** 所声称排除的泄漏路径有具体依据。本条的查询与发布方法服务于这一检查；加密公开材料只改变获取方式，不构成未污染证明。

<a id="j12"></a>
### J12 基准饱和

当一组模型在固定基准上接近上限时，检查它还能否区分关心的差异。看逐题分布、剩余错误及同题配对差的区间；不能用差值与单个模型的误差条比较代替差值的不确定性。

可以增加更难开发题、查看连续分数或新的任务条件，但保留原始基准结果及新结果的范围。接近满分不意味着所有细小差异都没有意义，关键是精度与研究问题；也不意味着已经达到通用或人类水平。

**核对与判定：** 区分量尺压缩、真实小差异和样本不足。一般边界效应见[E6](#e6)。

<a id="j13"></a>
### J13 指令遵循

把指令拆成可检查的行为条件，确定各条件适用范围、冲突优先顺序和拒答编码。形式条件可用程序检查，涉及内容语义的条件采用适当的评分规则；不要求所有约束都能用字符串匹配判断。

按每条要求适用的试次报告通过率，再按原始试次报告全部适用要求同时满足的比例。任务内容正确、格式合格、动作合法与遵循优先级是不同事件，可另报联合成功，但不能互相代替。

**核对与判定：** 判据对应模型实际收到的指令，失败保留在正确分母。结构解析见[J14](#j14)，真正执行动作及反馈见[J20](#j20)。

<a id="j14"></a>
### J14 结构化输出与格式约束

运行前定义输出schema、允许值、解析及等价归一规则，说明能否修复或重试。保存原始文本、解析结果和失败类型。约束解码作用于生成阶段，事后解析只判断输出，两者不能混写。

以原始试次为分母报告首次格式合法率、首次格式合法且内容正确率；另在格式合法输出中报内容正确率。允许修复时保留尝试链和成本，另报最终可用率，不能只统计修好后的样本。

<a id="j14-01"></a>
#### 代码生成、执行与结果判定

把一次代码执行绑定到程序版本、实际输入、解释器或求解器、依赖及判分用例。保留模型原输出和实际执行代码；从代码块抽取、补入口或修复语法都算中间转换，应能看出执行了什么。返回值、标准输出、异常、退出状态和用例结果分开记录。

“生成了代码”“能解析”“运行结束”“通过指定用例”是四种不同结果。缺库、超时或服务不可用不能直接判成推理错误；程序正常退出也不等于答案正确。资源上限和可访问文件按实际执行环境设定，用例只支持其覆盖范围内的结论。需要修改后重试时保留各次输入、修改和返回，不能只报告最终成功版本。

**核对与判定：** 结构合法不等于内容或程序正确。代码、逻辑和工具产物需真正运行时，按本条的执行桥接回收结果，再交给[A2](#a2)计分。

<a id="j15"></a>
### J15 安全边界下的拒答与稳健性

在明确边界的评测材料上，先定义应该回答和应该拒绝的请求、模型可见信息及判分规则。对正常请求统计过度拒答，对不当请求统计适当拒答和不当回应；不能仅以拒答越多判越安全。

比较已有变体或防护条件时，记录查询预算、重试、选择与对话历史，在意图可比的材料上配对。模型的礼貌措辞与实际是否给出不当内容分开判断；正常任务效用同步保留。

**核对与判定：** 威胁条件、分母和判据清楚，结论只覆盖实际测试条件。不预设所有模型一定存在同一种漏洞，也不要求为每项机器实验加入安全攻击测试。

<a id="j16"></a>
### J16 模型作为被试的范式定位

研究对象先定义为具体模型及其输入、输出、状态和运行条件。区分可观察行为规律、任务参照模型下的参数和内部机制证据。把机器任务命名为记忆、偏好或推理时，应说明实际操作和解释范围，不能以名称证明人类心理过程存在。

模型可作为比较因素，也可在有抽样依据时作为推断单位；大量对话并不自动构成大量个体。使用已有的人类评分或脑数据作为机器输出的外部参照，不等于本手册负责设计真人对照实验。

<a id="j16-01"></a>
#### 线性attention的形式参照

指定理论输入E为(d+1)×(N+1)，前N列含(x,y)，query列标签0。形式前向`f(E)=E+W_PV E(EᵀW_KQ E)/ρ`保持同维，取右下角预测；ρ=N是某一参照设定，不能当所有Transformer公式。

在`x~N(0,Λ)`、独立任务`w~N(0,I)`等假设下，总体平方风险可展开为迹及加权Frobenius逼近。设`Λ=Q diag(λ_i)Qᵀ`降序，秩≤r的指定最优块为`U*=cQ diag(v_i)Qᵀ`、`u*=1/c`，前r项`v_i=N/[(N+1)λ_i+trΛ]`，其余0，c≠0。缩放由目标权重决定，不能换成普通PCA截断；零特征值等退化按模型条件处理。

风险展开使用Gaussian四阶矩`E[x_i x_j x_k x_l]=Λ_ijΛ_kl+Λ_ikΛ_jl+Λ_ilΛ_jk`。独立零均值标签噪声使交叉项消失，分别计有限context方差、噪声、遗漏信号与缩放偏差。仅小秩已覆盖全部信号时，增加r至r′的额外风险可写为`(sᵀDs+σ²)/M·Σ_(i=r+1)^r′[Nλ_i/((N+1)λ_i+trD)]²`；一般增加维度也会增加信号收益。解析最优不证明经验训练收敛。

<a id="j16-02"></a>
#### 非线性模式覆盖与投影界

一种parity参照为`g=Σ_h a_h ReLU(yᵀXW_hx_q/N)`、|a_h|≤1，目标`E max(0,1−y_qg)+λΣ_h||W_h||²_F`。总体期望、N→∞与λ→0⁺是理论设定，不是0/1准确率或已运行的优化日志。

在特定加权模式覆盖构造中，d=2^ν；用j−1的ν个二进制位定义第h个对角矩阵元素`(2bit_h(j−1)−1)/(4γ)`、输出系数−1，再加对角恒为`−ν/(4γ)`且系数+1的单元；每个单元加入矩阵相反、系数相同的配对，共2(ν+1)个。经正交dictionary G转为`W_h=GV_hGᵀ`。正负模式覆盖给出此设定的单元下界，不能泛化到任意任务。

重要任务优先的一个充分条件是`0<p_T<(1/4−γ)/{[d(d−1)/2](1/4+γ)+1/4−γ}`且0<γ<1/4。覆盖集合可嵌套，但随ν变化的权重不能原样复制。有限M的集中误差如`O(√[(ν/M)ln(1/δ)])`中δ是理论失败概率；噪声投影满足`E||Pε||²=tr(PΣ_ε)`，各向同性时为`σ² rank(P)`。维数比可描述期望噪声能量比，不是准确率比。

<a id="j16-03"></a>
#### 明确定义的注意力参照模型

写出参照模型的轴和运算。例如token独热矩阵X为V×T，嵌入E为d×V，`H=EX`，`Q=W_QH`、`K=W_KH`、`V_h=W_VH`；按列对key维归一化，`A=softmax(KᵀQ/√d_a)`，`Z=V_hA`。需要的因果掩码、输出投影和选取位置须与具体模型一致。

若参照使用绑定词表读出，可由`EᵀZ`的目标列得到logit再softmax。只有设定中确实包含的残差、层归一化等步骤才加入模型；线性注意力与softmax注意力不能互换。此处的可计算参照用于明确机制假设，不替代实际大模型的实现说明。

**核对与判定：** 行为、形式基线和机制推断各有对应证据。本条的理论模型须连同其输入分布、维度与极限条件使用，不把解析结论当作所有LLM的实测性质。

<a id="j17"></a>
### J17 能力变化与指标阈值

观察规模、训练进程或预算变化时，同时保留原始输出及其计分方式。硬阈值可能使连续变化表现为跃升；在可行时用同一批输出计算有意义的连续指标，并检查取值间隔和不确定性。

连续指标下较平滑不证明所有能力跃升都是假象，二值曲线突变也不证明出现新的内部机制。若模型点很少，明确哪些曲线解释仍无法区分。平滑或插值仅用于展示时不增加实际观测。

**核对与判定：** 指标转换、模型间隔与曲线结论相符。形式模型的规模结论还需[J16](#j16)的假设，统计和显示处理见[F1](#f1)。

<a id="j18"></a>
### J18 代理指标的过度优化

有显式优化或按分数选候选时，记录优化对象、搜索空间、预算和选择规则。再用未直接参与该选择、且能反映目标质量的证据比较不同优化强度，查看代理分数与目标表现是否分离。

独立判据可以是可验证结果、保留任务或其他合适测量，不必是人类评分。反复查看保留集并据此修改方案，会把它变成新的开发信号。优化分数上升本身不能证明真实质量上升。

**核对与判定：** 代理和目标有明确区别，评价没有暗中成为优化输入。若独立判据不足，只报告代理改善及其边界，不预设必然发生奖励过优化。

<a id="j19"></a>
### J19 评估可复现性与版本依赖

保存能还原实际实验的模型和分词器标识、接口日期、材料、完整提示、工具、解码、评分程序及可用种子。不能取得的训练或服务端设置标明未知；无需为了表面完整虚构配置。

同题多次采样分别统计题数和每题次数；比较模型或提示时按题号对齐，保留原始输出及失败。重抽数据估计样本波动，重新调用模型估计运行波动，两者不是同一操作。固定种子一次重现也不能证明所有环境下结果相同。

**核对与判定：** 关键版本和数据链条能接上，复现范围如实说明。区间按[F1](#f1)的目标计算；材料公开需要兼顾可获取性与污染边界，见[J11](#j11)。

<a id="j20"></a>
### J20 多轮交互、记忆与一致性变化

以环境的真实状态为准，逐轮记录模型看见什么、输出什么、实际执行了什么，以及结果怎样进入下一轮。固定或操纵历史、记忆、工具权限、反馈和终止规则，检查截断与重置的实际效果。

一致性指同一约束、偏好或事实承诺在适用条件下是否维持；根据新证据合理更新不算无条件失败。私密信息、共同反馈和多agent交互会产生依赖，不能把每条消息当独立样本。模型声称完成动作，不等于环境已经执行。

#### 检索排序与候选上下文

TF-IDF以当前文档词频乘参照语料上的逆文档频率，说明平滑、归一和词表；文档频率是出现该词的文档数，不是总词频。BM25常对查询词求和`IDF(t)·tf(k1+1)/[tf+k1(1−b+b·dl/avgdl)]`，保存所用IDF变体、分词、k1、b和语料版本。

向量检索把查询和候选放入兼容空间，以明确距离排序；记录索引近似、候选数、分块、去重、重排和返回片段。候选文档排名与最终输入的片段不同，需保存模型实际收到的上下文。检索不到与已检得但无答案分开；检索得分不是事实支持概率。

#### 有限信念、通信传递与交替抽样

有限世界H上的更新为`π(h|d)=π(h)L(d|h)/Σ_hπ(h)L(d|h)`，硬相容过滤是0/1似然。分母为零表示假设空间与观测不相容。若正确消息概率1−ε、错误有|Y|−1种，均匀错误似然为ε/(|Y|−1)，不是每种错误都取ε。

通信实验另定义谁持有当前后验、怎样发送和重建、哪些成功样本写入缓冲、何时更新及下一代如何初始化。后验复制、模型生成示例传递和按成功筛选数据是不同机制；保留各阶段可见信息，不能从仿真规则推定LLM执行了同样更新。

交替抽样可用最新T采S~p(S|T)，再用最新S采T~p(T|S)。只有两条件与同一联合分布相容、链具有合适遍历性并达到所需状态时，才解释为该联合抽样。初值、多链、舍弃段、混合和样本依赖均须考虑；条件不相容时可以研究该过程，但不能称预设联合分布的无偏样本。

#### 状态搜索与分阶段候选展开

BFS保存队列、访问集合和父指针，按合法动作逐层扩展；单位成本时首次目标给最短步数，不等成本需相应算法。每个动作有前提与效果，状态等价决定去重。反向规划从目标回归前提，再验证完整初态合法；部分状态可对应多个完整世界却共享最优计划，不必强迫额外提问。

ToT先生成thought候选并评分/投票，再生成action候选、评分并执行合法转移，保存下一前沿。空间链可维护chain、target、unused关系，连接后移除已用关系。自由文本候选先验证合法，不能把生成两段文本等同于两条可执行边。

束宽b的广度搜索每层合并候选并保留评分最高的b个，到目标或深度上限停止。保存束宽、深度、评分、剪枝及预算；剪枝可能丢失最优路径，局部投票不是穷尽。部分初态任务须比较所有相容完整状态的可行/最优计划集合，判断哪些信息真有助于决策。

#### 树搜索对手

MCTS每次模拟从根按树策略选择，遇未展开合法行动则扩展，按规定rollout到终局或截断，再沿路径更新访问数N与回报Q。常见UCT为`Q_i+c√(ln N_parent/N_i)`，未访问节点按规则探索；所有回报要统一玩家视角。

达到预算后按访问最多或价值最高等预定规则落子，说明是否复用树。记录探索常数、rollout、终局/平局及随机状态；随机行动基线不含这些更新。不完全信息游戏只向搜索提供角色可见信息，不能无意读取对手隐藏状态。

<a id="j20-05"></a>
#### 问答树与价值回传

节点保存真实加模拟历史及可能集合Ω。问题扩展YES/NO互斥分支，各分支更新Ω；检查两子集不交且并为原集。分支概率按先验质量，仅均匀先验时才用数量比。问题节点可再生m个候选，递归至预算或深度限。

一种协议向下累加局部奖励Ru为Ra，叶Re=Ra；答案节点按答案概率加权子价值，问题节点取m个候选均值，根候选再取最大。将问题均值换最大，或用路径奖励乘积选择首问，会改变优化目标。记录实际使用的累加、均值、最大或乘积，不能相互代替；模拟回答正确性也限制结果解释。

#### 随机递推与停止点判断

对`e_t=(1−γα_t)e_(t−1)−γε_t`，若α与过去误差独立、噪声独立零均值且`E||ε||²=dσ²`，令`a=(1−γEα)²+γ²Varα`，则`M_t=E||e_t||²=a M_(t−1)+γ²dσ²`。a≠1时`M_t=a^tM0+γ²dσ²(1−a^t)/(1−a)`，a=1为线性累积。

a<1有有限稳态，但固定a与噪声下，曲线由初值相对稳态决定单调升或降，不能自行推出唯一U形最优停止轮。主张内部最优点需加入实际存在的时变、相关或不同目标并重新推导。先核对维度、零噪声、系数符号及极限，再决定能否用作停止规则。

<a id="j20-07"></a>
#### 环境状态与行动循环

交互任务按“当前状态→可见观察→模型输出→解析行动→环境转移→新状态”运行。环境维护权威状态；模型说自己获得奖励、移动成功或完成任务，不会自动改变环境。分别定义行动合法性、解析失败处理、步数上限、成功条件和终止条件。

多臂赌博机需固定各臂奖励分布、切换规则、强制探索阶段，以及奖励在行动后何时反馈。多智能体同时行动时，各参与者应从同一轮状态取得各自观察，先提交本轮行动再统一结算；先公开某人的结果再让其他人行动，已经改变了信息条件。

<a id="j20-08"></a>
#### 私有信息、公共讨论与群体决定

为每个参与者规定可读、可写和可转发的信息。私有观察、私有提交与公共讨论分开保存；公开内容限于实验约定的消息，不能把未公开的内部推理当作其他参与者可见材料。按阶段明确输入截断、发言顺序、轮次、投票及平票处理。

终止短语只是流程信号，是否达成协议仍按协议条件判定：软性一致可以要求可接受提案相同；显式接受制度则要求各方接受同一个有效提案。成员构成、共享反馈和彼此可见的历史影响群体结果，统计时以实际独立群体或完整交互为单位，不能把相互影响的消息当作独立样本。

<a id="j20-09"></a>
#### 检索证据进入模型的过程

记录实际查询、检索服务和调用时点，并区分返回的是摘要片段、全文、结构化字段还是服务生成的答案。清理、去重、重排和截断后，保存真正送给模型的上下文及其来源对应关系；只记录原网页而不记录模型看到的片段，无法解释检索条件。

没有命中、命中后抓取失败、取得材料但没有答案应分别标记。来源链接不一定需要展示给模型，但研究记录应能定位证据。需要比较检索策略时，控制模型、任务和预算，并将检索改变与后续提示改变分开说明。

<a id="j20-10"></a>
#### 摘要记忆与外部记忆读写

摘要记忆要说明选取哪些历史、摘要目标、生成和写入时点、原消息来源及读取预算。保留被替换的历史与实际摘要；摘要中的归纳属于压缩后的解释，不能视为原话。比较有无记忆时，说明模型实际可见的是全文、摘要还是查询结果。

外部记忆接口分别定义读取、搜索、新增、更新的实际存储效果。核心记忆可以持续进入提示，档案记忆通常需要查询；两者不可混称为模型已知。检查无命中、同名条目、时间顺序、写入失败和遗忘策略的处理。记忆库更新、缓存命中和模型权重训练属于不同机制。

<a id="j20-11"></a>
#### 谈判提案与结算

将贡献计算、分配提案、接受或拒绝、反提案和实际结算分开。每个提案有明确版本、总量和可行性约束；只有共同接受的有效版本才能进入结算。未达成一致时按事先确定的退出或保底规则处理。

Shapley值等贡献估计可以作为提案依据，但不自动等于最终支付。保存接受的是哪一版提案，以及最终收据或环境结算结果；模型承诺付款与实际转移不能合并为同一个成功指标。

<a id="j20-12"></a>
#### 自适应对手匹配

自适应匹配需要保存候选集U、已入池集合R、比赛结果、当前评分和选择规则。以一种SWIM式流程为例：初始化一批参考对象；随机取新对象P，令s=|R|，比较次数c=ceil(max(log₂s,1))。第一位对手随机选；每次比赛后重新拟合Bradley–Terry评分，再从尚未交手的参考对象中选与P评分最接近者，完成剩余比较后将P加入R。

记录随机种子、同分选择、失败比赛和对手耗尽的处理。每一场只能使用当时已有结果选择对手，不能用最终评分倒推匹配。瑞士轮等其他制度有不同分组和轮次规则，不因同样使用动态评分就视作同一方法。

<a id="j20-13"></a>
#### 等待、回调与虚拟时间调度

调度器区分可运行、运行中、等待时间、等待token、等待回调和完成状态。只合并执行条件兼容的请求；一次执行到主动让出或完成，之后按规定顺序恢复已经就绪的请求。全部阻塞时，按所定义的时钟或token补充规则推进，不能把等待直接当作失败。

回调需说明注册、触发、过期、重复、取消及任务结束后的清理。提前触发、漏触发和正确触发分别判分。虚拟时间由哪些操作累加、起点是什么、与真实耗时是否对应，都要明确；只在进程内推进的虚拟时钟不能支持关于外部真实等待行为的结论。

**核对与判定：** 轨迹从输入到状态更新完整相接，失败、未成交、超时及非法动作各有结果。本条的协议把检索、外部记忆、搜索和调度接入实际运行；这里只规定实验方法，不要求使用者开发某一种固定平台。
