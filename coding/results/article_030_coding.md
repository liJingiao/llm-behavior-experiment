# article_030 | MR-Ben: A Meta-Reasoning Benchmark for Evaluating System-2 Thinking in LLMs | 2024

研究类型概述：这是一项面向 LLM 的基准构建与评测研究：作者构建 5,975 个带人工错误分析标注的 question-solution pairs，要求被评模型判断解答正确性、定位首个错误步骤并解释错误原因；主要分析单位是被评模型在题目/学科上的聚合 MR-Score，辅以 zero/one-shot、self-refine、correctness prior 等提示条件比较。研究不是人类被试实验，而是 LLM-as-evaluated / LLM-as-judge 的观察性基准评测。
- **研究构念（Construct）**：元推理与系统2错误监测（meta-reasoning and error monitoring）｜CA 构念锚定：元认知（metacognition, `trm_4a3fd79d0a920`）；错误监测（error detection, `trm_4a3fd79d0a20c`）；行为监控（performance monitoring, `trm_4a3fd79d0ac30`）
- **实验任务与范式（Task / Paradigm）**：这是一项面向 LLM 的基准构建与评测研究：作者构建 5,975 个带人工错误分析标注的 question-solution pairs，要求被评模型判断解答正确性、定位首个错误步骤并解释错误原因；主要分析单位是被评模型在题目/学科上的聚合 MR-Score，辅以 zero/one-shot、self-refine、correctness prior 等提示条件比较。研究不是人类被试实验，而是 LLM-as-evaluated / LLM-as-judge 的观察性基准评测。｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）

## 编码小结
论文在任务定义、评分公式、人工标注流程和 prompt 公开方面较充分，但大量人类实验设计组件不适用于该基准评测。主要风险在于：使用公开 MMLU/LogiQA/MHPP 题目但未做污染检测；闭源模型 snapshot、重复运行和置信区间报告不足；提示敏感性与 GPT-4 代理评分自偏好风险仅部分讨论；模型规模与学科比较多为描述性聚合，缺少随机效应/项目级推断。
