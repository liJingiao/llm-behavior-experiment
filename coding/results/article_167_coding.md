# article_167 | Cross-Care: Assessing the Healthcare Implications of Pre-training Data on Language Model Bias | 2024

研究类型概述：这是一项针对大语言模型疾病—人口群体表征偏差的基准评测/观察性比较研究：比较 The Pile 共现、多个开源模型的 logits 排序、真实世界 CDC/NHIS 患病率排序，并跨语言、模板、模型规模与对齐方法做描述性比较；无人类被试、无随机分配、无训练干预。
- **研究构念（Construct）**：疾病与人口群体关联中的表征偏差、社会刻板印象传播与现实知识失准｜CA 构念锚定：刻板印象（stereotypes, `trm_4a3fd79d0b285`）；态度（attitude, `trm_4a3fd79d09947`）；社会认知（social cognition, `trm_4a3fd79d0b13d`）
- **实验任务与范式（Task / Paradigm）**：对现成Pythia、Mamba、Llama、Mistral和Qwen系列checkpoint输入疾病与人口群体模板，读取下一词logit，并与The Pile共现分布及CDC真实患病率排序比较。｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）

## 编码小结
研究设计是 LLM 基准评测而非人类实验。模板、语言、疾病与人口关键词构成受控刺激条件，模型、对齐方法和规模多为观察性比较。报告较完整地操作化了共现、logits 与真实患病率指标，并提供公开代码与模板；但统计推断、信效度、跨语言 tokenization 控制、重复采样/CI、预注册与分析层级处理不足。
