# article_181 | Do as We Do, Not as You Think: the Conformity of Large Language Models | 2025

研究类型概述：这是一项面向 LLM 多智能体系统的基准评测与实证消融研究：作者构建 BenchForm（基于 BBH 的多选题），设置 Raw、Correct Guidance、Wrong Guidance、Trust、Doubt 五种交互协议，评测 11 个代表性 LLM，并用 accuracy、conformity rate、independence rate 量化从众与独立性；随后考察交互轮数、多数派规模、行为解释以及两类 prompt 缓解策略。分析单位主要是题目/协议/模型，而非人类被试。
- **研究构念（Construct）**：多智能体群体从众、独立性与群体压力｜CA 构念锚定：社会规范加工（social norm processing, `trm_58c80b824c51b`）；社会认知（social cognition, `trm_4a3fd79d0b13d`）；态度（attitude, `trm_4a3fd79d09947`）
- **实验任务与范式（Task / Paradigm）**：让目标LLM在其他代理先给出一致或分歧答案后重新作答，并在五种交互协议中观察其是否放弃原判断。（改变交互轮次、多数派规模、其他代理答案结构、目标代理persona和反思提示。）｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）

## 编码小结
研究提出了清晰的 LLM 从众评测框架、协议和指标，并公开了较完整 prompt 与部分可复现信息；但整体以描述性比较为主，缺少正式的因子统计检验、随机效应/项目推广建模、功效分析、操纵检验、信效度证据以及若干 LLM 评测风险控制。多数心理实验设计中的人类分配/顺序组件不适用；LLM 特有的位置偏差、采样随机性、污染、格式合法率与多轮上下文控制仅有部分或完全未报告。
