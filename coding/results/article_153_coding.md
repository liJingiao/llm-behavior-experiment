# article_153 | Shapley-Coop: Credit Assignment for Emergent Cooperation in Self-Interested LLM Agents | 2025

研究类型概述：这是一项面向自利 LLM 多智能体的计算/工程评估研究，提出并比较 Shapley-Coop 工作流：在 Escape Room、Raid Battle 和 ChatDev 三个模拟场景中比较 LLM-only、LLM+NEG、LLM+STS、LLM+SC 等配置，并以成功率、个体收益、贡献分、奖励分配和 WEV 等指标评估合作与信用分配。没有人类被试，分析单位为模拟团队/LLM 智能体/角色。
- **研究构念（Construct）**：自利代理在社会困境中的合作形成、议价、贡献归因与分配公平｜CA 构念锚定：社会认知（social cognition, `trm_4a3fd79d0b13d`）；决策（decision making, `trm_4a3fd79d0a038`）；信任（trust, `trm_N7MLgAsJBIbiQ`）
- **实验任务与范式（Task / Paradigm）**：让现成LLM代理在Escape Room、Raid Battle和ChatDEV中以异质私人收益行动，比较无协商、普通协商、短期Shapley推理和完整Shapley-Coop四种条件。｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）

## 编码小结
论文提出较完整的 Shapley-Coop 多智能体合作与价格匹配框架，并在三个计算场景中展示结果；但实验报告在随机化、重复运行、采样参数、完整 prompt、统计推断、信效度、随机效应和可复现性方面明显不足。多数适合人类实验设计的组件在本研究中不适用；适用于 LLM 智能体实验的组件则普遍存在关键报告缺口。
