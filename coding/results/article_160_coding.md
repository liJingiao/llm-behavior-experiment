# article_160 | Do Language Models Exhibit the Same Cognitive Biases in Problem Solving as Human Learners? | 2024

研究类型概述：LLM-as-participant 的认知偏差基准实验：围绕算术文字题生成配对问题，分别操纵一致性/不一致性、迁移/比较、进位/无进位等题目特征，比较多种基座与指令微调模型在 direct、CoT 等提示方式下的答案正确率与 CATE。分析单位主要是同一模型下的问题对/试次，而非人类被试分配。
- **研究构念（Construct）**：算术文字题中的一致性偏差、迁移—比较偏差与进位效应｜CA 构念锚定：认知启发式（cognitive heuristic, `trm_4a3fd79d09d58`）；锚定（anchoring, `trm_4a3fd79d09833`）；决策（decision making, `trm_4a3fd79d0a038`）
- **实验任务与范式（Task / Paradigm）**：让现成LLM解决受控生成的算术文字题，并分别隔离文本理解、解题规划和计算执行三个步骤。（系统改变关系词与所需运算的一致性、迁移/比较关系结构及是否需要进位。）｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）

## 编码小结
论文的核心优势是神经符号生成管线实现了严格的题目特征配对与质量控制，并用 500 个问题对、配对 t 检验和 FDR 校正检验模型是否存在类儿童偏差。主要不足是缺少测量信效度、效应量置信区间、功效分析、预注册、精确 API snapshot/重复采样，以及未用多层模型处理题目与模型的聚类结构；部分人类实验设计组件因无人类被试分配、无顺序呈现、无主观量表而不适用。
