# article_195 | Certifying Counterfactual Bias in LLMs | 2025

研究类型概述：这是一项 LLM 公平性/反事实偏差的认证与基准评估研究，不是人类被试实验。分析单位是从前缀分布中独立采样的 counterfactual prompt set；研究比较多个 LLM、两个数据集（BOLD 与 Decoding Trust）以及三类前缀分布（随机 token、jailbreak 混合、embedding 空间 jailbreak 扰动），用偏见检测器得到二值结果，再用 Clopper-Pearson 区间估计“无偏响应概率”。
- **研究构念（Construct）**：反事实偏差和人口属性变化下的刻板印象反应｜CA 构念锚定：推理（reasoning, `trm_4a3fd79d0aec1`）；问题解决（problem solving, `trm_4a3fd79d0adb7`）；刻板印象（stereotypes, `trm_4a3fd79d0b285`）
- **实验任务与范式（Task / Paradigm）**：为只在性别或种族属性上不同的反事实提示集合采样随机、越狱混合或嵌入扰动前缀，调用多个现成模型并检测回答之间的偏差。（操纵人口属性、前缀分布、越狱类型、模型和数据集，并比较无前缀与有前缀条件。）｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）

## 编码小结
论文提出了可复现的认证框架，形式化定义、采样算法、检测器与置信区间报告较清楚，并对部分检测器效度和解码超参做了验证/消融。主要不足是：多项人类实验设计组件不适用；提示/模板版本、随机种子、精确模型 snapshot、多重比较、污染检查与跨材料随机效应报告不足；若干比较仍是描述性认证界，而非完整推断统计。
