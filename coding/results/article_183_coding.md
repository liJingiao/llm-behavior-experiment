# article_183 | B-score: Detecting biases in large language models using response history | 2025

研究类型概述：纯 LLM 基准/观察性比较研究：在 8 个 LLM 上比较单轮与多轮（可观察自身历史回答）条件下的答案分布，提出 B-score 作为偏差检测指标，并在自建题集与 MMLU、HLE、CSQA、BBQ 上评估答案验证效果；无人类被试。分析单位主要是模型—问题—答案/重复运行，而非人类被试组。
- **研究构念（Construct）**：选择偏差、反应历史敏感性以及多轮条件下的自我纠偏行为｜CA 构念锚定：推理（reasoning, `trm_4a3fd79d0aec1`）；决策（decision making, `trm_4a3fd79d0a038`）
- **实验任务与范式（Task / Paradigm）**：对同一问题分别进行30次独立单轮询问和一次连续30轮重复询问，让模型在后者中看到自身历史答案，比较各选项分布的变化。（操纵单轮或多轮回答历史、问题类别、选项数量和模型，并比较B-score、回答概率与自报置信度。）｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）
