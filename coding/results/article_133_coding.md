# article_133 | Walk the Talk? Measuring the Faithfulness of Large Language Model Explanations | 2025

研究类型概述：方法学/LLM 评估研究：提出因果概念忠实性定义，用辅助 LLM 生成概念级反事实，并用贝叶斯分层模型估计概念因果效应与解释隐含效应的对齐程度；在 BBQ 与 MedQA 上评估 GPT-3.5、GPT-4o、Claude-3.5-Sonnet 等模型的解释忠实性。分析单位为问题/概念干预/LLM 响应，不是人类被试实验。
- **研究构念（Construct）**：解释忠实性，以及模型口头解释与实际因果决策依据之间的系统偏离｜CA 构念锚定：推理（reasoning, `trm_4a3fd79d0aec1`）；问题解决（problem solving, `trm_4a3fd79d0adb7`）
- **实验任务与范式（Task / Paradigm）**：对BBQ和MedQA问题抽取概念、生成保持其他内容不变的反事实版本，重复采样GPT-4o、GPT-3.5和Claude-3.5-Sonnet的答案与解释，并在问题级和数据集级比较CE与EE。｜CA 任务锚定：CA 无直接任务条目（属社会调查/多轮交互/LLM 特定行为评测范式，依 v1.6 H.4/H.5 标注具体实验任务）
