# article_199 | Working Memory Capacity of ChatGPT: An Empirical Study | 2024

研究类型概述：LLM-as-participant 的实证基准/行为评测研究：用言语与空间 n-back 任务评估 ChatGPT 的工作记忆容量，并在同一模型上比较 n 负荷、任务变体、网格大小、抽象空间推理及多个 LLM 模型。没有人类被试分配；分析单位主要是每种条件下 50 个 block 的聚合指标（hit rate、false alarm、accuracy、d′）。
- **研究构念（Construct）**：工作记忆容量、干扰控制和n-back负荷下的容量极限｜CA 构念锚定：工作记忆（working memory, `trm_4a3fd79d0b5a7`）；工作记忆刷新（working memory updating, `trm_55b6b9a666604`）
- **实验任务与范式（Task / Paradigm）**：GPT-3.5逐试次完成文本化verbal和ASCII网格spatial n-back，并在多个现成模型上复测基线。（改变n-back负荷、刺激类型、噪声、反馈、CoT、空间网格和被测模型。）｜CA 任务锚定：n-back 任务（n-back task, `tsk_4a57abb949bcd`）

## 编码小结
论文对 n-back 任务、刺激构造、提示模板与主要指标有较清楚的操作化，并提供了代码仓库；但整体是描述性评测，缺少操纵检验、信效度证据、随机化/顺序平衡、功效分析、预注册、模型 snapshot 与污染/可复现性细节。多数人类实验设计组件不适用于本研究的 LLM 分析单位；与 LLM 评测相关的提示敏感性、采样随机性、格式约束、可复现性、多轮上下文等只得到部分报告。
