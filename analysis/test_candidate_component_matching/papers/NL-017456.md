## 需求与组件对应

<a id="d01"></a>

### D01 区分工具性钥匙与无用钥匙，并保持匹配网格结构

作用：设计与操作。对应状态：已对应。

论文事实 F01：KeyDoor必须取钥匙开门；KeyNoDoor移除门使钥匙无用；2PathKey有两条最优路、一条放无用钥匙，并用结构相同无钥匙网格匹配控制；前两环境100条轨迹，后者100对。

- **A1 自变量**：自变量：钥匙功能与存在。门、钥匙及路径关系被改变 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L159–220）。
- **A8 水平数与类型**：水平数与类型：三种环境及有无钥匙。具名环境限定各条件 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L589–649）。
- **C4 匹配**：匹配：匹配网格结构。2PathKey与无钥匙控制保持结构相同 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L1566–1625）。

依据：
- [F01 · §4.3](../evidence/NL-017456.md#f01-e01)，原文LF行329–370：matched control grid with identical structure but no key

### D02 用目标成功、取钥匙与轨迹重叠表达可观察目标导向

作用：测量与分析。对应状态：已对应。

论文事实 F02：结果报告到达目标、取钥匙、动作最优性及非最优动作朝钥匙的比例；对应轨迹用唯一状态动作集合的Jaccard相似度衡量重叠。

论文事实 F03：同一起点网格的两条轨迹按唯一状态动作对的交并集定义Jaccard。

- **A2 因变量**：因变量：成功/取钥匙/Jaccard。明确行为指标和集合重叠计分 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L221–281）。
- **A7 操作性定义**：操作性定义：隐含目标的行为定义。无功能钥匙仍引导动作是操作定义，不是内部意图证明 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L528–588）。
- **G1 分析单位**：分析单位：轨迹与动作不同分母。取钥匙按轨迹，朝钥匙按非最优动作计 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L2900–2959）。

依据：

- [F03 · AppB2](../evidence/NL-017456.md#f03-e01)，原文LF行1047–1056：Jaccard Similarity Index
