# NL-005130 · Persona-E²: A Human-Grounded Dataset for Personality-Shaped Emotional Responses to Textual Events

时间状态：窗内依据已核。领域：C、S。

模型在一般观察者、BFI人格及BFI+CoT条件中报告相同事件的前两种情绪，与对应人类组标签比较。

**本次范围：**RQ2相同事件下General、BFI人格及BFI+CoT提示的情绪报告，与真人人格组标签对照。

**范围外：**不纳入RQ3给定情绪后的事后理由生成；不把角色报告认作模型真实情绪。
