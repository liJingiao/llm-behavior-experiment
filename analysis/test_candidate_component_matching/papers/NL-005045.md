# NL-005045 · When Personalization Legitimizes Risks: Uncovering Safety Vulnerabilities in Personalized Dialogue Agents

时间状态：窗内依据已核。领域：S。

在有害请求中提供主题性个人记忆，并与无个人信息的相同模板对照，比较有害输出标签；另以人工标注核验检测器。
