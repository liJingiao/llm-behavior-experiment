# NL-005124 · Location Not Found: Exposing Implicit Local and Global Biases in Multilingual LLMs

时间状态：窗内依据已核。领域：S。

向模型提出未指定地点的平行多语言问题，按答案与各地区标准的匹配统计默认地区偏好，并校正共享答案。

**本次范围：**地区歧义多语言问答的隐含地区偏好，以及碰撞校正的全球/地区指标。

**范围外：**不纳入新训练，也不把base/instruct差异当训练过程因果证据。
