# NL-012949 · DAG-Math: Graph-of-Thought Guided Mathematical Reasoning in LLMs

时间状态：窗内依据已核。领域：C、M。

正式ICLR论文用固定LLM的结构化CoT实际输出，对比只看最终答案与要求逻辑闭合的推理计分，分析错误轨迹的分支/依赖结构；有明确推理构念和测量有效性研究对象，非仅通用正确率排行。所选实验通过提示完成，无新参数训练。

**本次范围：**固定模型数学DAG格式CoT的答案正确率与逻辑闭合PRR比较，含同题32/128次轨迹。

**范围外：**不把报告的图结构等同真实内部思维或每步数学验证。
