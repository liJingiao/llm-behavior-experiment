# NL-010489 · Reading between the lines: LLMs match or exceed human empathic accuracy using text alone

时间状态：窗内依据已核。领域：S。

三模型只读12个希伯来语故事文本，推断八种情绪强度，以讲述者自评为参照并与人类文本/视频条件比较。

**本次范围：**三个固定LLM纯文本推断12故事讲述者情绪，与讲述者自评和人类两种材料条件比较。

**范围外：**不混入后续每故事10000次Gemini独立提示扩展作为初轮重复。
