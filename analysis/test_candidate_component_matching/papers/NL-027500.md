## 需求与组件对应

<a id="d01"></a>

### D01 保持攻击文本和目标一致，改变指令进入的用户/资料渠道

作用：设计与操作。对应状态：已对应。

论文事实 F01：PI与CUP使用相同攻击目标、输入模板和字符串；PI来自检索资料，CUP来自共享会话另一合法用户。

- **A1 自变量**：自变量：来源渠道。检索文本与另一合法用户 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L159–220）。
- **A8 水平数与类型**：水平数与类型：PI/CUP两个水平。两进入路径明确 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L589–649）。
- **C3 恒定**：恒定：相同目标模板字符串。保证攻击内容恒定 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L1506–1565）。

依据：
- [F01 · §5.1/Table4](../evidence/NL-027500.md#f01-e01)，原文LF行574–585：same attack objectives, input templates, and inputs

<a id="d02"></a>

### D02 按用户任务归属测错误执行攻击指令

作用：测量与分析。对应状态：已对应。

论文事实 F02：ASR按良性任务中执行攻击指定动作序列计分，需该执行发生在服务映射到良性任务的用户时；普通任务成功另按确定性最终环境状态判断。

- **A2 因变量**：因变量：攻击成功率。仅良性任务执行攻击动作计入 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L221–281）。
- **A7 操作性定义**：操作性定义：跨用户作用域失败定义。区分合法给某用户的指令和错误用于其他用户 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L528–588）。
- **J15 越狱稳健性**：越狱稳健性：对抗条件攻击成功。明确指定攻击动作的程序化ASR [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L4069–4122）。
- **J13 指令遵循**：指令遵循：指令适用范围与行为判据。工具状态与动作序列检验是否错误遵循 [组件定义](../../literature_component_coverage/baselines/实验组件_v1.4.md)（L3961–4014）。

依据：
- [F02 · §4.2](../evidence/NL-027500.md#f02-e01)，原文LF行464–477：serving some benign user
