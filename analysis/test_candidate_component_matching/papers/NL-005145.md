# NL-005145 · LLMs (Almost) Never Abstain Under Medical Uncertainty

时间状态：窗内依据已核。领域：D、C。

通过移除正确答案、隐藏题干与可弃答选择，直接比较现成模型在不确定信息下的过度承诺和信心-选择分离；窄单元为纯文本Table2及§5.1。

**本次范围：**纯文本Table2及§5.1的移除正确答案后题干可见/隐藏弃答，含自报信心与选项位置支撑检查。

**范围外：**不纳入多模态任务或将所有错误选项等同现实临床危害。
