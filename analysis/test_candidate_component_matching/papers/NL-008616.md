# NL-008616 · TALES: A Taxonomy and Analysis of Cultural Representations in LLM-generated Stories

时间状态：窗内依据已核。领域：S。

窄S：固定模型独立生成本地文化故事，经文化内行系统标注文化不准确/刻板化/过度简化等模式；地区/语言条件和文化表征策略正式比较。人类是输出评判者，不是模型与真人互动；总体错误含语言错误，不能都算文化偏见。

**本次范围：**TALES的文化故事生成与当地文化内行的跨度分类，比较地区/语言和模型表征。

**范围外：**不纳入由已发现错误改写的TALES-QA为知识因果证据。
