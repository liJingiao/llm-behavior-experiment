# NL-005079 · REST: Stress Testing Large Reasoning Models by Asking Multiple Problems at Once

时间状态：窗内依据已核。领域：C。

将多道题循环连接成同一提示，让各题轮换位置，观察负载、题目序号与答题正确性及推理长度的关系。

**本次范围：**REST既有模型在多题连接提示中的负载和题目位置准确率，含循环移位构造及逐位置统计。

**范围外：**不纳入权重训练效果或把长输出本身认作思维失调。
