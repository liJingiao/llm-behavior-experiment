# NL-005125 · LLMs in Sarcasm Detection? It’s elementary! (Or is it?)

时间状态：窗内依据已核。领域：C。

固定模型对自然、合成与人类示例引导的混合语料作讽刺二分类，比较混淆矩阵和错误方向；另有人审标签核验。

**本次范围：**自然、合成及人类示例引导混合语料的讽刺识别差异；含二分类输出和小样本标注核验。

**范围外：**不把tSNE或LIME解释分支作为心理机制证据。
