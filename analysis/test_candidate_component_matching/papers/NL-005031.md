# NL-005031 · LiveCultureBench: a Multi-Agent, Multi-Cultural Benchmark for Large Language Models in Dynamic Social Simulations

时间状态：窗内依据已核。领域：S。

在本地文化规范的文本社会模拟中，逐步记录目标完成和规范违反，按人物画像及轨迹统计两者的关系。

**本次范围：**LiveCultureBench既有文化画像的规范遵从与任务完成轨迹；含规范评分和每画像一条模拟的直接支撑。

**范围外：**不纳入新代理训练或把全部环境验证另立行为单元。
