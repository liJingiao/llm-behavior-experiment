## F01 · 依据1 · §3 injection

原文LF行：202–217。

````text
Injection. To test whether VEA shifts model behaviour, we injected two types of strings into model
CoTs: sentences expressing evaluation awareness (VEA sentences), and control sentences containing
meta-cognitive or process-related thoughts unrelated to evaluation (control sentences). All injection
results compare VEA injections against control injections on the same prompts.
For each model, we sampled 5 benchmark-agnostic VEA sentences from that model’s own rollouts.
We generated additional VEA sentences for GPT-OSS-120b, Qwen3-32b, Nemotron-3-super, Kimi-
K2.5, and DeepSeek-R1, since we found few benchmark-agnostic sentences in their CoTs. For
control sentences, we prompted each model to generate 10 short meta-cognitive sentences, of which
we randomly sampled five. For a full list of VEA and control sentences see Appendix D.
Sentences were injected into the CoT at the beginning and after ∼ 1/3 of characters. In the latter
case the exact injection point was set after the end of a sentence or paragraph to preserve the natural
flow of the CoT. We kept the original CoT until the injection point, added the sentence and resampled
from there onwards. This yielded 10 new combinations per prompt per sentence type (5 sentences ×
2 positions), which we collapsed into one per injection position using majority vote on answer labels.
We only injected into the subset of model rollouts that do not contain VEA naturally, allowing us to
directly compare model outputs on the same prompts with and without VEA content.
````

## F02 · 依据1 · §3 removal

原文LF行：219–229。

````text
Removal. We compared two conditions applied to the same original CoTs that contain VEA. In
the removal condition, we truncated the CoT right before the first sentence containing VEA and
resampled from that point until the CoT no longer contained any VEA. We used a temperature of 0.8
for resampling, since temperature 0 would reproduce the original continuation verbatim. We repeated
this process until the model finished reasoning without evaluation awareness, or a maximum of 20
resampling attempts was reached. CoTs still containing evaluation awareness after 20 iterations were
excluded from the analysis. Resampling attempt counts per model are in Appendix E.
In the control condition, we truncated the same original CoT right after the first sentence containing
VEA and resampled with a temperature of 0.8. This preserves the truncation and resampling procedure
but leaves VEA intact. We only included items where VEA removal succeeded, so that both conditions
are evaluated on the same set of prompts.
````

## F03 · 依据1 · §3 statistical analysis

原文LF行：260–277。

````text
For off-policy experiments, as with the on-policy analysis, all comparisons are within-prompt: each
condition pair refers to the same benchmark prompt. For the injection experiments, we compared
INJECTED EA against INJECTED C ONTROL; for the removal experiments, we compared REMOVED EU
against REMOVED C ONTROL. All results in the main text use the injection position after ∼1/3 of
characters, unless specified, which better reflects where VEA occurs naturally (see Figure 10 in
Appendix G). We excluded prompts where either the intervention or control condition produced an
invalid output (e.g., incomplete reasoning trace), yielding different sample sizes per benchmark (see
Tables 15 - 18, Appendix H).

Statistical Analysis. All comparisons are paired: each prompt appears in both (unaware/aware)
conditions. We used the Stuart-Maxwell marginal homogeneity test for all benchmarks, with post-hoc
per-category McNemar tests corrected via Bonferroni. For the safety benchmark, we additionally
report mean harm scores compared via Wilcoxon signed-rank test. We report Cohen’s ω as the effect
size throughout, and rank-biserial r for mean harm score comparisons. Sample sizes range from
2,756 to 3,542 for injection, 678 to 2,582 for on-policy, and 144 to 760 for removal experiments.
Given these sample sizes, we interpret effect sizes rather than p-values as the primary indicator of
practical significance. Confidence intervals are nonparametric bootstrap 95% CIs over prompt-level
paired differences (10,000 resamples).
````
