## H.1　Cognitive Atlas 的数据模型，以及它与本清单字段的对应

Cognitive Atlas 把一个范式拆成四层，这四层与本清单「详细例子」的字段几乎一一对应。以 `Stroop task`（`tsk_4a57abb949e27`）为例，API 返回：

| CA 层 | Stroop task 的实际内容 | 本清单对应字段 |
|---|---|---|
| **task**（任务） | Stroop task | 范式/任务 |
| **conditions**（条件） | congruent / neutral / incongruent | IV 及水平；刺激与材料 |
| **indicators**（指标） | accuracy；time to complete task | DV 与计分 |
| **contrasts**（对比） | incongruent minus congruent；incongruent minus neutral；incongruent minus congruent depending on the congruency condition of the previous trial | 预期结果模式 |
| **concepts**（构念，经 `ASSERTS` 关系） | conflict detection；response inhibition；selective attention；conflict adaptation effect | 关键构念（A7 操作性定义、F3 构念效度） |

这一层级结构提示：**任务名本身不足以确定所测构念；构念由“任务 × 条件对比 × 指标 × 计分规则”共同决定**。以 Stroop 为例，`incongruent minus congruent` 这类对比通常用于操作化冲突监测或反应抑制，而 `incongruent minus congruent depending on the previous trial` 更指向冲突适应效应。  
但这不意味着所有任务都必须使用条件相减；单条件容量分数、阈限值或问卷总分等操作化方式，应改用相应的指标与计分规则说明。

> **可直接写进清单的推论**：对**以条件对比为因变量的实验范式**，A7 要求“把构念写成可操作的程序”时，不能只写到“用 Stroop 任务测量抑制控制”，还应说明**哪个条件减哪个条件**。  
> 对单条件容量分数、阈限值或问卷总分等操作化方式，应改为说明对应的指标与计分规则。

### H.2.0　构念通俗解释

> **说明**：这一节先给每个构念一句“人话版”解释，帮助非专业读者理解后面表格里的术语。  
> 这些解释不是 Cognitive Atlas 原文，而是本清单为便于使用而写的通俗版本。  
> 如果你想看 CA 原始页面，可以把对应 ID 拼到：  
> `https://cognitiveatlas.org/concept/id/<ID>/`

| 构念 | 通俗解释 |
|---|---|
| working memory | 在脑子里临时存住信息并同时操作它的能力，比如心算时既要记住数字又要算结果 |
| short-term memory | 很短时间内记住少量信息的能力，比如刚听到一个电话号码还没拨出去 |
| long-term memory | 把信息长期保存下来的记忆，比如几年后还记得的老朋友名字 |
| episodic memory | 记得“某次具体经历”的记忆，比如昨天和谁吃了饭、在哪儿吃的 |
| semantic memory | 记得“知识”的记忆，比如知道巴黎是法国首都 |
| declarative memory | 可以用语言说出来的记忆，比如事实、概念、经历，例如“我知道今天是周五” |
| procedural memory | 记得“怎么做”的记忆，比如骑车、打字、系鞋带，通常很难用语言完整描述 |
| explicit memory | 有意识想起来的记忆，比如主动回忆昨天发生了什么 |
| implicit memory | 不用刻意回忆就表现出来的记忆，比如重复做某件事时越来越熟练 |
| encoding | 把外界信息转成大脑能存的形式，相当于把资料“录入”记忆系统 |
| memory retrieval | 把已经记住的信息取出来用，相当于从记忆里“调档” |
| recall | 不给提示或只给很少提示，主动把信息想出来，比如默写单词表 |
| recognition | 看到东西时认出“以前见过”，比如选择题里认出正确答案 |
| forgetting | 记忆随时间或干扰变弱，想不起来或认不出来了 |
| proactive interference | 旧学习内容干扰新学习，比如学过“ABD”，再学“ABC”时容易写错 |
| retroactive interference | 新学习内容干扰旧记忆，比如学了一个新电话号码后忘了旧号码 |
| rehearsal | 在脑子里重复信息，让它不容易消失，比如反复默念一串数字 |
| elaborative rehearsal | 不是简单重复，而是把信息和已有知识建立联系，比如用故事串起单词 |
| chunking | 把零散信息打包成大块，比如把一长串数字拆成几段来记 |
| deep processing | 关注信息的意义而不是表面形式，通常记得更牢 |
| working memory updating | 随着情况变化替换脑子里的旧信息，比如算到下一步时丢掉前一步的中间数 |
| serial learning | 按顺序学习一串项目，常用于看系列位置效应 |
| association learning | 学会两件事之间的联系，比如看到闪电就想到雷声 |
| pavlovian conditioning | 通过配对刺激形成条件反射，比如铃声一响狗就流口水 |
| attention | 选择并维持对某些信息的加工，忽略别的信息 |
| selective attention | 在多个刺激中只关注一个，比如在嘈杂餐厅里听清对面的人说话 |
| divided attention | 同时做两件需要注意力的事，比如边开车边听导航 |
| sustained attention | 长时间保持专注，比如一直盯着一页书或一直听讲 |
| spatial attention | 把注意力指向某个空间位置，比如注意屏幕左边还是右边 |
| attention capacity | 一次能处理多少注意信息，相当于注意力的“带宽” |
| attentional resources | 注意力这种有限资源，会被任务占掉 |
| processing capacity | 大脑一次能处理的信息量上限 |
| capacity limitation | 容量有限，超出就记不住或算不清 |
| inhibition of return | 已经看过的地方，注意力反而暂时不愿再回去，像被“标记为已经查过” |

| visual search | 在一堆东西里找目标，比如在货架上找某个牌子 |
| cognitive control | 用意志和策略管理自己的反应，而不是自动反应 |

| updating | 用新信息替换脑子里旧的信息，不一定是工作记忆专有 |
| planning | 想好一系列步骤再去做，比如先查路线再出发 |

### H.3.6　任务操作化解释

> **说明**：本节为 v1.5 新增。CA ID 只解决“命名锚定”和“可追溯”问题，不能替代实验操作化说明。  
> 因此，这里为 H.3 的每个任务补充：
> **目的构念、材料与流程、关键 DV / 对比、操作化解释要点**。  
> 解释为常见实验用法，非 Cognitive Atlas 原文；具体研究中仍应按实际程序、条件与计分规则重新写。

#### H.3.6.1　注意与执行控制

| 任务 | 操作化目的 | 典型材料 / 流程 | 关键 DV / 对比 | 操作化解释要点 |
|---|---|---|---|---|
| Stroop task | 测色词干扰下的抑制控制 | 色词以一致 / 不一致 / 中性墨色呈现 | 不一致 − 一致 RT；正确率 | 干扰量越大，抑制控制越弱；不能只写“用 Stroop 测抑制”，必须写清条件对比与指标 |
| color-word stroop task | 同 Stroop，偏色词版本 | 色词命名或色词判断 | 不一致 − 一致 RT | 与 Stroop task 本质相近，属重复条目；应避免混用两种计分口径 |
| Eriksen flanker task | 测侧抑制与反应冲突 | 中央靶刺激两侧出现一致 / 不一致侧翼 | 不一致 − 一致 RT；错误率 | 侧翼冲突反映干扰控制；注意区分“侧翼冲突”与“Stroop 冲突” |
| Simon task | 测空间—反应相容性冲突 | 刺激位置与反应键不一致 / 一致 | 不相容 − 相容 RT | 反映空间编码与反应选择冲突；不等同于语义抑制 |
| go/no-go task | 测对罕见刺激的抑制能力 | 高频 go 刺激中插入低频 no-go 刺激 | no-go 上的虚报率；go RT | 适合测冲动性 / 反应抑制，但需区分抑制失败与注意力失效 |
| stop signal task | 测主动停止能力 | go 试验中偶发 stop 信号 | stop-signal reaction time；停止失败率 | SSRT 越短，抑制越强；不能只报 no-go 错误率 |
| antisaccade/prosaccade task | 测眼动控制与注意定向 | 中央线索后靶点出现在同侧或对侧 | 正确眼动率、潜伏期 | antisaccade 需抑制反射性看向线索，prosaccade 反射性眼动作基线 |
| task-switching | 测认知灵活性与任务转换 | 在两套规则间交替，如数字 / 字母判断 | switch trial − repeat trial RT / 正确率 | switch cost 越大，转换能力越弱；需控制规则频率与准备时间 |
| Wisconsin card sorting test | 测规则发现与定势转换 | 按颜色 / 形状 / 数量分类卡片，规则隐性切换 | perseverative errors；完成类别数 | 高持续错误提示定势转换困难；不能直接等同于“执行功能总分” |
| Posner cueing task | 测注意定向与提示效应 | 有效 / 无效 / 中性空间提示后呈现靶刺激 | 无效 − 有效 RT | 提示效应反映注意定向；无提示与中性提示的差值可拆分 alerting / orienting |
| visual search task | 测视觉搜索效率 | 目标与干扰项混合呈现，集合大小变化 | RT × 集合大小斜率 | 斜率越平，搜索越高效；需区分 pop-out 与 serial search |
| conjunction search task | 测特征绑定搜索 | 目标由两个以上特征共同界定 | RT × 集合大小斜率 | 反映 feature binding；不等同于一般视觉搜索 |
| attention networks test | 同时拆分警觉、定向、执行控制 | 提示 × flanker 冲突组合 | alerting / orienting / executive 子分数 | 子分数来自特定 RT 差，不能混作一个总分 |
| attentional blink paradigm | 测时间注意瓶颈 | RSVP 序列中两个靶刺激间隔不同 | T2 正确率随 lag 变化 | lag 1 sparing 与后续 dip 反映时间注意分配，不等于持续注意 |
| dichotic listening task | 测选择性注意与注意通道 | 双耳同时呈现不同信息，要求追随一耳 | 追随耳正确率；非追随耳侵入率 | 可考察选择性注意与自动加工；不能把非追随耳报告简单当作无意识觉知 |
| sustained attention to response task | 测持续注意与反应抑制 | 高频 go 中偶发 no-go，要求不反应 | commission errors；RT 变异性 | 适合测持续性注意失效与冲动性；虚报率高提示抑制不足 |
| PEBL Perceptual Vigilance Task | 测警觉与简单反应时 | 长时间简单 RT 任务 | RT 中位数、最慢 RT、lapse 数 | 用于疲劳或睡眠剥夺研究；简单 RT 不等于一般智力或工作记忆 |
| negative priming task | 测先前忽略刺激的抑制残留 | 忽略刺激在下一试次成为目标 | negative prime − control RT | RT 变慢说明抑制残留；需排除单纯重复效应 |
| psychological refractory period paradigm | 测加工瓶颈与双任务干扰 | 两个任务以不同 SOA 依次呈现 | RT2 随 SOA 缩短而增加 | 短 SOA 下 RT2 延长反映加工瓶颈或资源竞争 |
| dual-task paradigm | 测注意资源与中央执行 | 同时或交替完成两个任务 | dual-task cost：双任务 − 单任务 RT / 正确率 | 需明确两任务的优先级与干扰来源，不能泛称“测注意” |

#### H.3.6.2　记忆与学习

| 任务 | 操作化目的 | 典型材料 / 流程 | 关键 DV / 对比 | 操作化解释要点 |
|---|---|---|---|---|
| free word list recall | 测自由回忆与系列位置效应 | 学习词表后立即或延迟自由回忆 | 总回忆数、首因 / 近因成分 | 近因反映短时维持，首因更多依赖长时加工；不应只报总分 |
| episodic recall | 测具体情景记忆 | 回忆特定过去事件及细节 | 细节数、来源正确率、主观 vividness | 情景记忆强调时空情境与自我参照，不等同于词表回忆 |
| immediate recall test | 测即时保持 | 学习后立即回忆 | 正确项数 | 适合测短时保持；不能与延迟记忆混用 |
| delayed recall test | 测保持间隔后的遗忘 | 学习后延迟测试 | 延迟 − 即时回忆下降率 | 更能反映长时保持或遗忘；必须报告延迟时长 |
| recall test | 一般回忆能力 | 提示线索后回忆项目 | 正确回忆数 | CA 将其窄化为 articulatory loop，过于可疑；不应直接采信 |
| recognition memory test | 测再认记忆 | 旧 / 新项目判断 | hits、false alarms、d′ | 必须拆分敏感性与反应偏向，不能只报正确率 |
| item recognition task | 测项目再认 | 单个探测项旧 / 新判断 | d′、RT | 与 yes/no 信号检测框架一致；需明确旧新比例 |
| Sternberg Item Recognition Task | 测工作记忆扫描 | 记忆集后呈现探测项 | RT × set size 斜率 | 斜率反映扫描效率；需区分序列与并行搜索模型 |
| encoding task | 测编码过程中的加工差异 | 不同深度或类型的编码任务 | 编码条件之间的后续记忆差异 | 编码任务只处理学习阶段；DV 通常来自后续记忆测试 |
| Incidental encoding task | 测无预期编码 | 学习阶段不告知会有记忆测试 | 意外回忆 / 再认成绩 | 适合测自动编码；要防止被试猜到后续测试 |
| paired associate recall | 测联想记忆 | 学习词对后以一词线索回忆另一词 | 正确配对数 | 反映联结形成，不只是项目记忆 |
| paired associate learning | 测联想学习与干扰控制 | 反复学习配对，含干扰对 | 学会所需试次、干扰错误 | 适合测学习速率与前 / 后摄干扰 |
| California Verbal Learning Test-II | 测言语学习策略与干扰 | 多次学习同一词表，随后插入干扰词表 | 学习斜率、语义聚类、延迟回忆、错误类型 | 不只是“记忆总分”，应报告策略与干扰成分 |
| Rey Auditory Verbal Learning Task | 测听觉言语学习 | 多次听觉呈现词表后延迟回忆 | 学习斜率、延迟回忆、再认 | 常用于临床记忆评估；需区分获得、保持与提取 |
| directed forgetting task | 测有意遗忘与提取抑制 | 标记“记住 / 忘记”项目后测试 | 忘记项 − 记住项回忆率 | 有意遗忘不等于自然遗忘；需区分 item-cue 与 list-cue 范式 |
| n-back task | 测工作记忆刷新 | 判断当前刺激是否与 n 步前相同 | 正确率、RT、d′ | n 越高负荷越大；须报告 n、刺激概率与伪重复率 |
| operation span task | 测工作记忆容量 | 简单运算与词回忆交替进行 | 正确回忆词数；运算正确率 | 需控制加工速度，防止只测简单短时记忆 |
| reading span task | 测言语工作记忆 | 阅读句子并回忆句末词 | 正确回忆数；理解正确率 | CA 将其链接到 visuospatial sketch pad，疑为错标；应按言语工作记忆解释 |
| listening span task | 测听觉工作记忆 | 听句子并回忆关键项 | 回忆正确数；听觉理解率 | 与阅读广度平行，但应区分通道效应 |
| complex span test | 测复杂工作记忆容量 | 加工任务与记忆项目交替 | 总正确回忆数；加工正确率 | 反映“容量 + 干扰控制”，不是纯存储广度 |
| digit span task | 测短时 / 工作记忆容量 | 顺向或逆向复述数字序列 | 最大正确跨度 | forward span 偏存储，backward span 更接近操作控制 |
| memory span test | 测一般记忆跨度 | 系列呈现后立即回忆 | 最大跨度 | 应写明材料类型与顺序要求，不能泛称“记忆能力” |
| delayed match to sample task | 测延迟期间的信息维持 | 呈现样本，延迟后比较测试项 | 延迟正确率；RT | 延迟越长越依赖维持能力；需区分匹配与不匹配试次比例 |
| Change Detection Task | 测视觉工作记忆容量 | 先后呈现两个阵列，判断是否变化 | K 容量估计、正确率 | 适合容量估计；需控制阵列大小与暴露时间 |
| pavlovian conditioning task | 测条件反射形成与消退 | 中性刺激反复与无条件刺激配对 | 条件反应出现率、消退曲线 | 需报告配对次数、消退与自发恢复；不能只报“学过” |
| Morris water maze | 测空间学习与记忆 | 水迷宫中寻找隐藏平台 | 逃逸潜伏期、路径长度、穿台次数 | 动物范式；应控制游泳速度与动机，不能只看潜伏期 |
| serial reaction time task | 测内隐序列学习 | 反应一个序列中的刺激 | RT 随练习下降；随机段 RT 上升 | 内隐学习不等于外显知识；可配合生成任务测意识 |

#### H.3.6.3　语言

| 任务 | 操作化目的 | 典型材料 / 流程 | 关键 DV / 对比 | 操作化解释要点 |
|---|---|---|---|---|
| lexical decision task | 测词汇通达 | 判断字符串是否为真词 | word − nonword RT；正确率 | RT 受词频、邻居密度与语义启动影响；应控制词频 |
| word recognition task | 测词形识别 | 呈现真词 / 非词或干扰词 | 正确率、RT | 识别不等同于理解；需说明呈现时长与词汇控制 |
| contextual semantic priming task | 测语境对语义通达的影响 | 先呈现语境或启动词，再判断靶词 | 启动条件 − 控制条件 RT | 语义启动不能直接等同句法启动；v1.5 只作近似映射 |
| semantic decision task | 测语义加工 | 判断词语是否属于某语义类别 | 类别判断 RT / 正确率 | 适合测语义知识或语义分类策略；需控制熟悉度 |
| picture naming task | 测语义—词汇—语音转换 | 看图并说出名称 | 命名潜伏期、错误类型 | 分数受词汇频率、物体熟悉度与语音复杂度影响 |
| sentence-picture matching task | 测句子理解 | 听或读句子后选择匹配图片 | 正确率、RT | 反映句子—世界映射，不是工作记忆容量；不应映射 A9 |

#### H.3.6.4　知觉与心理物理

| 任务 | 操作化目的 | 典型材料 / 流程 | 关键 DV / 对比 | 操作化解释要点 |
|---|---|---|---|---|
| psychophysics task | 测感觉阈限或辨别能力 | 用恒定刺激 / 极限 / 阶梯法调整强度 | 阈限、JND、PSE | CA 条目过粗，只保留 ID 不够；必须写明方法、强度与判断规则 |
| target detection task | 测目标觉察与注意容量 | 在干扰中判断目标是否出现 | hits、false alarms、RT | 必须拆分敏感性与标准；不能只报“检测率” |
| contrast detection task | 测视觉对比敏感度 | 在噪声或掩蔽中觉察光栅 | 75% 正确阈限 | 适合视知觉与掩蔽研究；需报告空间频率与噪声参数 |
| dot motion task | 测运动方向判断或知觉决策 | 随机点群中有不同比例一致运动 | 正确率、RT、阈值 | 需控制相干率和决策标准；不能把正确率直接当“智力” |
| Tone Detection (JND) | 测听觉差别阈限 | 比较两个音的频率或强度差异 | JND | 适合心理物理阈值研究；应报告适应、试次与反馈 |
| mental rotation task | 测空间转换能力 | 比较旋转角度不同的图形是否相同 | RT × 角度斜率；正确率 | 斜率反映心理旋转效率；不能把正确率当作空间能力总分 |

#### H.3.6.5　决策、推理、社会与自评量表

| 任务 | 操作化目的 | 典型材料 / 流程 | 关键 DV / 对比 | 操作化解释要点 |
|---|---|---|---|---|
| Iowa Gambling Task | 测风险决策与强化学习 | 在不同收益 / 损失牌组间选择 | net advantageous score；学习曲线 | 应报告 block 或 trial 分数；总分掩盖学习过程 |
| temporal discounting task | 测跨期选择 | 在“即得小奖”与“延迟大奖”间选择 | 折扣率 k 或 AUC | 需报告延迟、金额与任务顺序；折扣率不等于冲动性本身 |
| Ultimatum Game (UG) | 测公平规范、利他与惩罚 | 提议者分配，回应者可接受或拒绝 | 拒绝率、出价比例 | CA 未列构念，解释需自证；拒绝率受愤怒、规范与文化影响 |
| Trust game (TG) | 测信任与互惠 | 投资者投资，受托人返还 | 投资金额、返还率 | 信任与可信度是两个构念，必须分开测量与解释 |
| prisoner's dilemma (PD) | 测合作与冲突决策 | 同步或交替选择合作 / 背叛 | 合作率、互惠模式 | 需报告轮次、沟通条件与收益结构；不能只用一轮游戏推断稳定倾向 |
| Moral Dilemma Task | 测道德判断与冲突权衡 | 在高冲突情境中选择是否造成伤害 | 选择比例、RT、冲突感 | 不映射当前 v1.3 的 A6/F3 范例；应单独说明理论框架 |
| theory of mind task | 测他人心理状态推理 | 推断信念、意图或情绪 | 正确率、RT | 需区分认知 ToM 与情感 ToM；避免把智力或语言能力混入 |
| Implicit Association Task | 测类别—评价联结强度 | 兼容与不兼容分类配对 | D-score；块间 RT 差 | D-score 反映相对联结强度，不是直接测态度或偏见；需报告信度与块序 |
| NIH Toolbox General Life Satisfaction Survey | 测整体生活满意度 | 自评生活满意程度 | 总分或因子分 | 属自陈量表；需报告量表版本、信度与计分方向 |
| Positive and Negative Affect Scale | 测正性与负性情感 | 自评近期情绪状态 | PA / NA 子量表分 | 正负情感不是单一维度两端；需分开解释 |
| deductive reasoning task | 测逻辑推理 | 根据前提判断结论必然性 | 正确率、RT、逻辑条件类型 | 应区分演绎推理与概率判断；报告内容效度与规则类型 |
| analogical reasoning task | 测关系映射与类比推理 | 比较 A:B 与 C:D 的关系结构 | 正确率、RT | CA 仅链到 semantic memory，不足以解释该任务；应按类比推理描述 |
| Raven's Advanced Progressive Matrices | 测抽象推理与流体智力 | 补全图形矩阵模式 | 正确题数、反应时 | CA 未链 fluid intelligence，不能仅靠 ID 支撑构念解释；需说明难度与计分 |

## H.5　覆盖缺口与数据质量——为什么不能把 CA 当作构念—任务关系的权威

### H.5.1　量化证据（本次全量遍历 857 个任务所得）

| 指标 | 数值 |
|---|---|
| 任务总数 | 857 |
| **未链接任何构念的任务** | **298（34.8%）** |
| 每个任务平均链接构念数 | 1.66 |
| 构念总数 | 918 |
| **至少被一个任务链接的构念** | **463（50.4%）** |

即：**约三分之一的任务没有说明自己测量什么，约一半的构念没有任何任务可以测量它**。`measures` 这条本该是本体核心的关系，实际上是稀疏的。

### H.5.2　具体错例（均为 API 原样返回）

| 任务 | CA 断言测量 | 问题 |
|---|---|---|
| `free word list recall` 自由词表回忆 | working memory; emotional memory; chunking | **漏掉 episodic memory 与 recall**——自由回忆的主要测量对象完全未列；"情绪记忆"是材料属性而非该范式所测构念 |
| `reading span task` 阅读广度任务 | sentence processing; visuospatial sketch pad | **漏掉 working memory**；言语任务却链到"视空间模板"，与 Baddeley 模型相反 |
| `recall test` 回忆测验 | articulatory loop | 仅链"发音回路"，等于把一个通用回忆测验窄化为语音回路测量 |
| `analogical reasoning task` 类比推理任务 | semantic memory | **漏掉 analogical reasoning 本身**（该构念在库中存在，`trm_4a3fd79d09810`） |
| `recognition memory test` 再认记忆测验 | explicit memory; working memory retrieval | "工作记忆提取"用于长时再认测验属误标 |
| `directed forgetting task` 定向遗忘任务 | working memory; updating; maintenance; proactive interference | 未链 `intentional forgetting`（`trm_4a3fd79d0a689`），该构念正为此范式而设 |
| `Raven's Advanced Progressive Matrices` | （空） | 流体智力的标准测验，未链 `fluid intelligence` |

### H.5.3　重复与分裂条目

- `Stroop task`（`tsk_4a57abb949e27`）与 `color-word stroop task`（`trm_4b1968619b00b`）是同一范式的两条记录，构念集不同（前者 4 个含 selective attention，后者 2 个含 decision making）。全库另有 6 条 Stroop 变体。
- `Wechsler Adult Intelligence Scale-Revised` 出现两次（`tsk_4a57abb949f04`、`tsk_4a57abb949f12`，名称仅差一个连字符空格）。
- 构念侧同样有重复：`implicit learning` 两条（`trm_4a3fd79d0a527`、`trm_565bce2791089`）、`risk aversion` 两条（`trm_4a3fd79d0b642`、`trm_55ce71c47f37b`）。

### H.5.4　系统性领域偏差

CA 的任务侧明显偏向**认知神经影像与临床神经心理测验**（NIH Toolbox、WAIS/WISC 分测验、Penn 系列、CANTAB、各类 fMRI localizer 占相当比例），对以下三类内容覆盖薄弱或为零：

1. **经典社会心理学范式**：认知失调、从众、旁观者、独裁者博弈、服从——构念或有或无，任务基本为零。
2. **经典心理物理学方法**：绝对阈限、恒定刺激法、极限法、量值估计——仅有一条极简 `psychophysics task`（有 conditions，但无 indicators / concepts）。
3. **方法学构念**：顺序效应、练习效应、需求特征、社会赞许、共源方差、安慰剂——这些是本清单 C、D、E 三节的主题，CA 作为"认知本体"原则上不收录它们。唯一的例外是 `response bias`（`trm_559f0a129c136`），但它只被 2 个任务链接。

**结论**：CA 能覆盖本清单的 A、B、G 三节中的认知范式，基本不能覆盖 C、D、E 三节（控制与偏差），完全不能覆盖 J 节（LLM）。

## H.6　对本清单的四条具体建议

### 建议 1（A7）：把「条件对比」写入操作性定义的基本要件（限对比型范式）

依据 H.1。对**以条件对比为因变量的实验范式**，建议在 A7 的「判定线索」中增加：

> 仅给出任务名称（如“用 Stroop 任务测量抑制控制”）而未指明构成 DV 的条件对比（如“不一致减一致试次的反应时差”），不算达成基本要件。

这条规则不适用于单条件容量分数、阈限值或问卷总分等操作化方式。

### 建议 2（A9）：把 A9 范例改为引 CA ID 的多操作化清单

A9 是 CA 覆盖最好的一条——6 个任务（n-back、运算广度、阅读广度、听觉广度、复杂广度、数字广度）在 CA 中共指 `working memory`（`trm_4a3fd79d0b5a7`）。建议把 A9 范例 1 的"用多个范式测量同一构念"落实为这 6 个带 ID 的任务，并在「正确做法」中要求报告各操作间的会聚证据。这同时为 F3（构念效度）提供了一个现成的会聚/区分效度例子。

### 建议 3（F3）：用 CA 的覆盖缺口本身作为构念效度的反面教材

F3 现在的范例是"独裁者游戏出价操作化利他"。CA 的事实是：`altruism`（`trm_4a3fd79d097b4`）作为构念存在，但**零个任务**被断言测量它。这正是 F3 要讲的问题——构念存在于理论词汇中，却没有被公认的操作化所锚定。建议在 F3 的「判定线索」中加一条：

> 若关键构念在公认本体（如 Cognitive Atlas）中无任何被断言测量它的任务，作者有更重的举证责任说明其操作化的效度来源。

### 建议 4（全局）：引 CA ID 时必须标明只引名称、不引关系

鉴于 H.5，建议在清单中引用 CA 时统一采用如下写法，避免把 CA 的 `ASSERTS` 关系当作共识：

> 范式名称与标识符据 Cognitive Atlas（`tsk_4a57abb949e27`，2026-10-07 快照）；该任务所测构念依本清单判断，不采用 Cognitive Atlas 的 `measures` 断言。

J 节不加 CA 标识符——CA 无 LLM 条目。

## H.7　复核方式

全部数据可按下列方式复现：

```
https://cognitiveatlas.org/api/v-alpha/concept            # 全部构念（918）
https://cognitiveatlas.org/api/v-alpha/task               # 全部任务（857）
https://cognitiveatlas.org/api/v-alpha/task?id=<task_id>  # 单任务详情，含 conditions / indicators / contrasts / concepts
https://cognitiveatlas.org/api/v-alpha/concept?id=<id>    # 单构念详情
https://cognitiveatlas.org/task/id/<task_id>              # 人读页面
https://cognitiveatlas.org/concept/id/<concept_id>        # 人读页面，含「Tasks that are asserted to measure …」一栏
```

注意 `?name=` 形式的查询返回 404，只能用 `?id=`；按字母浏览的索引页为 `/tasks/<letter>/` 与 `/concepts/<letter>/`。

**本附录未核验的部分**：中文译名为本清单自拟，未对照已出版的中文译法（如《认知心理学》教材中的通行译名）；「对应组件」列为本清单的判断。两列均不属于 Cognitive Atlas 内容，使用时请按自拟内容对待。
