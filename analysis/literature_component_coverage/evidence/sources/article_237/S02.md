# Code for "Large language models should not replace human participants because they can misportray and flatten identity groups"

### Quick Guide:
#### To Run
- analyze\_results.py generates analysis\_results/all\_data.pkl
- any of the visualize\_\*.py files generates the corresponding figures

#### To Understand Analysis:
- Refer to [naming convention](#naming-convention)

### Data
- LLM-generated data: available for download [here](https://osf.io/7gmzq/?view_only=4e0c5680b0e8434eab3733115d4e506d).
- Human-generated data: due to the conditions of our IRB exemption and consent form provided, we do not release the human participant data as it is sensitive and personal. 

### Files
- files/: contains relevant files for running the code
- llm_responses/: contains a copy of the LLM-generated data (different format than the more user-friendly version listed above) that analyze\_results takes as input
- analyze\_results.py: runs the analysis on the LLM-generated and human-generated data, saving results into a pickle file that serves as input for visualize\_results.py
    - Note: Because the human-generated data is not available raw due to our consent conditions, this code is not directly runnable as is. However, we have provided the output of this file to allow running visualize\_results.py
    - Tip: To find the code relevant to specific analyses in the paper, refer to [naming convention](#naming-convention) and look to the function name, e.g., ``def different_1'' to see how analysis for whether LLMs prompted with different identities have different responses is done
- analysis_results/all\_data.pkl: contains all of the aggregated data (including human) that is generated from analyze\_results.py
- visualize\_results.py: visualizes the results based on the output of analyze\_results.py
- visualize\_promptchoice.py: shows the effect of prompt choice on ngram and SBERT embeddings. Appendix Fig. D8
- visualize\_temp.py: visualizes the temperature effect for GPT-4 and Wizard-Vicuna-Uncensored. Fig. 5
- visualize\_flatsum.py: visualizes the summary of all flattening results on the four LLMs. Fig. 4 
- utils.py: relevant utils
- llm\_prompts.py: exact prompts used for each LLM and each question
- package-list.txt: pip python packages used

### Naming convention
- Preliminaries: nums\_t\_1 in visualize\_results.py, different\_1 in analyze\_results.py: analyzes whether LLMs prompted with different identities have different responses, and whether human in-group and human out-group responses are different
    - Appendix Figs. B6 and B7
- Flatten: nums\_t\_2 in visualize\_results.py, within\_group\_2 in analyze\_results.py: analyzes the flattening and level of within-group heterogeneity
    - Fig. 4 and Appendix Fig. A3
- Misportrayal: nums\_t\_3 in visualize\_results.py, analyze\_distance\_3 in analyze\_results.py: analyzes misportrayal through the distance between LLM-generated responses to human in-group and out-group
    - Figs. 2 and 3 and Appendix Figs. A1 and A2
- Essentializing: nums\_3\_4 in visualize\_results.py, diversity\_analysis\_4 in analyze\_results.py: analyzes coverage of responses
    - Fig. 6 and Appendix Fig. A4
