# LLM心理学与行为科学文献筛选标准

- **现役版本：v1.6**
- **生效日期：2026-10-11（Asia/Tokyo）**
- **适用范围：**文献检索、摘要初筛、全文核验和最终纳入判断。
- **唯一原则：**一篇文章只有在同一个正式实验单元中同时通过来源与日期、T0、T1和E1—E4，才可纳入。

## 1. 我们要找什么

纳入对象是：使用LLM或LLM Agent开展正式、可重建的心理学或行为科学实验，研究模型在认知、判断、决策、语言、情绪、人格表现或社会条件下呈现的系统性行为规律。

仅有模型输出、任务分数、benchmark排名、工程性能提升或潜在平台用途，不足以纳入。

## 2. 来源与日期

### 日期范围

- `2023-01-01`至`2025-06-30`，首尾均包含。
- 以可核验的正式在线日期、正式会议版本日期或截止日前公开版本为准。
- 日期尚不能确认时标记为`WAIT_DATE`，不得自动排除或冒充通过。

### 来源范围

满足下列任一来源组，才进入内容筛选：

- **P：心理学期刊**：冻结JCR中`PSYCHOLOGY, EXPERIMENTAL`、`PSYCHOLOGY, SOCIAL`或`PSYCHOLOGY, MULTIDISCIPLINARY`类别前10%的期刊；
- **G：综合与跨学科期刊**：Nature、Science、PNAS、Nature Human Behaviour、Nature Machine Intelligence、Nature Computational Science、Nature Communications、Science Advances、Nature Neuroscience；
- **C：AI/HCI会议**：ICML、ICLR、NeurIPS、ACL、AAAI、CHI的主会正式完整研究论文。

来源合格只代表可以继续筛选，不代表内容已经合格。

## 3. 判定顺序

按以下顺序判断，并记录第一个决定性失败：

1. 来源和日期；
2. **T0**：实验能否用文本稳定执行；
3. **T1**：实验是否不要求自行训练、微调或更新模型；
4. **E1**：LLM是否是相关行为实验主体；
5. **E2**：是否研究心理学或行为科学问题；
6. **E3**：构念和实验是否被清楚操作化并可重建；
7. **E4**：是否报告可解释的行为结果。

最终内容资格只有`INCLUDE`或`EXCLUDE`。证据不足时使用`REVIEW`、`WAIT_FULLTEXT`或`WAIT_DATE`等过程状态，不得把缺摘要、获取失败或无免费全文直接当作排除。

## 4. T0：文本可执行

同一个候选实验单元必须同时满足：

- 模型输入是自然语言文本，或可确定性表示为文本、JSON、表格、节点—边列表或离散状态；
- 模型输出是文本、离散选择，或可由文本稳定表示的行动；
- 计分不依赖视觉、音频、视频、3D场景或具身感知判断；
- 文本化不会改变被测构念。

论文中出现图片、流程图或结果图不影响T0；关键是模型在正式实验中实际接收和产生什么。

## 5. T1：不得要求训练、微调或更新模型

### 核心规则

**使用现成模型可以；如果复现正式实验必须自行训练、微调、编辑参数，或训练正式实验必需的学习组件，则不纳入。**

T1判断的是正式实验本身，而不是文章是否在背景中讨论训练，也不是分析阶段是否使用普通统计方法。

### 允许

- 直接调用现成checkpoint或API；
- 修改prompt或system prompt；
- zero-shot、few-shot和in-context examples；
- temperature、解码、采样和重复抽样；
- RAG、外部记忆和工具调用；
- 不更新权重的推理期干预；
- 多个现成模型的投票、jury或固定组合；
- 普通统计分析、回归、混合效应模型和认知模型拟合；
- 直接使用已有Tokenizer，或比较不需要重新训练模型的现成Tokenizer／token粒度。

### 不允许

如果正式实验依赖以下任一操作，T1失败：

- 从头训练或继续预训练；
- SFT、fine-tuning或其他监督微调；
- LoRA、adapter、prefix tuning或soft prompt；
- RLHF、DPO、PPO、GRPO或其他参数学习；
- 知识编辑、权重编辑或神经元参数修改；
- 训练新Tokenizer并据此重新训练或更新模型；
- 训练正式实验必需的分类器、probe、回归头、reward model、环境模型或RL代理；
- 其他为得到论文正式实验结果而必须学习或更新参数的组件。

### 边界

- 文章可以报告训练实验，但只有当另一个彼此独立的正式实验单元完全不依赖训练，并单独通过T0、T1和E1—E4时，文章才可据该单元纳入。
- 仅把公开、现成checkpoint当作被测对象可以；如果论文的核心操纵或结论本身是某种训练方法带来的性能提升，则排除。
- 训练后才能得到的probe分数不等于普通统计分析；对已经产生的行为数据做回归或认知模型拟合则允许。

## 6. E1—E4：心理学与行为科学内容资格

### E1：LLM是相关行为实验主体

通过情形：

- LLM／Agent独立完成心理学或行为任务；
- 多个LLM／Agent围绕明确的社会或行为问题互动；
- 人类与LLM分别、独立完成同一或可比任务，再比较行为。

不通过情形：

- LLM只用于生成材料、标签、摘要、训练数据或研究工具；
- 研究重点是人类使用AI后的信任、依赖、满意度或决策变化；
- 人类与模型在同一实验过程中直接协作、建议或相互影响；
- 只有模型输出示例，没有正式任务、条件和结果。

### E2：研究的是心理学或行为科学问题

文章必须明确研究一个心理学／行为科学构念或现象，而不是只测“能力”或系统性能。

合格构念链应当能够写成：

```text
构念或行为现象
→ 操纵、条件、刺激结构或理论比较
→ 模型可观察的反应、选择、判断、语言输出或行动
→ 与构念直接对应的指标或轨迹
→ 对行为规律、差异、策略、错误或机制的解释
```

`reasoning`、`planning`、`intelligence`、`cognitive load`、`tool use`、`safety`、`robustness`、`alignment`或`human-like`等标签本身不等于心理构念。只有论文把具体过程、条件和结果操作化后，才可能通过E2。

### E3：实验可重建

必须能够从论文中确认：

- 被测模型或API；
- 输入、提示或刺激；
- 条件、操纵和对照；
- 输出或行动空间；
- 计分、编码或指标；
- 样本量、重复次数或运行结构；
- 关键方法与结果所在位置。

无法从摘要确认时进入全文核验；无法获得全文不是自动排除。

### E4：结果可解释

文章必须报告与构念直接对应的正式结果，例如：

- 条件差异、效应量或不确定性；
- 选择分布、错误模式、策略类型或行为轨迹；
- 稳健的模型间或人机差异；
- 能够检验理论解释的定量或系统编码结果。

只有总体准确率、排行榜、个别案例、演示输出或“看起来像人”的描述，不足以通过E4。

## 7. 常见边界

- **Benchmark：**只有当任务条件和结果能诊断具体心理构念、策略或行为机制时才纳入；普通能力榜单排除。
- **语言研究：**心理语言学、语用、话语理解、概念组织或语言行为可以纳入；纯工程NLP性能比较排除。
- **Agent：**有行动不等于行为科学；必须围绕明确构念并通过E2—E4。
- **安全与偏差：**若研究的是欺骗、偏见、从众、攻击性、公平判断等行为现象，可继续判断；若核心是攻击成功率、防御性能或安全工具，则排除。
- **社会模拟：**必须有明确社会行为构念、操纵、可观察行为和正式分析；仅生成模拟文本不够。
- **人机关系：**人类与模型彼此独立完成任务可以纳入；实验过程中直接人机互动不在当前范围。
- **纯人研究：**当前不单独纳入；合格人机独立对比中的人类条件完整保留。

## 8. 最低证据记录

每篇候选至少记录：

- 题名、来源、正式日期和稳定ID；
- T0、T1、E1、E2、E3、E4判断；
- 心理学／行为科学构念；
- 操纵或比较条件；
- 可观察反应与行为指标；
- 正式实验单元及页码、章节、表格或图；
- 第一个决定性失败；
- `INCLUDE`、`EXCLUDE`或过程状态及简明理由。

来源获取、PDF存在、哈希一致、AI建议和用户批准都必须与正式资格分开记录；任何一项都不能单独代替内容核验。
